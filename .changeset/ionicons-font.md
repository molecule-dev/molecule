New `@molecule/app-fonts-ionicons` font provider: the Ionicons 2.0 icon font and its `ion-*` glyph classes, self-hosted, so markup written against the 2.x class names (e.g. the RealWorld Conduit spec's `<i class="ion-heart">`) renders icons without an external CDN.
