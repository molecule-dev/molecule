# @molecule/api-slug

URL slugs for titles and names.

`slugify` folds accents and punctuation into a lowercase, hyphenated slug;
`uniqueSlug` finds one your store does not have yet; `uniqueSlugInTable`
does that against a table column through the bonded DataStore.

```typescript
interface SlugifyOptions {
```

#### `UniqueSlugOptions`

How {@link uniqueSlug} looks for a free slug.

```typescript
interface UniqueSlugOptions extends SlugifyOptions {
  /** Numbered tries (`slug-2` … `slug-N`) before a random suffix (default 20). */

  alwaysSuffix?: boolean
  /** The base when the text has no letters or digits (default `'item'`). */

}
```

### Functions

#### `slugify(text, options)`

Turn a title or name into a URL slug: accents folded ("Café" → "cafe"),
lowercase, every run of other characters one separator, no separator at
either end, cut to `maxLength` at a word boundary when one is near.

```typescript
function slugify(text: string, options?: SlugifyOptions): string
```

- `text` — The title or name.
- `options` — Separator and maximum length.

**Returns:** The slug; empty when the text has no letters or digits at all.

#### `uniqueSlug(text, isTaken, options)`

A slug for `text` that `isTaken` says is free: the plain slug, then
`slug-2`, `slug-3` … up to `maxNumbered`, then `slug-<random>`.

A check-then-insert can still race another writer: keep a UNIQUE index on
the column and retry the insert on a conflict (call this again).

```typescript
function uniqueSlug(
  text: string,
  isTaken: (slug: string) => Promise<boolean> | boolean,
  options?: UniqueSlugOptions,
): Promise<string>
```

- `text` — The title or name.
- `isTaken` — Whether a slug is already used (your store's lookup).
- `options` — Slug options, the numbered tries and a fallback for text with no letters.

**Returns:** A slug `isTaken` reported free.

#### `uniqueSlugInTable(table, column, text, options)`

```typescript
function uniqueSlugInTable(
```

- `table` — The table, e.g. `'articles'`.

## Injection Notes

### Requirements

Peer dependencies:

- `@molecule/api-database` ^1.0.1

### Runtime Dependencies

- `@molecule/api-database`

- **Keep a UNIQUE index on the slug column.** Checking and then inserting can
  race another request; the index makes the second insert fail, and calling
  `uniqueSlugInTable` again finds the next free slug.
- **`alwaysSuffix: true`** gives every row a random tail (`hello-world-k3x9q2`),
  for specs that expect slugs not to collide or not to be guessable.
- Text with no letters or digits (`'!!!'`) slugifies to `''`; the unique
  variants fall back to `fallback` (default `'item'`).
- `uniqueSlugInTable` needs a DataStore bond (`@molecule/api-database`);
  `slugify` and `uniqueSlug` need nothing.
