# @molecule/api-screenshots-molecule

## 1.1.0

### Minor Changes

- 4a433f7: First release: the molecule.dev hosted `ScreenshotProvider` bond — capture a URL or an HTML string to a PNG/JPEG image through molecule.dev's headless-Chrome render machine (`MOLECULE_API_KEY`/`MOLECULE_SERVICES_URL`, metered per capture), with the service limits mirrored locally so a bad call never leaves the process.
