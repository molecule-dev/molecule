# @molecule/app-routing-angular-router

Angular Router provider for `@molecule/app-routing`.

Implements the framework-neutral molecule `Router` over the Angular Router, so
molecule packages and app code can navigate, read params/query and register guards
without importing `@angular/router` — while Angular keeps owning its own routes,
links and guards. Guards, named routes, query/hash helpers and subscriptions come
from `@molecule/app-routing`'s `createHistoryRouter`, so this bond behaves exactly
like the other routing bonds and an app can swap routing bonds without noticing.

Wire it once at bootstrap, next to Angular's own router providers, and inject it
through `@molecule/app-angular`'s `ROUTER` token:

## Quick Start

```ts
import { bootstrapApplication } from '@angular/platform-browser'
import { provideRouter } from '@angular/router'
import { provideMoleculeRouter } from '@molecule/app-routing-angular-router'

bootstrapApplication(App, {
  providers: [
    provideRouter([
      { path: '', component: HomeComponent },
      { path: 'users/:id', component: UserComponent },
    ]),
    provideMoleculeRouter({ routes: [{ path: '/users/:id', name: 'user' }] }),
  ],
})
```

Outside Angular's injector (no `inject(AngularRouter)` available), build the
adapter directly with {@link createAngularRouter}; the exported {@link provider}
constant is the core browser router fallback (an Angular-backed router needs a
booted injector, which an import-time constant cannot have).

### Functions

#### `createAngularRouter(router, location, options)`

Creates a molecule `Router` over the Angular Router.

Reads, navigation and notifications all go through Angular itself: `location()`
parses `router.url`, `push`/`replace` call `router.navigateByUrl` (returning its
promise), `go` calls `location.historyGo`, and `listen` follows `router.events` —
one notification per committed navigation (Angular's own links, the back button,
or this router's `navigate`), `'pop'` for a popstate navigation, nothing for a
cancelled, failed or skipped one. Each committed entry gets a location key in its
`history.state`, which Angular carries through Back and Forward, so the key names
the entry as React Router's does. Guards, named routes and the query/hash helpers
come from `createHistoryRouter`.

```typescript
function createAngularRouter(
  router: AngularRouter,
  location: Location,
  options?: AngularRouterOptions,
): Router
```

- `router` — Angular's `Router` (inject it, or get it from an `EnvironmentInjector`).
- `location` — Angular's `Location` over the same history (injected alongside the router; with `provideRouter` it shares the `LocationStrategy` the router uses).
- `options` — Molecule route definitions for named routes and route params.

**Returns:** A molecule `Router` driving the Angular Router.

#### `provideMoleculeRouter(options)`

Provides the molecule `Router` built on Angular's own `Router` and `Location`,
under `@molecule/app-angular`'s `ROUTER` token, so molecule packages and app code
(`inject(ROUTER)`, `@molecule/app-angular`'s services) navigate through Angular.

Apps add it next to Angular's own `provideRouter(routes)` — Angular keeps owning
its route config; the molecule options only name the routes molecule should know
({@link Router.navigateTo}, {@link Router.generatePath}).

```typescript
function provideMoleculeRouter(options?: AngularRouterOptions): EnvironmentProviders
```

- `options` — Molecule route definitions for named routes and route params.

**Returns:** Environment providers.

### Constants

#### `provider`

The conventional typed provider constant.

The Angular Router only exists inside a booted injector (`inject(AngularRouter)`,
`inject(Location)`), so this constant — resolved at import time, before any app
boots — cannot be Angular-backed: it is the core `@molecule/app-routing`
{@link createBrowserRouter} (same `Router` interface, plain browser history).
Angular apps should NOT wire it; use {@link provideMoleculeRouter} next to
`provideRouter(routes)` to get the Angular-backed router.

```typescript
const provider: Router
```
