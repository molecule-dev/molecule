# @molecule/app-routing-solid-router

Solid Router provider for `@molecule/app-routing`.

Implements the molecule `Router` over `@solidjs/router`, so molecule packages
navigate the app's real Solid Router. Build it from a component under the router and
hand it to `MoleculeProvider`, so every molecule package shares it:

## Quick Start

```tsx
import { MemoryRouter, Route } from '@solidjs/router'
import { MoleculeProvider } from '@molecule/app-solid'
import { createSolidRouter } from '@molecule/app-routing-solid-router'

;<MemoryRouter
  history={memory}
  root={(props) => (
    <MoleculeProvider config={{ router: createSolidRouter({ history: memory }) }}>
      {props.children}
    </MoleculeProvider>
  )}
>
  <Route path="/users/:id" component={User} />
  <Route path="*rest" component={NotFound} />
</MemoryRouter>
```

#### `SolidMemoryHistory`

The memory history a Solid `<MemoryRouter history={…}>` runs on, as
{@link createSolidMemoryHistory} makes it: Solid's `MemoryHistory` shape plus each
entry's state and key. Solid Router reports no navigation action, so Back, Forward
and `go` on a memory router are only observable through the history's own `listen`.

```typescript
interface SolidMemoryHistory {
  /** The current entry's URL (`/users/7?x=1#top`). */
  get(): string
  /** The current entry's state and key. */
  entry(): SolidMemoryEntry
  /** Adds (or, with `replace`, replaces) an entry; Solid Router calls it to navigate. */
  set(change: LocationChange): void
  /** Moves one entry back. */
  back(): void
  /** Moves one entry forward. */
  forward(): void
  /** Moves `delta` entries, clamped to the history. */
  go(delta: number): void
  /**
   * Subscribes to the history's moves; each call passes the entry moved to.
   *
   * @param listener - Called after every `set` and every move.
   * @returns A function that unsubscribes the listener.
   */
  listen(listener: (value: string) => void): () => void
}
```

#### `SolidRouterOptions`

Solid Router-specific options for {@link createSolidRouter}.


#### `Router`

Client-side router providing navigation, guards, route matching, and history control.

All routing providers must implement this interface.

```typescript
interface Router {
  /**
   * Returns the current route location (pathname, search, hash, state).
   */
  getLocation(): RouteLocation

  /**
   * Gets the current route params.
   */
  getParams<T extends RouteParams = RouteParams>(): T

  /**
   * Gets the current query params.
   */
  getQuery(): QueryParams

  /**
   * Gets a specific query parameter.
   */
  getQueryParam(key: string): string | undefined

  /**
   * Gets the current hash.
   */
  getHash(): string

  /**
   * Navigates to a path.
   */
  navigate(path: string, options?: NavigateOptions): void

  /**
   * Navigates to a named route.
   */
  navigateTo(
    name: string,
    params?: RouteParams,
    query?: QueryParams,
    options?: NavigateOptions,
  ): void

  /**
   * Goes back in history.
   */
  back(): void

  /**
   * Goes forward in history.
   */
  forward(): void

  /**
   * Goes to a specific point in history.
   */
  go(delta: number): void

  /**
   * Updates the current query params.
   */
  setQuery(params: QueryParams, options?: NavigateOptions): void

  /**
   * Updates a specific query parameter.
   */
  setQueryParam(key: string, value: string | undefined, options?: NavigateOptions): void

  /**
   * Updates the current hash.
   */
  setHash(hash: string, options?: NavigateOptions): void

  /**
   * Checks if a path matches the current location.
   *
   * @returns `true` if the path matches the current route.
   */
  isActive(path: string, exact?: boolean): boolean

  /**
   * Matches a path pattern against a pathname.
   */
  matchPath<Params extends RouteParams = RouteParams>(
    pattern: string,
    pathname: string,
  ): RouteMatch<Params> | null

  /**
   * Generates a URL from a named route.
   */
  generatePath(name: string, params?: RouteParams, query?: QueryParams): string

  /**
   * Subscribes to route changes.
   */
  subscribe(listener: RouteChangeListener): () => void

  /**
   * Adds a navigation guard.
   */
  addGuard(guard: NavigationGuard): () => void

  /**
   * Registers route definitions.
   */
  registerRoutes(routes: RouteDefinition[]): void

  /**
   * Gets all registered routes.
   */
  getRoutes(): RouteDefinition[]

  /**
   * Destroys the router.
   */
  destroy(): void
}
```

### Functions

#### `createSolidMemoryHistory(initialEntries)`

Creates a memory history for a Solid `<MemoryRouter>`. Pass the same object to
`createSolidRouter({ history })` so the molecule router reads each entry's state and
key, and hears Back and Forward as pops.

```typescript
function createSolidMemoryHistory(initialEntries?: string[]): SolidMemoryHistory
```

- `initialEntries` — The starting entries; the last one is current. Defaults to `/`.

**Returns:** The history, with the shape Solid's `MemoryRouter` takes.

#### `createSolidRouter(options)`

Creates a molecule `Router` over the Solid Router the call sits inside.

Call it inside a Solid Router context — a component under `<Router>`, `<HashRouter>`
or `<MemoryRouter>`, typically the router's `root` component — and bond the result so
every molecule package shares the native router:

```typescript
function createSolidRouter(options?: SolidRouterOptions): Router
```

- `options` — Route definitions and, for a memory router, its history.

**Returns:** A molecule `Router` driving that Solid Router.

### Constants

#### `provider`

Typed provider constant for the bond registry.

A Solid Router needs a component context (`useLocation` and friends read it), so no
router can be built at import time: `provider` is `@molecule/app-routing`'s own
browser router, correct only where no Solid Router is mounted. Wire
`createSolidRouter()` from a component under the router instead (see its example).

```typescript
const provider: Router
```

- `solid-js`

- Call `createSolidRouter()` inside the router's `root` component (any component under
  `<Router>`, `<HashRouter>` or `<MemoryRouter>`): it reads the native router through
  `useLocation()`, `useNavigate()` and `useParams()`, which need that context.
