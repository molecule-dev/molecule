# @molecule/app-drag-drop-dndkit-solid

Solid sortable list for `@molecule/app-drag-drop-dndkit`.

{@link SortableList} renders a list the user reorders with the pointer,
touch or the keyboard, on `@dnd-kit/solid`. Each row calls
{@link useSortableItem}. The options are `@molecule/app-drag-drop-dndkit`'s
`SortableListOptions`, the same in the React, Vue, Svelte and Angular
bindings, so a list swaps between frameworks unchanged.

## Quick Start

```tsx
import { For } from 'solid-js'
import { SortableList, useSortableItem } from '@molecule/app-drag-drop-dndkit-solid'

function Row(props: { task: Task }) {
  const item = useSortableItem({ id: props.task.id })
  return (
    <li ref={item.ref} data-dragging={item.isDragging()}>
      {props.task.title}
    </li>
  )
}

function Tasks(props: { tasks: Task[]; setTasks: (next: Task[]) => void }) {
  return (
    <SortableList
      items={props.tasks}
      onReorder={props.setTasks}
      getItemLabel={(task) => task.title}
    >
      <ul>
        <For each={props.tasks}>{(task) => <Row task={task} />}</For>
      </ul>
    </SortableList>
  )
}
```

### Functions

#### `SortableList(props)`

A list the user reorders with the pointer, touch or the keyboard (Space or
Enter to pick an item up, the arrow keys to move it, Space or Enter to drop
it, Escape to cancel). A screen reader hears translated instructions and
where the item is as it moves. A drop that moves an item calls `onReorder`
with the new order; render `items` from your state.

Props are read lazily, so the drag callbacks see the list as it is when the
event fires.

```typescript
function SortableList<T extends { id: string }>(props: SortableListProps<T>): JSX.Element
```

- `props` — {@link SortableListProps}.

**Returns:** The list.

#### `useSortableItem(options)`

Makes one row of a `SortableList` draggable. Call it in the row's component,
inside the list.

```typescript
function useSortableItem(options: SortableItemOptions): SortableItemState
```

- `options` — The row's item id, drag data and disabled flag.

**Returns:** The refs to attach and the row's drag state.
