# @molecule/app-drag-drop-dndkit-react

React sortable list for `@molecule/app-drag-drop-dndkit`.

{@link SortableList} renders a list the user reorders with the pointer,
touch or the keyboard, on `@dnd-kit/react`. Each row calls
{@link useSortableItem}. The options are `@molecule/app-drag-drop-dndkit`'s
`SortableListOptions`, the same in the Vue, Solid, Svelte and Angular
bindings, so a list swaps between frameworks unchanged.

## Quick Start

```tsx
import { SortableList, useSortableItem } from '@molecule/app-drag-drop-dndkit-react'

function Row({ task }: { task: Task }) {
  const { ref, isDragging } = useSortableItem({ id: task.id })
  return (
    <li ref={ref} data-dragging={isDragging}>
      {task.title}
    </li>
  )
}

function Tasks({ tasks, setTasks }: { tasks: Task[]; setTasks: (next: Task[]) => void }) {
  return (
    <SortableList items={tasks} onReorder={setTasks} getItemLabel={(task) => task.title}>
      <ul>
        {tasks.map((task) => (
          <Row key={task.id} task={task} />
        ))}
      </ul>
    </SortableList>
  )
}
```

### Functions

#### `SortableList(props)`

A list the user reorders with the pointer, touch or the keyboard (Space or
Enter to pick an item up, the arrow keys to move it, Space or Enter to drop
it, Escape to cancel). A screen reader hears translated instructions and
where the item is as it moves. A drop that moves an item calls `onReorder`
with the new order; render `items` from your state.

```typescript
function SortableList<T extends { id: string }>(props: SortableListProps<T>): JSX.Element
```

- `props` — {@link SortableListProps}.

**Returns:** The list.

#### `useSortableItem(options)`

Makes one row of a {@link SortableList} draggable. Call it in the row's
component, inside the list.

```typescript
function useSortableItem(options: SortableItemOptions): SortableItemState
```

- `options` — The row's item id, drag data and disabled flag.

**Returns:** The refs to attach and the row's drag state.
