# @molecule/app-drag-drop-dndkit-vue

Vue sortable list for `@molecule/app-drag-drop-dndkit`.

{@link SortableList} renders a list the user reorders with the pointer,
touch or the keyboard, on `@dnd-kit/vue`. Each row calls
{@link useSortableItem}. The options are `@molecule/app-drag-drop-dndkit`'s
`SortableListOptions`, the same in the React, Solid, Svelte and Angular
bindings, so a list swaps between frameworks unchanged.

<script setup lang="ts">
import { useSortableItem } from '@molecule/app-drag-drop-dndkit-vue'
import type { ComponentPublicInstance } from 'vue'

interface Task {
  id: string
  title: string
}

const props = defineProps<{ task: Task }>()
const { ref: rowRef, isDragging } = useSortableItem({ id: props.task.id })

// A template ref may also receive a component instance, which is not this row's element.
const setRow = (element: Element | ComponentPublicInstance | null): void => {
  rowRef(element instanceof Element ? element : null)
}
</script>

<template>

</template>

## API

### Interfaces

#### `SortableListProps`

Props for {@link SortableList}: the options every framework's list takes,
plus the rendered list as the default slot.

The callbacks are declared in method form on purpose. A Vue component is not
generic, so this list is typed over `{ id: string }`; method parameters
compare bivariantly, which lets a list of your own item type pass its own
`onReorder(items: Task[])`, `getItemLabel(item: Task)` and drag listeners.

```typescript
interface SortableListProps<T extends { id: string }> extends Omit<
  SortableListOptions<T>,
  'onReorder' | 'getItemLabel' | 'onDragStart' | 'onDragOver' | 'onDragEnd'
> {
  /**
   * Called with the whole list in its new order when a drop moves an item. Not
   * called when the drag is cancelled, the list is disabled, or the item is
   * dropped where it started.
   *
   * @param items - The reordered items.
   */
  onReorder(items: T[]): void
  /**
   * The name a screen reader hears for an item in the drag announcements.
   * Defaults to the item's `id`.
   *
   * @param item - The item.
   * @returns Its label.
   */
  getItemLabel?(item: T): string
  /**
   * Called when a drag starts.
   *
   * @param event - The core drag-start event.
   */
  onDragStart?(event: DragStartEvent): void
  /**
   * Called while a dragged item is over another item.
   *
   * @param event - The core drag-over event.
   */
  onDragOver?(event: DragOverEvent): void
  /**
   * Called when a drag ends, before `onReorder`. `overId` is the item whose
   * place it took.
   *
   * @param event - The core drag-end event.
   */
  onDragEnd?(event: DragEndEvent): void
}
```

#### `SortableItemState`

What {@link useSortableItem} returns for one row.

```typescript
interface SortableItemState {
  /**
   * Attach to the row's element, as a template ref. dnd-kit makes it
   * focusable and sets its `role`, `aria-roledescription`, `aria-describedby`,
   * `aria-pressed` and `aria-disabled`.
   *
   * @param element - The row's element, or `null` on unmount.
   */
  ref: (element: Element | null) => void
  /**
   * Attach to a drag handle inside the row so only the handle starts a drag;
   * leave it unused to drag by the whole row.
   *
   * @param element - The handle's element, or `null` on unmount.
   */
  handleRef: (element: Element | null) => void
  /** `true` while this row is being dragged. */
  isDragging: Readonly<Ref<boolean>>
  /** `true` while another dragged row is over this one. */
  isDropTarget: Readonly<Ref<boolean>>
}
```

### Constants

#### `SortableList`

A list the user reorders with the pointer, touch or the keyboard (Space or
Enter to pick an item up, the arrow keys to move it, Space or Enter to drop
it, Escape to cancel). A screen reader hears translated instructions and
where the item is as it moves. A drop that moves an item calls `onReorder`
with the new order; render `items` from your state.

The rows come from the default slot; each one calls {@link useSortableItem}.

```typescript
const SortableList: DefineSetupFnComponent<
  SortableListProps<{ id: string }>,
  {},
  {},
  SortableListProps<{ id: string }> & {},
  PublicProps
>
```

- `props` — {@link SortableListProps}.
- `context` — The setup context, whose default slot renders the rows.

**Returns:** The list's render function.
