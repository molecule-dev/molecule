# @molecule/app-drag-drop-dndkit-svelte

Svelte sortable list for `@molecule/app-drag-drop-dndkit`.

`SortableList` renders a list the user reorders with the pointer, touch or
the keyboard, on `@dnd-kit/svelte`. Each row calls `useSortableItem`. The
options are `@molecule/app-drag-drop-dndkit`'s `SortableListOptions`, the
same in the React, Vue, Solid, Svelte and Angular bindings, so a list swaps
between frameworks unchanged.

`useSortableItem` returns Svelte attachments for the row element (`ref`) and
an optional drag handle (`handleRef`), plus the row's `isDragging` and
`isDropTarget` state as read-only reactive getters. Apply an attachment with
Svelte's attachment tag on the element, or with `createAttachmentKey()` in a
spread, as the example below shows.

## Quick Start

```svelte
<!-- Row.svelte -->
<script lang="ts">
  import { createAttachmentKey } from 'svelte/attachments'

  import { useSortableItem } from '@molecule/app-drag-drop-dndkit-svelte'

  let { task }: { task: Task } = $props()

  const { ref, isDragging } = useSortableItem({ id: task.id })
  const attach = { [createAttachmentKey()]: ref }
</script>

<li {...attach} data-dragging={isDragging}>{task.title}</li>
```

```svelte
<!-- Tasks.svelte -->
<script lang="ts">
  import { SortableList } from '@molecule/app-drag-drop-dndkit-svelte'
  import Row from './Row.svelte'

  let { tasks }: { tasks: Task[] } = $props()
</script>

<SortableList
  items={tasks}
  onReorder={(next) => (tasks = next)}
  getItemLabel={(task) => task.title}
>
  <ul>
    {#each tasks as task (task.id)}
      <Row {task} />
    {/each}
  </ul>
</SortableList>
```

#### `SortableItemState`

What {@link useSortableItem} returns for one row.

```typescript
interface SortableItemState {
  /**
   * A Svelte attachment for the row's element: Svelte calls it with the
   * element when the row mounts, and with the returned cleanup when it is
   * removed. dnd-kit makes the element focusable and sets its `role`,
   * `aria-roledescription`, `aria-describedby`, `aria-pressed` and
   * `aria-disabled`.
   *
   * @param node - The row's element.
   * @returns The detach function Svelte calls when the row is removed.
   */
  ref: (node: HTMLElement) => () => void
  /**
   * A Svelte attachment for a drag handle inside the row (the library's
   * `attachHandle`) so only the handle starts a drag; leave it unused to drag
   * by the whole row.
   *
   * @param node - The handle's element.
   * @returns The detach function Svelte calls when the handle is removed.
   */
  handleRef: (node: HTMLElement) => () => void
  /** `true` while this row is being dragged. */
  readonly isDragging: boolean
  /** `true` while another dragged row is over this one. */
  readonly isDropTarget: boolean
}
```
