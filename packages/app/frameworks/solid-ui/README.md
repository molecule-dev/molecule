SolidJS UI components for molecule.dev.

Implements the same component surface as `@molecule/app-ui-react`, styled

## Quick Start

```tsx
import { setClassMap } from '@molecule/app-ui'
import { classMap } from '@molecule/app-ui-tailwind'
import { Button, Card, Modal } from '@molecule/app-ui-solid'
import { createSignal } from 'solid-js'

// Once at startup, before first render — components throw without it:
setClassMap(classMap)

function ConfirmPanel() {
  const [open, setOpen] = createSignal(false)
  return (
    <Card>
      <Button color="primary" onClick={() => setOpen(true)}>
        Open
      </Button>
      <Modal open={open()} onClose={() => setOpen(false)} title="Confirm">
        <Button color="error" onClick={() => setOpen(false)}>
          Done
        </Button>
      </Modal>
    </Card>
  )
}
```

#### `AuthGuard(props)`

and provides the resolved account identity to its sub-components.

```typescript
function UserMenuPopover(props: UserMenuPopoverProps): any
```

- `props` — The popover children, optional guest label, and className.

**Returns:** The relative-positioned popover container.

#### `UserMenuPopoverTrigger(props)`

The trigger button: an initials avatar plus the account name and email,

```typescript
function UserMenuPopoverTrigger(props: UserMenuPopoverTriggerProps): any
```

- `props` — aria-label overrides, `data-mol-id`, and className.

**Returns:** The popover trigger button.

#### `UserMenuPopoverPanel(props)`

The popover panel: an absolutely-positioned card with a built-in identity

```typescript
function UserMenuPopoverPanel(props: UserMenuPopoverPanelProps): any
```

- `props` — The nav children, className, and aria-label overrides.

**Returns:** The popover panel, or nothing when closed.

#### `useUserMenuPopoverClose()`

Returns a callback that closes the enclosing `UserMenuPopover`. Useful for

don't change the route. Returns a no-op when called outside a

```typescript
function useUserMenuPopoverClose(): () => void
```

**Returns:** A function that closes the popover.
