# @molecule/app-ui-solid

SolidJS UI components for molecule.dev.

Implements the same component surface as `@molecule/app-ui-react`, styled

Separator, Skeleton, Spinner, Switch, Table, Tabs, Textarea, Toast,

## Quick Start

```tsx
import { setClassMap } from '@molecule/app-ui'
import { classMap } from '@molecule/app-ui-tailwind'
import { Button, Card, Modal } from '@molecule/app-ui-solid'
import { createSignal } from 'solid-js'

// Once at startup, before first render — components throw without it:
setClassMap(classMap)

function ConfirmPanel() {
  const [open, setOpen] = createSignal(false)
  return (
    <Card>
      <Button color="primary" onClick={() => setOpen(true)}>
        Open
      </Button>
      <Modal open={open()} onClose={() => setOpen(false)} title="Confirm">
        <Button color="error" onClick={() => setOpen(false)}>
          Done
        </Button>
      </Modal>
    </Card>
  )
}
```

#### `KitEvent`

The event a UI kit hands a component's handler: the members that behave the same on every kit. React's kit
passes React's event (so `stopPropagation()` stops React parent handlers), the other kits pass the DOM event;
both satisfy this type. A handler that needs a member only one of them has (`nativeEvent`, `composedPath()`,
`isComposing`) takes the component's ref element (see {@link BaseProps}) and listens on it.

`type` is left out on purpose: kits report different event types for the same moment (a text field's
`onChange` is React's `'change'` and the DOM's `'input'`).

```typescript
interface KitEvent {
  /** The element the event started on (`(event.target as HTMLInputElement).value` reads a field). */
  readonly target: EventTarget | null
  /** The element of the component the handler was passed to. */
  readonly currentTarget: EventTarget | null
  /** Whether a handler already called {@link KitEvent.preventDefault}. */
  readonly defaultPrevented: boolean
  /** Cancels the browser's default action (a form's submit, a checkbox's toggle). */
  preventDefault(): void
  /** Stops handlers of ancestor components of the same kit. */
  stopPropagation(): void
}
```

#### `BaseProps`

Base props shared by all components.

Ref element: a component that renders one main element gives the caller that element, the one
that takes `className` and `style`. Each UI kit hands it over in its framework's own way: React
and Solid a `ref`, Vue a template ref's `$el`, Svelte `bind:ref`, Angular the component's
`element()` signal. It is empty while the element is not rendered (a closed Tooltip, Dropdown or
Modal). A component's own doc names the element when it is not the outermost one.

```typescript
interface BaseProps {
  /**
   * Additional CSS class name(s).
   */
  className?: string

  /**
   * Inline styles.
   */
  style?: CSSProperties

  /**
   * Test ID for automated testing.
   */
  testId?: string

  /**
   * Automation ID for AI agents and E2E tests. Maps to the `data-mol-id`
   * HTML attribute. Use `molId()` from `./automation.js` to generate
   * semantic IDs. (Tooling only — screen readers do not expose `data-*`
   * attributes; accessible names come from labels/`aria-*`.)
   */
  automationId?: string

  /**
   * Disables the controls the component renders: a disabled Button, Input, Textarea, Select,
   * Checkbox, Switch, RadioGroup, Tabs, Accordion or Pagination takes no input, a disabled
   * Dropdown never opens, and a disabled Card never calls `onClick` (an interactive one is
   * announced as disabled and leaves the tab order). A component that renders no control
   * (Badge, Spinner, Skeleton, a layout box) ignores it.
   */
  disabled?: boolean
}
```

### Functions

#### `AuthGuard(props)`

Route guard for authenticated sections of the app tree.

- While the auth status is `'loading'` (no session decision yet), renders the
  `loadingFallback` (or the default `<div data-mol-id="auth-guard-loading">{t('common.loading')}</div>`).
- If the status is `'unauthenticated'`, renders nothing and redirects to
  `loginPath` (replacing the entry), carrying the attempted location in
  `state.from` for post-login restoration. On `loginPath` itself it renders
  its children instead, so a guard that wraps the whole route tree (login
  page included) does not redirect in a loop.
- Otherwise renders `children` (or `<RoutedView />` if none).

The guard reads `status`, not `initialized`: a stored token AND user make the
FIRST render `'authenticated'`, so a protected page paints immediately instead
of waiting for the background verification or a current-user round trip.
`'unavailable'` (a retained candidate the server could not confirm) still
renders the page and lets the API decide. It is not a confirmed-session
boolean: `isAuthenticated` can be false and `user` can be null while a
token/cookie-only candidate is unavailable, so never redirect on the
boolean or require a profile in this state.

The default loading tag carries `data-mol-id="auth-guard-loading"`
so AI agents and e2e tests can target it reliably. When the caller
passes a custom `loadingFallback`, it's the caller's responsibility
to include any data-mol-id they need.

```typescript
function AuthGuard(props: AuthGuardProps): JSX.Element
```

#### `Icon(props)`

Renders an SVG glyph looked up by `name` from the bonded
`@molecule/app-icons` set.

Handles two icon-data shapes returned by the bond:

1. Pre-rendered SVG markup (`icon.svg`) — injected through the
   element's `innerHTML` property. The bond is the trust boundary; only
   bond a set that controls its own SVG strings.
2. Structured paths (`icon.paths`) — rendered as discrete `<path>`
   children, with optional stroke styling forwarded from the icon set.

`role="img"`, `onClick`) is forwarded to the root `<svg>` via spread.

Decorative by default: when the caller passes no `aria-label` /
`aria-labelledby` / `role`, the SVG is rendered `aria-hidden` +
`focusable="false"` so screen readers skip it (an unnamed inline SVG is
announced as a stray "image" by some combos). Passing any of those props
opts the icon into the accessibility tree.


#### `Modal`

Renders the Modal component.

Renders into a `document.body` portal. Every other declared prop (`id`,

scroll lock is reference-counted so closing one of several open dialogs
