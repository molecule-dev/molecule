# @molecule/app-file-card-angular

Angular file card primitives — the Angular counterpart of
`@molecule/app-file-card-react`: the same props and the same DOM for the
same input.

Exports:

- `<FileCard>` — file representation card (icon/thumbnail + name + size + modified date + optional actions).
  Two layouts: `'grid'` (square tile, default) and `'row'` (horizontal list line).
- `<FileIcon>` — stroke-currentColor SVG glyph keyed by `FileKind`.
- `bytes(value)` — pure helper that formats a byte count as `420 B` / `1.4 KB` / `2.3 MB` / etc.
- `sizeParts(value)` — the same split as `{ n, unit }`, for rendering the unit through `t()`.
- `relativeBucket(at, now?)` — pure helper that buckets a timestamp into `just-now` / `minutes` /
  `hours` / `days` / `weeks` / `months` / `absolute`.
- `FileSummary` / `FileKind` / `SizeParts` types — stable shape for the consumer's domain model.

Used by cloud-file-manager (grid + list views), social-media + email-client
(attachment previews), and document-collaboration (sidebars).

### Functions

#### `sizeParts(value)`

Split a non-negative byte count into its displayed number and unit token
(e.g. `420` + `B`, `1.4` + `KB`, `471` + `MB`) — the two halves
{@link bytes} joins, exposed so the card can translate the unit word via
`t()` (one literal key per {@link SizeUnit}, as the kind labels do).

Uses a 1024 base (binary) and 1 fractional digit for KB+. Returns the
`0 B` parts for non-finite or negative inputs so callers do not need to
pre-validate.

```typescript
function sizeParts(value: number): SizeParts
```

- `value` — Byte count (>= 0).

**Returns:** The displayed number and unit token.

#### `bytes(value)`

Format a non-negative byte count as a short human-readable string
(e.g. `420 B`, `1.4 KB`, `2.3 MB`, `4.7 GB`, `8.1 TB`).

The unlocalized join of {@link sizeParts}'s two halves, for callers that
want the raw SI shorthand. The card itself renders the unit through `t()`
(`file-card.size.<unit>` keys in the locale bond) so a locale switch
translates it; the unit token is universal SI shorthand — a language that
names bytes differently (French octets, Russian КБ) changes only the token,
never the magnitude.

```typescript
function bytes(value: number): string
```

- `value` — Byte count (>= 0).

**Returns:** Formatted size string.

#### `relativeBucket(at, now)`

Bucket a `Date` (or ISO string / ms timestamp) against `now` into a
relative-time bucket. The bucket is purely structural — translation keys
and pluralization are applied by the consumer.

```typescript
function relativeBucket(at: string | number | Date, now?: Date): RelativeBucket
```

- `at` — Modified-at timestamp (ISO string, ms epoch, or `Date`).
- `now` — Reference "now" (defaults to `new Date()`). Injected for tests.

**Returns:** A `RelativeBucket` describing the offset from `now`.
