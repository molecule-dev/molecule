# @molecule/app-shell-layout-solid

Solid top-level app shell layout.

Exports `AppShellLayout` — the Solid counterpart of
`@molecule/app-shell-layout-react` with the same props and the same DOM:
header slot + main content (constrained by a Container) + footer slot,
with the page frame styled via the ClassMap bond. Apps fill the slots
with their own Header, Footer, and route content.

### Functions

#### `AppShellLayout(props)`

Top-level page scaffold: header → main (constrained by Container) → footer.

The page frame uses ClassMap tokens (`cm.page`, `cm.appLayout`) so the
styling library can be swapped without touching consumers. The header and
footer are slot props so consumers retain full control over branding,
navigation, and footer copy.

This is the Solid counterpart of `@molecule/app-shell-layout-react`: the
same props (React names), the same ClassMap tokens, and the same DOM for
the same input.

```typescript
function AppShellLayout(props: AppShellLayoutProps): JSX.Element
```

- `props` — Component props (see {@link AppShellLayoutProps}).

**Returns:** The rendered shell layout.
