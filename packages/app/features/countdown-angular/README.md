#### `Countdown`

Countdown component.

Live countdown display with three default formats, the Angular counterpart
of `@molecule/app-countdown-react`'s `Countdown`: the same props (React
names), the same DOM for the same input.

React's root is the display `<span>` — or, once the target passes and an
`expired` node was given, that node alone (a fragment, with no wrapper). A
host element always exists in Angular, so this component's host is
transparent (`mol-countdown`, `display: contents`, unwrapped by the
conformance normalizer) and the template renders whichever root React would.

Node-valued props are `<ng-template>` refs (`expired`, and `render`, whose
template context carries the live state as `$implicit` / `a0`).

```typescript
@Component({
  selector: 'mol-countdown',
  standalone: true,
  imports: [NgTemplateOutlet],
  inputs: ['target', 'format', 'render', 'expired', 'className'],
  host: { 'data-parity-unwrap': '', style: 'display: contents' },
  template: `@if (expiredTemplate(); as expired) {
      <ng-container [ngTemplateOutlet]="expired" />
    } @else if (renderTemplate(); as custom) {
      <span [class]="className"
        ><ng-container [ngTemplateOutlet]="custom" [ngTemplateOutletContext]="renderContext()"
      /></span>
    } @else {
      <span [class]="classes()">{{ display() }}</span>
    }`,
})
export class Countdown implements DoCheck, OnDestroy {
  /** Target date / ISO string / epoch ms. */
  target!: Date | string | number
  /** Display format. Defaults to `'compact'` at read time. */
  format?: 'compact' | 'long' | 'colon'
  /** Renderer override — its template context carries the live state. */
  render?: TemplateRef<unknown> | null
  /** Optional template rendered when the timer expires. */
  expired?: TemplateRef<unknown> | null
  /** Extra classes. */
  className?: string

  /** React's `useCountdown` state, kept current by the interval. */
  private readonly state = signal<CountdownState>({
    days: 0,
    hours: 0,
    minutes: 0,
    seconds: 0,
    msRemaining: 0,
    expired: false,
  })

  /** The target the running timer belongs to (`null` before the first check). */
  private timerTarget: number | null = null

  /** Stops the running timer. */
  private stop: (() => void) | null = null

  /**
   * The current class map.
   * @returns The UIClassMap.
   */
  cm(): UIClassMap {
    return getClassMap()
  }

  /**
   * The wrapper class list (React's `cm.cn(className)`).
   * @returns The class string.
   */
  classes(): string {
    return this.cm().cn(this.className)
  }

  /**
   * The display text for the current format (React's `format` branches).
   * @returns The display text.
   */
  display(): string {
    const current = this.state()
    return formatDisplay(
      this.format ?? 'compact',
      current.days,
      current.hours,
      current.minutes,
      current.seconds,
    )
  }

  /**
   * The `expired` template, when the target has passed and the caller supplied one.
   * @returns The template, or null.
   */
  expiredTemplate(): TemplateRef<unknown> | null {
    return this.state().expired && isTemplate(this.expired) ? this.expired : null
  }

  /**
   * The render template, when the caller supplied one.
   * @returns The template, or null.
   */
  renderTemplate(): TemplateRef<unknown> | null {
    return isTemplate(this.render) ? this.render : null
  }

  /**
   * The render template's context: React's `render(state)` argument as `$implicit` / `a0`.
   * @returns The template context.
   */
  renderContext(): Record<string, unknown> {
    const current = this.state()
    return { $implicit: current, a0: current, a1: undefined, a2: undefined }
  }

  /**
   * Follows the `target` input and starts, restarts or stops the timer. Angular
   * writes inputs as plain fields, so the change is picked up here rather than
   * by an effect.
   */
  ngDoCheck(): void {
    const ts = targetMs(this.target)
    if (ts === this.timerTarget) return
    this.timerTarget = ts
    this.stop?.()
    this.stop = tickCountdown(ts, 1_000, (next) => this.state.set(next))
  }

  /** Stops the timer when the component is destroyed. */
  ngOnDestroy(): void {
    this.stop?.()
    this.stop = null
  }
}
```

### Functions

#### `useCountdown(target, tickMs)`

Live-updating countdown to a target date, React's `useCountdown` in Angular's
idiom: call it in an injection context (a component field initializer or
constructor). The target and interval may each be a plain value or a signal,
and the countdown follows a changed signal on the same host — a component
re-rendering with a new `target` input behaves as React's hook does.

```typescript
function useCountdown(
  target: Date | string | number | Signal<Date | string | number>,
  tickMs?: number | undefined | Signal<number | undefined>,
): {
  /** Days remaining. */
  days: Signal<number>
  /** Hours (0-23) within current day. */
  hours: Signal<number>
  /** Minutes (0-59) within current hour. */
  minutes: Signal<number>
  /** Seconds (0-59) within current minute. */
  seconds: Signal<number>
  /** Total milliseconds remaining (negative if past). */
  msRemaining: Signal<number>
  /** True once the target is in the past. */
  expired: Signal<boolean>
}
```

- `target` — Date / ISO string / epoch ms, or a signal of one.
- `tickMs` — Refresh interval, or a signal of one. Defaults to `1000`; `0` or less disables it.

**Returns:** A signal per live countdown field.

The built-in `'compact'` and `'long'` formats hardcode English unit labels
and pluralization ("3d 4h", "3 days 4 hours") — there is no locale bond.
For localized apps pass a `render` `<ng-template>` whose context carries the
live state (`$implicit` / `a0`) and compose translated units via `t()` (or
`Intl.RelativeTimeFormat`). `expired` only swaps the rendering once the
target passes — schedule side effects (redirects, refetches) from
`useCountdown().expired()` in an effect, not from the component.
