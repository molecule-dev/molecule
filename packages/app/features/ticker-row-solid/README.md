# @molecule/app-ticker-row-solid

Solid financial ticker row.

Exports `TickerRow` — symbol + price + change% + optional icon, sparkline
and meta, with the direction color applied inline via the ClassMap bond's
fixed hex values. Use for crypto trackers, stock watchlists, market
dashboards. It is the Solid counterpart of `@molecule/app-ticker-row-react`:
the same props (React names) and the same DOM for the same input. Pair the
`sparkline` prop with `<Sparkline values={...} />` from
`@molecule/app-sparkline-solid`.

### Functions

#### `TickerRow(props)`

Financial ticker row — symbol + price + change% + optional sparkline.
Use for crypto trackers, stock watchlists, market dashboards. `changePct`
drives the ▲/▼/– direction and a FIXED green/red hex color applied inline;
`price` and `meta` are opaque display nodes — the app owns formatting. With
`onClick` the row is a clickable div WITHOUT button semantics — wrap it in
your own button/link where keyboard access matters.
