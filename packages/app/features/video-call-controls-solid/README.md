# @molecule/app-video-call-controls-solid

Solid video-call participant tile + controls bar.

Exports:

- `VideoCallControls` — bottom controls bar (mute/video/screen-share/leave).
- `ParticipantTile` — single participant card with name, mute, hand-raised, speaking ring.

Pure UI — the app owns the WebRTC/SDK plumbing (pair with an
`@molecule/api-video-rooms-*` bond server-side) and passes state + callbacks
down. It is the Solid counterpart of
`@molecule/app-video-call-controls-react`: same exports, same props and the
same DOM for the same input, so an app switches framework by changing only
the package name.

## Quick Start

```tsx
import { createSignal } from 'solid-js'

import { ParticipantTile, VideoCallControls } from '@molecule/app-video-call-controls-solid'

export function CallBar() {
  const [audioOn, setAudioOn] = createSignal(true)
  const [videoOn, setVideoOn] = createSignal(true)
  return (
    <div>
      <ParticipantTile name="Alice" audioEnabled={audioOn()} speaking />
      <VideoCallControls
        audioEnabled={audioOn()}
        onToggleAudio={() => setAudioOn((value) => !value)}
        videoEnabled={videoOn()}
        onToggleVideo={() => setVideoOn((value) => !value)}
        onLeave={() => console.log('leave call')}
      />
    </div>
  )
}
```

### Functions

#### `ParticipantTile(props)`

Single participant tile for a video grid. Apps supply the video element via
`videoSlot`; this component renders the surrounding chrome (name badge, mute
indicator, hand-raised, speaking ring).

Tiles are fixed 16:9 theme surfaces (`cm.surface` background, theme ink) with
a scrim name badge (`cm.bgScrim`, inverse text) and a success-tone speaking
ring (`cm.textTone('success')` ink, `currentColor` outline); supply the
`<video>` element via `videoSlot` and a fallback via `avatarSlot`.

#### `VideoCallControls(props)`

Bottom controls bar for a video meeting — mute, camera, screen-share,
leave. Pure UI — apps own the WebRTC plumbing.

The screen-share button renders only when `onToggleScreenShare` is supplied;
`extraControls` slots more buttons before Leave. Control-button glyphs are
emoji delivered as i18n default values, so the emoji doubles as the
accessible name.

doubles as the accessible name. In `ParticipantTile` the ' (you)' suffix and
the 'Muted' / 'Hand raised' indicator labels are translated too

(`cm.textTone('success')` ink, `currentColor` outline); supply your `<video>`
