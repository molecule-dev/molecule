# @molecule/app-kanban-board-angular

Angular Kanban board primitives (pure presentational — you own the data) —
the Angular counterpart of `@molecule/app-kanban-board-react`, with the same
exports, the same props (React names) and the same DOM for the same input.

Exports:

- `<KanbanBoard>` (`div[mol-kanban-board]`) — columns side-by-side with HTML5
  drag-drop between columns. Props: `columns`,
  `onCardMove?(cardId, fromColumnId, toColumnId)`, `onCardClick?(card, column)`,
  `renderHeaderActions` / `renderFooter` (templates whose context carries the
  column as `a0`), `className?`.
- `<KanbanColumn>` (`section[mol-kanban-column]`) / `<KanbanColumnHeader>`
  (`header[mol-kanban-column-header]`) / `<KanbanCard>`
  (`div[mol-kanban-card]`) — the building blocks, usable standalone.
- `KanbanColumnData` (`{ id, title, accent?, cards }`), `KanbanCardData`
  (`{ id, title, body?, footer? }`) types. Node-valued fields are template
  references or text.

This package is standalone UI: it does NOT use the headless
`@molecule/app-kanban` core or the `app-kanban-default` bond. Reach for those
when you want board STATE management (move/add/remove logic) behind a bond;
use this package when you just need the rendered board and will persist moves
yourself in `onCardMove`.

#### `KanbanBoard`

Kanban board with HTML5 drag-drop between columns.

The Angular counterpart of `@molecule/app-kanban-board-react`'s
`KanbanBoard`: the same props (React names), the same ClassMap tokens, and
the same DOM for the same input. The host IS the board `<div>`
(`div[mol-kanban-board]`), matching React's root exactly, with one wrapper
div per column holding a `section[mol-kanban-column]`.

The drag payload is the same JSON React writes under `text/molecule-kanban`:
`{ cardId, fromColumnId }`. A drop on the source column is ignored, and a
malformed payload cancels the drop without a callback.

```typescript
@Component({
  selector: 'div[mol-kanban-board]',
  standalone: true,
  imports: [KanbanColumn],
  inputs: [
    'columns',
    'onCardMove',
    'onCardClick',
    'renderHeaderActions',
    'renderFooter',
    'className',
  ],
  host: {
    '[class]': 'classes()',
  },
  // prettier-ignore
  template: `@for (column of columns; track column.id) {<div [class]="columnWrapperClasses()"><section mol-kanban-column [column]="column" [onCardClick]="onCardClick" [onDrop]="dropHandlerFor()" [onCardDragStart]="cardDragHandler" [headerActions]="renderHeaderActions" [footer]="renderFooter"></section></div>}`,
})
export class KanbanBoard {
  /** Columns to render, left to right. */
  columns: KanbanColumnData[] = []
  /** Called when a card moves from one column to another. */
  onCardMove?: (cardId: string, fromColumnId: string, toColumnId: string) => void
  /** Called when a card is clicked. */
  onCardClick?: (card: KanbanCardData, column: KanbanColumnData) => void
  /** Optional per-column header action template (context: `a0` = column). */
  renderHeaderActions?: TemplateRef<unknown>
  /** Optional per-column footer template (context: `a0` = column). */
  renderFooter?: TemplateRef<unknown>
  /** Extra classes on the outer board wrapper. */
  className?: string

  /**
   * The drop handler handed to each column — React's `(column, e) => onDrop(…)`.
   *
   * @param column - The column dropped on.
   * @param event - The drop event.
   */
  readonly dropHandler = (column: KanbanColumnData, event: DragEvent): void => {
    this.onDrop(column, event)
  }

  /**
   * The drop handler the columns receive — present only when `onCardMove` is
   * supplied, matching React's `onDrop={onCardMove ? onDrop : undefined}`.
   *
   * @returns The drop handler, or undefined.
   */
  dropHandlerFor(): ((column: KanbanColumnData, event: DragEvent) => void) | undefined {
    return this.onCardMove ? this.dropHandler : undefined
  }

  /**
   * The card drag-start handler handed to each column.
   *
   * @param card - The dragged card.
   * @param column - The column it started from.
   * @param event - The drag start event.
   */
  readonly cardDragHandler = (
    card: KanbanCardData,
    column: KanbanColumnData,
    event: DragEvent,
  ): void => {
    this.onCardDragStart(card, column, event)
  }

  /**
   * The current class map.
   *
   * @returns The UIClassMap.
   */
  cm(): UIClassMap {
    return getClassMap()
  }

  /**
   * The board's class list.
   *
   * @returns The class string.
   */
  classes(): string {
    return this.cm().cn(this.cm().flex({ align: 'start', gap: 'md' }), this.className)
  }

  /**
   * The per-column wrapper's class list (`cm.flex1`).
   *
   * @returns The class string.
   */
  columnWrapperClasses(): string {
    return this.cm().cn(this.cm().flex1)
  }

  /**
   * Stores the card identity in the drag payload so the drop handler knows the
   * source column (the same JSON React writes).
   *
   * @param card - The dragged card.
   * @param column - The column it started from.
   * @param event - The drag start event.
   */
  onCardDragStart(card: KanbanCardData, column: KanbanColumnData, event: DragEvent): void {
    event.dataTransfer?.setData(
      'text/molecule-kanban',
      JSON.stringify({ cardId: card.id, fromColumnId: column.id }),
    )
    if (event.dataTransfer) event.dataTransfer.effectAllowed = 'move'
  }

  /**
   * Handles a card drop onto a column, parsing the drag payload and invoking
   * `onCardMove` when the card came from a different column.
   *
   * @param column - The column dropped on.
   * @param event - The drop event.
   */
  onDrop(column: KanbanColumnData, event: DragEvent): void {
    event.preventDefault()
    const payload = event.dataTransfer?.getData('text/molecule-kanban')
    if (!payload || !this.onCardMove) return
    try {
      const { cardId, fromColumnId } = JSON.parse(payload) as {
        cardId: string
        fromColumnId: string
      }
      if (fromColumnId !== column.id) this.onCardMove(cardId, fromColumnId, column.id)
    } catch (_error) {
      // Safe to ignore: the dataTransfer payload is untrusted/malformed, so the drop is cancelled.
    }
  }
}
```

#### `KanbanCard`

Single card inside a Kanban column.

The Angular counterpart of `@molecule/app-kanban-board-react`'s `KanbanCard`:
the same props (React names) and the same DOM for the same input. The host IS

  /**
   * The current class map.
   *
   * @returns The UIClassMap.
   */

    return getClassMap()
  }

  /**
   * Whether a drag-start handler was supplied — React adds the `draggable`
   * wrapper only then.
   *
   * @returns True when `onDragStart` is set.
   */

    return Boolean(this.onDragStart)
  }

   * component's `className`, in the same token order.
   *
   * @returns The class string.

      this.cm().card({ variant: 'elevated' }),
      this.cm().cardPadding('md'),
      this.cm().cn(this.cm().cursorPointer, this.className),
    )

   * The host's class list: the `Card` classes when the host IS the card, and
   * nothing when the host is the drag wrapper.
   *

   */

    return this.hasDragStart() ? null : this.cardClasses()

   * The card's title, as React reads `card.title`.

   * @returns The body, or undefined.

    return this.card?.body
  }

  /**
   * The card's footer, as React reads `card.footer`.
   *
   * @returns The footer, or undefined.
   */
  cardFooter(): string | number | TemplateRef<unknown> | undefined {
    return this.card?.footer
  }

  /**
   * The inner content's class list (`cm.stack(2)`).
   *
   * @returns The class string.
   */

    return this.cm().cn(this.cm().stack(2))
  }

  /**
   * The title's class list.
   *
   * @returns The class string.
   */

    return this.cm().cn(this.cm().textSize('sm'), this.cm().fontWeight('semibold'))
  }

  /**
   * The body's class list.
   *
   * @returns The class string.
   */
  bodyClasses(): string {
    return this.cm().cn(this.cm().textSize('sm'))
  }

  /**
   * The footer's class list.
   *
   * @returns The class string.
   */
  footerClasses(): string {
    return this.cm().cn(this.cm().flex({ align: 'center', gap: 'sm' }))
  }

  /**
   * Calls the card's click handler with the card, as React's `Card` onClick does.
   */

    if (this.card) this.onClick?.(this.card)
  }

  /**
   * The host's click: it is the card only when no drag wrapper is rendered —
   * otherwise the inner div owns the click, as in React.

   * @param event - The drag start event.
   */
  readonly cardDragHandler = (card: KanbanCardData, event: DragEvent): void => {
    if (this.column) this.onCardDragStart?.(card, this.column, event)
  }

  /**
   * The card click handler the cards receive — present only when `onCardClick`
   * is supplied, matching React's conditional prop.
   *
   * @returns The handler, or undefined.
   */
  cardClickFor(): ((card: KanbanCardData) => void) | undefined {
    return this.onCardClick ? this.cardClickHandler : undefined
  }

  /**
   * The card drag-start handler the cards receive — present only when
   * `onCardDragStart` is supplied.
   *
   * @returns The handler, or undefined.
   */
  cardDragFor(): ((card: KanbanCardData, event: DragEvent) => void) | undefined {
    return this.onCardDragStart ? this.cardDragHandler : undefined
  }

  /**
   * The current class map.
   *
   * @returns The UIClassMap.
   */
  cm(): UIClassMap {
    return getClassMap()
  }

  /**
   * The section's class list.
   *
   * @returns The class string.
   */
  classes(): string {
    return this.cm().cn(this.cm().stack(2), this.className)
  }

  /**
   * The card list's class list.
   *
   * @returns The class string.
   */
  cardsClasses(): string {
    return this.cm().cn(this.cm().stack(2))
  }

  /**
   * The column's heading, as React passes `column.title`.
   *
   * @returns The heading, or undefined before a column is bound.
   */
  columnTitle(): string | number | TemplateRef<unknown> | undefined {
    return this.column?.title
  }

  /**
   * The column's cards, in display order.
   *
   * @returns The cards.
   */
  cards(): KanbanCardData[] {
    return this.column?.cards ?? []
  }

  /**
   * The card count the header shows (React passes `column.cards.length`).
   *
   * @returns The count, or undefined before a column is bound.
   */
  cardCount(): number | undefined {
    return this.column?.cards.length
  }

  /**
   * The outlet context for the header actions and the footer — `{ a0: column }`,
   * the argument React passes to `renderHeaderActions` / `renderFooter`.
   *
   * @returns The outlet context.
   */
  headerContext(): Record<string, unknown> {
    return { a0: this.column }
  }

  /**
   * Handles a drag over the column: React prevents the default only when a drop
   * handler is supplied.
   *
   * @param event - The drag over event.
   */
  handleDragOver(event: DragEvent): void {
    if (!this.onDrop) return
    event.preventDefault()
  }

  /**
   * Handles a drop on the column, reporting the column to `onDrop` — React's own
   * handler does not prevent the default; the consumer decides.
   *
   * @param event - The drop event.
   */
  handleDrop(event: DragEvent): void {
    if (!this.onDrop || !this.column) return
    this.onDrop(this.column, event)
  }
}

### Runtime Dependencies

- `@angular/common`
- `@angular/core`
- `@angular/platform-browser`
- `@molecule/app-angular`
- `@molecule/app-ui`
- `@molecule/app-ui-angular`

- Drag-drop is native HTML5 DnD: it does not fire on touch devices — provide
  an alternate affordance (e.g. a move menu in `renderHeaderActions`) for mobile.
- `onCardMove` fires only when a card is dropped on a DIFFERENT column, and no
  insertion index is reported — same-column reordering is not supported; movers
  can only append to the target column.
- Consumers own the data: update your `columns` state in `onCardMove` or the
  board will snap back on re-render.
- `accent` on a column is currently cosmetic metadata only.
- Node props are template references or projected content: the column heading
  and actions accept `[slot=title]` / `[slot=actions]`, the column accepts
  `[slot=headerActions]` / `[slot=footer]`.
- Styling resolves through `getClassMap()`; `<KanbanCard>` renders React's
  `Card` classes itself — wire a ClassMap bond first.
