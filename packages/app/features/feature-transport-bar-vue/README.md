# @molecule/app-feature-transport-bar-vue

Vue transport bar — play / pause / stop / record / skip / loop controls
for editor playback (music DAW, video editor, animation tool).

Exports `<TransportBar>`. All styling routes through `getClassMap()`
and all button labels translate via the companion
`@molecule/app-locales-feature-transport-bar` locale bond. It is the Vue
counterpart of `@molecule/app-feature-transport-bar-react`: the same props,
the same DOM for the same input, and the same callbacks.

## Quick Start

```ts
import { createApp, defineComponent, h, ref } from 'vue'
import { TransportBar } from '@molecule/app-feature-transport-bar-vue'

const Editor = defineComponent({
  setup() {
    const playing = ref(false)
    const recording = ref(false)
    const loop = ref(false)
    return () =>
      h(TransportBar, {
        isPlaying: playing.value,
        isRecording: recording.value,
        loop: loop.value,
        onPlayToggle: () => (playing.value = !playing.value),
        onStop: () => (playing.value = false),
        onRecordToggle: () => (recording.value = !recording.value),
        onLoopToggle: () => (loop.value = !loop.value),
        timeDisplay: '0:42 / 3:10',
      })
  },
})

createApp(Editor).mount('#app')
```

### Constants

#### `TransportBar`

Transport-control bar (play / pause / stop / record / skip / loop)
used by music-daw + video-editor surfaces for editor playback
control. Renders a horizontal bar of buttons with semantic icons and
fully translated `aria-label`s; an optional time-display slot lets
callers render the current playhead position / total duration without
coupling the bar to any specific time-format library.

Vue counterpart of `@molecule/app-feature-transport-bar-react`'s
`TransportBar` — the same props (React names), the same DOM for the same
input, and the same callbacks. Node-valued props (`timeDisplay`) arrive as
a prop AND a same-named slot; `children` is the default slot.
