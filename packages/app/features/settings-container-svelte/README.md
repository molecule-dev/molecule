# @molecule/app-settings-container-svelte

Svelte Settings-page scaffold (layout chrome only) — the Svelte counterpart
of `@molecule/app-settings-container-react`, with the same props and the
same DOM for the same input.

Exports:

- `SettingsLayout` — two-column [sidebar, content] with an optional `header`
  slot rendered above both.
- `SettingsSidebar` — controlled side-nav (`items`, `activeId`, `onSelect`,
  optional `footer`); `SettingsSidebarItem` is `{ id, label, icon? }`.
- `SettingsContent` — stacked wrapper for the right column.
- `SettingsSection` — Card-wrapped titled section (`title`, `description?`,

## Quick Start

```svelte
<script lang="ts">
  import {
    SettingsContent,
    SettingsLayout,
    SettingsSection,
    SettingsSidebar,
  } from '@molecule/app-settings-container-svelte'

  const NAV = [
    { id: 'profile', label: 'Profile' },
    { id: 'notifications', label: 'Notifications' },
  ]

  let active = $state('profile')
</script>

<SettingsLayout>
  {#snippet header()}
    <h1>Settings</h1>
  {/snippet}
  {#snippet sidebar()}
    <SettingsSidebar items={NAV} activeId={active} onSelect={(id) => (active = id)} />
  {/snippet}
  <SettingsContent>
    <SettingsSection title="Profile" description="Update your display name and avatar.">
      <p>Form fields go here.</p>
    </SettingsSection>
  </SettingsContent>
</SettingsLayout>
```

### Runtime Dependencies

- `@molecule/app-svelte`
- `@molecule/app-ui`
- `@molecule/app-ui-svelte`
- `svelte`

- The `header` snippet is rendered above the columns but is NOT sticky —
  apply your own sticky positioning if you need it pinned.
- The two columns do not collapse responsively — swap the sidebar for a
  drawer on small screens yourself.
- Requires a bonded ClassMap. Labels are your own snippets or text
  (translate upstream); the sidebar nav's `aria-label="Settings"` is
  hardcoded English.
- Don't confuse with `@molecule/app-settings-panel-svelte`: that package is
  the batteries-included panel (prebuilt Account/Auth/Billing/… sections
  wired to molecule APIs). THIS package is empty layout chrome for building
  your own settings pages.
