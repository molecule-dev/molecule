# @molecule/app-carousel-svelte

## 2.0.0

### Major Changes

- `Carousel` now takes the slides as data in `items` and renders one entry through its `children` snippet, so a slide inserted, removed or reordered by the caller keeps its own wrapper.

## 1.1.0

### Minor Changes

- Add the Vue, Solid, Svelte and Angular counterparts of `@molecule/app-carousel-react`: the same exports and props, rendering the same DOM.
