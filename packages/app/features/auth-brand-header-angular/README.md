# @molecule/app-auth-brand-header-angular

Angular auth-page brand header.

Exports `<AuthBrandHeader>` — a centered wrapper holding a gradient
material-symbol chip + wordmark + tagline, with the sub-components
`<AuthBrandHeaderChip>`, `<AuthBrandHeaderWordmark>` and
`<AuthBrandHeaderTagline>` exported alongside it. It is the Angular
counterpart of `@molecule/app-auth-brand-header-react`: same props and the
same DOM for the same input.

Two modes: preset (pass `appName` / `tagline` / `icon` and the default chip +
wordmark + tagline render) or composed (project content built from the
exported sub-components — the preset props are then ignored).

#### `AuthBrandHeaderChip`

The host IS the outer `<div>` (`div[mol-auth-brand-header-chip]`), matching

```typescript
@Component({
  selector: 'div[mol-auth-brand-header-chip]',
  standalone: true,
  inputs: ['icon', 'chipGradient', 'chipShape'],
  host: {
    '[class]': 'classes()',
    '[style.background]': 'background()',
  },
  template:
    '<span [class]="iconClasses()" style="font-variation-settings: \'FILL\' 1" aria-hidden="true">{{ icon }}</span>',
})
export class AuthBrandHeaderChip {
  /** Material-symbol icon name shown inside the chip. */
  icon?: string
  /** CSS background value for the chip (a `linear-gradient(...)` or any CSS background). */
  chipGradient?: string
  /** Chip corner shape; defaults to `'round'` at read time. */
  chipShape?: 'round' | 'square'

  /**
   * The current class map.
   * @returns The UIClassMap.
   */
  cm(): UIClassMap {
    return getClassMap()
  }

  /**
   * The chip's corner shape (React's default parameter: a later-bound write of
   * `undefined` must not erase the `'round'` default).
   * @returns The shape.
   */
  shape(): 'round' | 'square' {
    return this.chipShape ?? 'round'
  }

  /**
   * The chip wrapper's class list.
   * @returns The class string.
   */
  classes(): string {
    const cm = this.cm()
    return cm.cn(
      cm.w(12),
      cm.h(12),
      this.shape() === 'round' ? cm.roundedFull : '',
      cm.flex({ align: 'center', justify: 'center' }),
      cm.sp('mb', 2),
      this.shape() === 'square' ? cm.authBrandHeaderChipSquare : '',
      this.chipGradient ? '' : cm.bgPrimary,
      cm.authBrandHeaderChipShadow,
    )
  }

  /**
   * The inline background, applied only when the caller supplied a gradient so
   * the ClassMap's `bg-primary` fallback stays visible otherwise.
   * @returns The background, or null for none.
   */
  background(): string | null {
    return this.chipGradient || null
  }

  /**
   * The glyph `<span>`'s class list.
   * @returns The class string.
   */
  iconClasses(): string {
    const cm = this.cm()
    return cm.cn(cm.textSize('3xl'), cm.iconGlyphFont, cm.authBrandHeaderChipIcon)
  }
}
```

#### `AuthBrandHeader`

Centered auth-page brand header supporting both composable content and
preset mode.

The host IS the outer `<div>` (`div[mol-auth-brand-header]`), matching
React's root exactly — a `<div>`, not `<header>`, because several hosts
render their own top bar on auth screens and a second `<header>` reads as a
duplicated app bar. Projected content renders in place of the preset, the
way React's `children` replaces its preset fragment.

```typescript
@Component({
  selector: 'div[mol-auth-brand-header]',
  standalone: true,
  imports: [AuthBrandHeaderChip, AuthBrandHeaderTagline, AuthBrandHeaderWordmark],
  inputs: ['className', 'appName', 'tagline', 'icon', 'chipGradient', 'chipShape', 'wordmarkColor'],
  host: {
    '[class]': 'classes()',
  },
  template: `<ng-content>
    @if (icon) {
      <div
        mol-auth-brand-header-chip
        [icon]="icon"
        [chipGradient]="chipGradient"
        [chipShape]="chipShape"
      ></div>
    }
    <h1 mol-auth-brand-header-wordmark [color]="wordmarkColor">{{ appNameText() }}</h1>
    <p mol-auth-brand-header-tagline>{{ taglineText() }}</p>
  </ng-content>`,
})
export class AuthBrandHeader {
  /** Extra classes appended to the wrapper `<div>`. */
  className?: string
  /** Brand name for the default wordmark. */
  appName?: string
  /** Tagline for the default tagline line. */
  tagline?: string
  /** Material-symbol icon name for the default chip (omit for no chip). */
  icon?: string
  /** CSS background for the default chip. */
  chipGradient?: string
  /** Default chip corner shape. */
  chipShape?: 'round' | 'square'
  /** Inline color for the default wordmark `<h1>`. */
  wordmarkColor?: string

  /**
   * i18n state. Its `t` reads the locale notifications, so the view refreshes
   * the text on a locale switch the way React re-renders on one.
   */
  readonly i18n = useTranslation()

  /**
   * The current class map.
   * @returns The UIClassMap.
   */
  cm(): UIClassMap {
    return getClassMap()
  }

  /**
   * The wrapper `<div>`'s class list.
   * @returns The class string.
   */
  classes(): string {
    const cm = this.cm()
    return cm.cn(cm.flex({ direction: 'col', align: 'center', gap: 'sm' }), this.className)
  }

  /**
   * The preset wordmark text.
   * @returns The translated brand name.
   */
  appNameText(): string {
    return this.i18n.t(
      'authBrandHeader.appName',
      { appName: this.appName ?? '' },
      { defaultValue: '{{appName}}' },
    )
  }

  /**
   * The preset tagline text.
   * @returns The translated tagline.
   */
  taglineText(): string {
    return this.i18n.t(
      'authBrandHeader.tagline',
      { tagline: this.tagline ?? '' },
      { defaultValue: '{{tagline}}' },
    )
  }
}
```

`icon` is a Material Symbols name rendered with the
`material-symbols-outlined` icon font — the app must load that font
(molecule scaffolds do; a custom stack must add it) or the icon name
renders as literal text. Omit `icon` to skip the chip entirely. The default
chip/wordmark treatment uses Tailwind theme tokens (`bg-primary`,
`text-on-surface`) from the wired ClassMap bond — with a non-Tailwind
ClassMap, pass `chipGradient` / `wordmarkColor` / `className` explicitly.
Requires the binding's i18n (`provideI18n` or `provideMolecule`) for
`useTranslation()`.
