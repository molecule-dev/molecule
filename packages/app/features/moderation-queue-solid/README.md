# @molecule/app-moderation-queue-solid

Solid moderation queue UI.

Exports `ModerationQueue` — a list of flagged items with kind icon, content
preview, reason chip, severity color, per-row action buttons (approve /
reject / escalate / mute), and a bulk-select toolbar (select-all checkbox +
apply-to-selected action buttons). It is the Solid counterpart of
`@molecule/app-moderation-queue-react`: same props (React names), same DOM
for the same input.

All user-visible text is i18n'd via the companion locale bond
`@molecule/app-locales-moderation-queue`.

#### `ModerationQueue(props)`

Moderation queue — a list of flagged items with kind icon, content preview,
reason chip, severity color, per-row action buttons (approve / reject /
escalate / mute), and a bulk-select toolbar (select-all checkbox +
apply-to-selected action buttons).

React keys each row by `item.id`, so a re-ordered or re-passed array
moves/keeps the rendered row. Solid's `For` keys by reference, so rows are
keyed through stable per-id records: the record for an id is created once
and reused, while the row reads the CURRENT item for its id reactively.

All user-visible text comes from i18n keys in
`@molecule/app-locales-moderation-queue`. Styling is driven exclusively
through `getClassMap()`.
