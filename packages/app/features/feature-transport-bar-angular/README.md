# @molecule/app-feature-transport-bar-angular

Angular transport bar — play / pause / stop / record / skip / loop controls
for editor playback (music DAW, video editor, animation tool).

Exports `<div mol-transport-bar>` (`TransportBar`). All styling routes
through `getClassMap()` and all button labels translate via the companion
`@molecule/app-locales-feature-transport-bar` locale bond. It is the Angular
counterpart of `@molecule/app-feature-transport-bar-react`: the same props,
the same DOM for the same input, and the same callbacks.

```ts
import { Component } from '@angular/core'
import { TransportBar } from '@molecule/app-feature-transport-bar-angular'

@Component({
  selector: 'app-editor-transport',

      [loop]="loop"

      [onStop]="stop"
      [onRecordToggle]="toggleRecord"
      [onLoopToggle]="toggleLoop"
      timeDisplay="0:42 / 3:10"

export class EditorTransport {
  playing = false
  recording = false
  loop = false
  togglePlay(): void {
    this.playing = !this.playing
  }
  stop(): void {
    this.playing = false
  }
  toggleRecord(): void {
    this.recording = !this.recording
  }
  toggleLoop(): void {
    this.loop = !this.loop
  }
}
```

### Classes

#### `TransportBar`

Transport-control bar (play / pause / stop / record / skip / loop) used by
music-daw + video-editor surfaces for editor playback control. Renders a
horizontal bar of buttons with semantic icons and fully translated
`aria-label`s; an optional time-display slot lets callers render the current
playhead position / total duration without coupling the bar to any specific
time-format library.

The host IS the outer `<div>` (`div[mol-transport-bar]`), matching React's
root exactly. Every button renders only while React would render it (a
missing handler renders no button, `canStop` / `canSkip` only disable one),
and the time-display wrapper renders only while React's `{slot && …}` would
render it — the Angular projection capture points must stay mounted, so
presence is read in {@link TransportBar.ngAfterViewInit} and the wrapper is
detached through {@link SlotWrapper} instead.
