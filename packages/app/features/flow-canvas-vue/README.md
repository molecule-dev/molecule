## Quick Start

```ts
import { createApp, defineComponent, h, ref } from 'vue'
import { FlowCanvas, type FlowEdge, type FlowNode } from '@molecule/app-flow-canvas-vue'

const Builder = defineComponent({
  setup() {
    const nodes = ref<FlowNode[]>([
      { id: 'a', type: 'task', position: { x: 40, y: 40 }, data: { label: 'Start' } },
    ])
    const edges = ref<FlowEdge[]>([])
    return () =>
      h(FlowCanvas, {
        nodes: nodes.value,
        edges: edges.value,
        onChange: ({ nodes: n, edges: e }) => {
          nodes.value = n
          edges.value = e
        },
        nodeRenderers: {
          task: (node) => h('strong', String((node.data as { label: string }).label)),
        },
      })
  },
})

createApp(Builder).mount('#app')
```

### Constants

#### `FlowCanvas`

Visual flow / DAG editor.

Renders nodes as absolutely-positioned `<div>` slots and edges as a single
`<svg>` overlay containing one `<path>` per edge. Built-in interactions:

- **Drag a node** — press on a node body and drag to reposition.
- **Pan the canvas** — press on empty space and drag.
- **Zoom** — mouse-wheel scroll (anchored on the cursor).
- **Connect ports** — press on a source handle (right edge of a node) and
  drag onto another node to create an edge.
- **Select** — click a node or edge, or Tab to a node's select button and
  press Enter / Space; Backspace / Delete removes everything in the
  selection.

Style is driven entirely by `getClassMap()`. Inline styles are reserved for
geometry — node `transform: translate(...)`, viewport pan/zoom, SVG
attributes — which classes can't express.

- `@molecule/app-vue`
- `vue`

The canvas fills 100% of its parent — give the PARENT an explicit height
(fixed-height panel, flex/grid track) or the canvas renders zero-tall and
appears blank.

Passing `onChange` puts the canvas in controlled mode: built-in edits (node
drag, connect, Backspace/Delete) call `onChange` with the full next
`{ nodes, edges }` and the caller re-renders with them. Without `onChange`
the canvas manages internal copies and `nodes` / `edges` act as initial
values only.

Fallback content for nodes without a renderer is the DEFAULT slot (or the
`children` prop); every node renders its own copy of it.
