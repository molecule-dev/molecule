# @molecule/app-chart-wrapper-angular

Angular `ChartCard` + `ChartLegend` wrappers around `@molecule/app-charts` —
the counterpart of `@molecule/app-chart-wrapper-react`: the same props and
the same DOM for the same input.

Exports:

- `<ChartCard>` — uniform chrome (title / description / actions / summary /
  body / footer) around a chart rendering. `minChartHeight` (default 240)
  stops responsive charts collapsing; `dataMolId` sets `data-mol-id`.
- `<ChartLegend>` — swatch + label (+ value) legend. Items become toggle
  buttons when `onToggle` is provided.
- `ChartLegendItem` type.

These wrappers provide ONLY the surrounding chrome. The chart itself is
whatever you project as the card's default content — typically a canvas
driven by `createLineChart`/`createBarChart` from `@molecule/app-charts`
(via a real bonded ChartProvider) or your own chart component. There is no
`<BarChart>` component in `@molecule/app-charts`.

## Quick Start

```ts
import { Component } from '@angular/core'
import { ChartCard, ChartLegend } from '@molecule/app-chart-wrapper-angular'

@Component({
  selector: 'app-revenue-chart',
  standalone: true,
  imports: [ChartCard, ChartLegend],
  template: `
    <div mol-chart-card [minChartHeight]="240">
      <h3 slot="title">Monthly Revenue</h3>
      <p slot="description">Last 12 months</p>
      <canvas #canvas height="240"></canvas>
      <div slot="footer">
        <div mol-chart-legend [items]="items" (onToggle)="toggle($event)"></div>
      </div>
    </div>
  `,
})
export class RevenueChart {}
```

#### `ChartCard`

ChartCard component.

Uniform chrome around a chart rendering — header + actions + optional
summary strip + chart body + optional footer. The host IS the Card `div`
(`div[mol-chart-card]`), matching React's root exactly: React renders
`<Card className data-mol-id>` whose Card defaults are variant `elevated`
and padding `md`, so the host wears that same class list. The regions'
content is projected content (`[slot=title]`, `[slot=description]`,
`[slot=actions]`, `[slot=summary]`, `[slot=footer]`, and the default slot).

This is the Angular counterpart of `@molecule/app-chart-wrapper-react`.

#### `ChartLegend`

ChartLegend component.

Swatch + label (+ optional value) per series. When `onToggle` is provided,
items become buttons that toggle series visibility. The host IS the legend
`div` (`div[mol-chart-legend]`), matching React's root exactly.

This is the Angular counterpart of `@molecule/app-chart-wrapper-react`.

```typescript
@Component({
  selector: 'div[mol-chart-legend]',
  standalone: true,
  imports: [NgTemplateOutlet],
  inputs: ['items', 'onToggle', 'layout', 'className'],
  host: {
    '[class]': 'classes()',
  },
  // prettier-ignore
  template: `<ng-template #row let-item><span [class]="contentClasses()"><span aria-hidden="true" [style]="swatchStyle(item)"></span><span [class]="labelClasses(item)" [style]="item.hidden ? 'opacity: 0.5' : null">@if (isNode(item.label)) {<ng-container [ngTemplateOutlet]="templateOf(item.label)"></ng-container>}@else {{{ textOf(item.label) }}}</span>@if (item.value !== undefined) {<span [class]="valueClasses()">@if (isNode(item.value)) {<ng-container [ngTemplateOutlet]="templateOf(item.value)"></ng-container>}@else {{{ textOf(item.value) }}}</span>}</span></ng-template>@for (item of items; track item.id) {@if (hasToggle()) {<button type="button" (click)="toggle(item.id)" [attr.aria-pressed]="!item.hidden"><ng-container [ngTemplateOutlet]="row" [ngTemplateOutletContext]="{$implicit: item}"></ng-container></button>}@else {<span><ng-container [ngTemplateOutlet]="row" [ngTemplateOutletContext]="{$implicit: item}"></ng-container></span>}}`,
})
export class ChartLegend {
  /** The legend's series. */
  items: ChartLegendProps['items'] = []
  /** Called when an item is toggled; when absent, items are plain spans. */
  onToggle?: (id: string) => void
  /** Layout direction. Defaults to `'horizontal'`. */
  layout?: 'horizontal' | 'vertical'
  /** Extra classes. */
  className?: string

  /**
   * The current class map.
   * @returns The UIClassMap.
   */
  cm(): UIClassMap {
    return getClassMap()
  }

  /**
   * Whether the items render as toggle buttons (React's `onToggle` presence).
   * @returns True when `onToggle` is set.
   */
  hasToggle(): boolean {
    return typeof this.onToggle === 'function'
  }

  /**
   * Calls `onToggle` for the clicked series.
   * @param id - The series id.
   */
  toggle(id: string): void {
    this.onToggle?.(id)
  }

  /**
   * Whether an item field is projected markup rather than plain text.
   * @param value - The field value.
   * @returns True for a template reference.
   */
  isNode(value: unknown): value is TemplateRef<unknown> {
    return value instanceof TemplateRef
  }

  /**
   * Narrows an item field to its template reference.
   * @param value - The field value.
   * @returns The template reference, or null for plain text.
   */
  templateOf(value: unknown): TemplateRef<unknown> | null {
    return value instanceof TemplateRef ? value : null
  }

  /**
   * Renders an item field as plain text.
   * @param value - The field value.
   * @returns The text.
   */
  textOf(value: unknown): string {
    return value === undefined || value === null ? '' : String(value)
  }

  /**
   * The legend's class list (React's flex classes plus `className`).
   * @returns The class string.
   */
  classes(): string {
    const cm = this.cm()
    return cm.cn(
      cm.flex({
        direction: this.layout === 'vertical' ? 'col' : 'row',
        align: 'center',
        gap: 'md',
        wrap: 'wrap',
      }),
      this.className,
    )
  }

  /**
   * The item content row class (`cm.flex({ align: 'center', gap: 'xs' })`).
   * @returns The class string.
   */
  contentClasses(): string {
    return this.cm().flex({ align: 'center', gap: 'xs' })
  }

  /**
   * The label class (React's `cm.textSize('sm')`, repeated when hidden).
   * @param item - The series entry.
   * @returns The class string.
   */
  labelClasses(item: ChartLegendItem): string {
    return this.cm().cn(
      this.cm().textSize('sm'),
      item.hidden ? this.cm().textSize('sm') : undefined,
    )
  }

  /**
   * The value class (`cm.textSize('sm')`).
   * @returns The class string.
   */
  valueClasses(): string {
    return this.cm().textSize('sm')
  }

  /**
   * The swatch's inline style (React's object).
   * @param item - The series entry.
   * @returns The style attribute text.
   */
  swatchStyle(item: ChartLegendItem): string {
    return (
      styleText({
        display: 'inline-block',
        width: 10,
        height: 10,
        borderRadius: 2,
        background: item.color,
        opacity: item.hidden ? 0.3 : 1,
      }) ?? ''
    )
  }
}
```

`@molecule/app-charts`' built-in provider renders a non-functional placeholder
notice (and logs a one-time console warning), not a real chart. Bond the
Chart.js provider once at startup — `import { provider } from
'@molecule/app-charts-chartjs'; setProvider(provider)` — so `createChart` /
`createBarChart` draw real charts (or render your own chart component as the
default content). Legend `items` labels/values are plain text or projected
template references; pass translated strings via `t()`.
Node props are projected content: `title`, `description`, `actions`,
`summary` and `footer` are selected by `[slot=<name>]`, everything else lands
in the chart body as the default projection.
