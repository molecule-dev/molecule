# @molecule/app-audio-player-angular

Angular HTML5 audio player chrome — play/pause, scrub bar, elapsed/total
time, and a mute toggle, over a hidden `<audio>` element. Use for podcasts,
voice notes, music previews, narrated lessons.

Exports `<AudioPlayer>` — the Angular counterpart of
`@molecule/app-audio-player-react`: the same props (React names) and the
same DOM for the same input.

## API

### Interfaces

#### `AudioPlayerProps`

Props accepted by {@link AudioPlayer} — the same props
`@molecule/app-audio-player-react` accepts. Node props (`title`, `subtitle`,
`visualizer`) are projected content in Angular (an input cannot carry a
node), so they are typed `unknown`: pass them in the host template as
`[slot=title]` / `[slot=subtitle]` / `[slot=visualizer]` content, or a plain
string as the input.

### Classes

#### `AudioPlayer`

HTML5 audio player chrome — play/pause, scrub, time, mute, optional
visualizer slot.

The host IS the outer `<div>` (`div[mol-audio-player]`), matching React's
root exactly, so the wrapper's ClassMap classes are the host's. The
`<audio>` element, the optional title / subtitle header, the visualizer and
the controls row render inside it, in React's order.

Angular projection needs always-mounted `<ng-content>` capture points, so
the header (and each of its spans) and the visualizer wrapper live in the
template unconditionally and {@link AudioPlayer.ngDoCheck} reconciles them
against React's DOM — React omits the header when neither title nor subtitle
renders, and renders the visualizer bare, without a wrapper element.

  ngOnInit(): void {
    this.playing = !!this.autoPlay
    this.muted = !!this.defaultMuted
  }

  ngOnChanges(changes: SimpleChanges): void {
    if (!this.viewReady || !('captions' in changes)) return
    this.dropCaptions()
    this.syncCaptions()

  ngAfterViewInit(): void {
    const audio = this.audioRef?.nativeElement
    if (audio) {
      const onTimeUpdate = (): void => {
        this.current = audio.currentTime
        this.cd.markForCheck()

      const onLoadedMetadata = (): void => {
        this.duration = audio.duration
        this.cd.markForCheck()
      }
      const onPlayEvent = (): void => {
        this.playing = true
        this.onPlay?.()
        this.cd.markForCheck()
      }
      const onPauseEvent = (): void => {
        this.playing = false
        this.onPause?.()
        this.cd.markForCheck()
      }
      const onEndedEvent = (): void => {
        this.playing = false
        this.onEnded?.()
        this.cd.markForCheck()
      }
      audio.addEventListener('timeupdate', onTimeUpdate)
      audio.addEventListener('loadedmetadata', onLoadedMetadata)
      audio.addEventListener('play', onPlayEvent)
      audio.addEventListener('pause', onPauseEvent)
      audio.addEventListener('ended', onEndedEvent)

        audio.removeEventListener('timeupdate', onTimeUpdate)
        audio.removeEventListener('loadedmetadata', onLoadedMetadata)
        audio.removeEventListener('play', onPlayEvent)
        audio.removeEventListener('pause', onPauseEvent)
        audio.removeEventListener('ended', onEndedEvent)
      })

    this.hasSubtitleSlot = hasProjectedNodes(
      this.subtitleSpanRef?.nativeElement,
      this.subtitleText(),

      this.visualizerSlotRef?.nativeElement,
      this.visualizerText(),
    )
    this.viewReady = true
    this.syncCaptions()
    this.reconcile()
  }

  }

There is NO volume slider — only a mute toggle; and no playback-rate
or skip controls. The optional `visualizer` is projected `[slot=visualizer]`
content rendered above the controls (bring your own waveform). `autoPlay` is
passed to the `<audio>` element and is routinely blocked by browsers until
user interaction — never rely on it. Duration renders `0:00` until
`loadedmetadata` fires (`preload="metadata"`). Translations come from the
companion `@molecule/app-locales-audio-player` locale bond. Node props
(`title`, `subtitle`, `visualizer`) are projected content: `[slot=title]`,
`[slot=subtitle]`, `[slot=visualizer]`.
