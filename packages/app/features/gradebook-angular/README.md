# @molecule/app-gradebook-angular

Angular gradebook UI — unified table of grades + optional GPA hero card.

Pairs with the `@molecule/api-resource-grade` resource. Rows can be courses
or assignments — the caller picks the granularity. The letter column renders
`Grade.letter` as plain text (string); pass pre-styled content via `title`
if you need richer cells.

This is the Angular counterpart of `@molecule/app-gradebook-react`: the same
exports, the same props (React names), and the same DOM for the same input,
so an app switches framework by changing only the package name in its
imports. Node-valued props are projected content (`[slot=<name>]`) or plain
text.

#### `GpaCard`

GpaCard component.

Hero card displaying the user's GPA — large primary value, "out of" caption,
and optional trend chip. The host IS the Card `div` (`div[mol-gpa-card]`),
matching React's root exactly: same classes, same region role, same aria
label. The `trendLabel` node prop is a text input or projected content
(`[slot=trendLabel]`). The label span stays in the template, so its
`<ng-content>` always captures, and leaves the page while it has nothing to
render, as React's `trendLabel && …` renders no span.

```typescript

  selector: 'div[mol-gpa-card]',
  standalone: true,
  inputs: ['gpa', 'scale', 'max', 'trend', 'trendLabel', 'className'],
  hostDirectives: [MolPlacement],
  host: {
    '[class]': 'classes()',
  },
  // prettier-ignore
  template: `<div [class]="innerClasses()" data-mol-id="gpa-card" role="region" [attr.aria-label]="titleText()"><span [class]="titleClasses()" data-mol-id="gpa-card-title">{{ titleText() }}</span><div [class]="valueRowClasses()"><span [class]="valueClasses()" data-mol-id="gpa-card-value">{{ formatted() }}</span><span [class]="outOfClasses()" data-mol-id="gpa-card-out-of">{{ outOfText() }}</span></div>@if (trendText()) {<div [class]="trendRowClasses()" data-mol-id="gpa-card-trend" [attr.data-trend]="trend"><span aria-hidden="true">{{ trendGlyph() }}</span><span [class]="smallClasses()" data-mol-id="gpa-card-trend-text">{{ trendText() }}</span><span #trendLabelWrap [class]="smallClasses()" data-mol-id="gpa-card-trend-label">@if (hasTrendLabelInput) {{{ trendLabel }}}<ng-content select="[slot=trendLabel]"></ng-content></span></div>}`,
})
export class GpaCard {
  /** The numeric GPA value (or percentage when `scale='percentage'`). */
  gpa = 0
  /** Which scale `gpa` is expressed on. */
  scale: GpaScale = '4.0'
  /** Override the maximum value shown in the "out of" caption. */
  max?: number
  /** Optional trend chip — render up/down/flat with localized label. */
  trend?: GpaTrend
  /** Optional caption below the trend: text, or `[slot=trendLabel]` content. */
  trendLabel?: GradeNode
  /** Extra classes merged onto the root element. */
  className?: string

  /** The trend-label span (always in the trend row; detached while it has nothing to render). */
  @ViewChild('trendLabelWrap') private trendLabelWrap?: ElementRef<HTMLElement>

  /** The i18n handle (locale-reactive), read in an injection context. */
  private readonly i18n = useTranslation()

  /**
   * Keeps the trend-label span on the page only while it renders a text input
   * or projected `[slot=trendLabel]` content, re-decided whenever either
   * changes (a label taken away and given back included).
   */
  constructor() {
    usePlacement((hasContent) => {
      const wrap = this.trendLabelWrap?.nativeElement
      setElementPresent(wrap, this.hasTrendLabelInput || (wrap ? hasContent(wrap) : false))
    })
  }

  /**
   * Whether a text trend-label input renders (React's truthiness test).
   * @returns True when the label input renders as text.
   */
  get hasTrendLabelInput(): boolean {
    return hasText(this.trendLabel)
  }

  /**
   * React's ceiling: an explicit positive `max`, otherwise the scale default.
   * @returns The maximum value shown in the "out of" caption.
   */
  ceiling(): number {
    return typeof this.max === 'number' && this.max > 0 ? this.max : defaultGpaMax(this.scale)
  }

  /**
   * The formatted GPA value.
   * @returns The formatted value.
   */
  formatted(): string {
    return formatGpa(this.gpa, this.scale)
  }

  /**
   * The translated title.
   * @returns The "GPA" label.
   */
  titleText(): string {
    return this.i18n.t('gradebook.gpa.title', {}, { defaultValue: 'GPA' })
  }

  /**
   * The translated "out of" caption with the formatted ceiling.
   * @returns The caption text.
   */
  outOfText(): string {
    return this.i18n.t(
      'gradebook.gpa.outOf',
      { max: formatGpa(this.ceiling(), this.scale) },
      { defaultValue: 'out of {{max}}' },
    )
  }

  /**
   * The translated trend label, or null when no known trend is set.
   * @returns The label text, or null.
   */
  trendText(): string | null {
    const key =
      this.trend === 'up'
        ? 'gradebook.gpa.trend.up'
        : this.trend === 'down'
          ? 'gradebook.gpa.trend.down'
          : this.trend === 'flat'
            ? 'gradebook.gpa.trend.flat'
            : null
    if (!key) return null
    const fallback =
      this.trend === 'up' ? 'Trending up' : this.trend === 'down' ? 'Trending down' : 'Steady'
    return this.i18n.t(key, {}, { defaultValue: fallback })
  }

  /**
   * The trend chip's glyph.
   * @returns The arrow for the current trend.
   */
  trendGlyph(): string {
    return this.trend === 'up' ? '↑' : this.trend === 'down' ? '↓' : '→'
  }

  /**
   * The current class map.
   * @returns The UIClassMap.
   */
  cm(): UIClassMap {
    return getClassMap()
  }

  /**
   * The host's class list (React's Card: elevated variant, default padding,
   * then `className`).
   * @returns The class string.
   */
  classes(): string {
    const cm = this.cm()
    return cm.cn(cm.card({ variant: 'elevated' }), cm.cardPadding('md'), this.className)
  }

  /**
   * The inner wrapper's class list (`cm.cn(cm.stack(2))`).
   * @returns The class string.
   */
  innerClasses(): string {
    return this.cm().cn(this.cm().stack(2))
  }

  /**
   * The title's class list (xs + semibold).
   * @returns The class string.
   */
  titleClasses(): string {
    const cm = this.cm()
    return cm.cn(cm.textSize('xs'), cm.fontWeight('semibold'))
  }

  /**
   * The value row's class list (`cm.flex({ align: 'baseline', gap: 'sm' })`).
   * @returns The class string.
   */
  valueRowClasses(): string {
    return this.cm().flex({ align: 'baseline', gap: 'sm' })
  }

  /**
   * The value's class list (3xl + bold).
   * @returns The class string.
   */
  valueClasses(): string {
    const cm = this.cm()
    return cm.cn(cm.textSize('3xl'), cm.fontWeight('bold'))
  }

  /**
   * The "out of" caption's class list (`cm.textSize('sm')`).
   * @returns The class string.
   */
  outOfClasses(): string {
    return this.cm().textSize('sm')
  }

  /**
   * The trend row's class list (`cm.flex({ align: 'center', gap: 'sm' })`).
   * @returns The class string.
   */
  trendRowClasses(): string {
    return this.cm().flex({ align: 'center', gap: 'sm' })
  }

  /**
   * The trend text / label's class list (`cm.textSize('xs')`).
   * @returns The class string.
   */
  smallClasses(): string {
    return this.cm().textSize('xs')
  }
}
```

#### `Gradebook`

Gradebook component.

Unified gradebook table — title, letter grade, numeric score, weight, and
contribution-to-GPA — with the em-dash placeholders, the empty state and the
per-cell click callback. The host IS React's root element
(`div[mol-gradebook]`), matching both of React's branches: the empty state's
classes, `data-mol-id` and child, or the table's. Node-valued row fields
(`title`, `postedAt`) are projected templates in Angular (an input cannot
carry a node), rendered through `ngTemplateOutlet`; plain text renders as
text.

```typescript
@Component({
  selector: 'div[mol-gradebook]',
  standalone: true,
  imports: [NgTemplateOutlet],
  inputs: ['grades', 'gpaScale', 'onCellClick', 'className'],
  host: {
    '[class]': 'classes()',
    '[attr.data-mol-id]': 'molId()',
    role: 'region',
    '[attr.aria-label]': 'regionLabel()',
  },
  // prettier-ignore
  template: `@if (grades.length === 0) {<span [class]="emptyTextClasses()">{{ emptyText() }}</span>} @else {<table [class]="tableClasses()" data-mol-id="gradebook-table"><thead><tr data-mol-id="gradebook-header-row">@for (header of headerCells(); track header.id) {<th scope="col" [class]="headerClasses()" [attr.data-mol-id]="header.id">{{ header.text }}</th>}</tr></thead><tbody>@for (grade of grades; track grade.id) {<tr data-mol-id="gradebook-row" [attr.data-row-id]="grade.id"><td [class]="cellClasses()" data-mol-id="gradebook-cell-title" (click)="cellClick(grade, 'title')">@if (isNode(grade.title)) {<ng-container [ngTemplateOutlet]="asTemplate(grade.title)"></ng-container>} @else {<ng-container>{{ text(grade.title) }}</ng-container>}</td><td [class]="cellClasses()" data-mol-id="gradebook-cell-letter" (click)="cellClick(grade, 'letter')">{{ grade.letter ?? '—' }}</td><td [class]="cellClasses()" data-mol-id="gradebook-cell-numeric" (click)="cellClick(grade, 'numeric')">{{ numericText(grade) }}</td><td [class]="cellClasses()" data-mol-id="gradebook-cell-weight" (click)="cellClick(grade, 'weight')">{{ weightText(grade) }}</td><td [class]="cellClasses()" data-mol-id="gradebook-cell-contribution" (click)="cellClick(grade, 'contribution')">{{ contributionText(grade) }}</td><td [class]="cellClasses()" data-mol-id="gradebook-cell-posted" (click)="cellClick(grade, 'posted')">@if (isNode(grade.postedAt)) {<ng-container [ngTemplateOutlet]="asTemplate(grade.postedAt)"></ng-container>} @else {<ng-container>{{ text(grade.postedAt ?? '—') }}</ng-container>}</td></tr>}</tbody></table>}`,
})
export class Gradebook {
  /** Rows to display (a course or an assignment per row — the caller's choice). */
  grades: Grade[] = []
  /** GPA scale used for numeric rendering of contribution / score columns. */
  gpaScale: GpaScale = '4.0'
  /** Optional cell-click handler — fires with the grade row + the column key clicked. */
  onCellClick?: (grade: Grade, column: GradebookColumn) => void
  /** Extra classes merged onto the root `<table>` wrapper. */
  className?: string

  /** The i18n handle (locale-reactive), read in an injection context. */
  private readonly i18n = useTranslation()

  /**
   * The current class map.
   * @returns The UIClassMap.
   */
  cm(): UIClassMap {
    return getClassMap()
  }

  /**
   * Whether the empty state renders (React's `grades.length === 0`).
   * @returns True when there are no rows.
   */
  get empty(): boolean {
    return this.grades.length === 0
  }

  /**
   * The host's class list: the empty branch's padding + `className`, or just
   * `className` for the table.
   * @returns The class string.
   */
  classes(): string {
    const cm = this.cm()
    return this.empty ? cm.cn(cm.sp('p', 4), this.className) : cm.cn(this.className)
  }

  /**
   * The host's `data-mol-id`, as React writes it per branch.
   * @returns `gradebook-empty` or `gradebook`.
   */
  molId(): string {
    return this.empty ? 'gradebook-empty' : 'gradebook'
  }

  /**
   * The translated region label (React's `gradebook.aria.region` key).
   * @returns The aria label.
   */
  regionLabel(): string {
    return this.i18n.t('gradebook.aria.region', {}, { defaultValue: 'Gradebook' })
  }

  /**
   * The translated empty-state text (React's `gradebook.empty` key).
   * @returns The empty-state label.
   */
  emptyText(): string {
    return this.i18n.t('gradebook.empty', {}, { defaultValue: 'No grades yet.' })
  }

  /**
   * The empty state's span class (`cm.textSize('sm')`).
   * @returns The class string.
   */
  emptyTextClasses(): string {
    return this.cm().textSize('sm')
  }

  /**
   * The table's class list (`cm.cn(cm.w('full'))`).
   * @returns The class string.
   */
  tableClasses(): string {
    return this.cm().cn(this.cm().w('full'))
  }

  /**
   * A header cell's class list (xs + semibold).
   * @returns The class string.
   */
  headerClasses(): string {
    const cm = this.cm()
    return cm.cn(cm.textSize('xs'), cm.fontWeight('semibold'))
  }

  /**
   * A body cell's class list (`cm.cn(cm.textSize('sm'))`).
   * @returns The class string.
   */
  cellClasses(): string {
    return this.cm().cn(this.cm().textSize('sm'))
  }

  /**
   * The six column headers, in React's order, with the scale-dependent numeric
   * label.
   * @returns The header cells.
   */
  headerCells(): HeaderCell[] {
    const t = this.i18n.t
    return [
      { id: 'gradebook-h-title', text: t('gradebook.col.title', {}, { defaultValue: 'Course' }) },
      { id: 'gradebook-h-letter', text: t('gradebook.col.letter', {}, { defaultValue: 'Letter' }) },
      {
        id: 'gradebook-h-numeric',
        text:
          this.gpaScale === 'percentage'
            ? t('gradebook.col.numericPct', {}, { defaultValue: 'Score (%)' })
            : t('gradebook.col.numeric', {}, { defaultValue: 'Score' }),
      },
      { id: 'gradebook-h-weight', text: t('gradebook.col.weight', {}, { defaultValue: 'Weight' }) },
      {
        id: 'gradebook-h-contribution',
        text: t('gradebook.col.contribution', {}, { defaultValue: 'GPA contribution' }),
      },
      { id: 'gradebook-h-posted', text: t('gradebook.col.posted', {}, { defaultValue: 'Posted' }) },
    ]
  }

  /**
   * Render a numeric percentage / score cell using the configured scale.
   *
   * @param grade - The grade row.
   * @returns The cell text.
   */
  numericText(grade: Grade): string {
    if (this.gpaScale === 'percentage') {
      return `${Math.round(computePercentage(grade))}%`
    }
    if (typeof grade.maxPoints === 'number' && grade.maxPoints > 0) {
      return `${grade.score} / ${grade.maxPoints}`
    }
    return String(grade.score)
  }

  /**
   * The weight cell's text (`25%`, or an em dash when absent).
   *
   * @param grade - The grade row.
   * @returns The cell text.
   */
  weightText(grade: Grade): string {
    return typeof grade.weight === 'number' ? `${Math.round(grade.weight * 100)}%` : '—'
  }

  /**
   * The contribution cell's text, formatted for the active scale.
   *
   * @param grade - The grade row.
   * @returns The cell text.
   */
  contributionText(grade: Grade): string {
    return typeof grade.contribution === 'number'
      ? formatGpa(grade.contribution, this.gpaScale)
      : '—'
  }

  /**
   * Calls the cell-click handler with the row and its column, as React does.
   *
   * @param grade - The grade row.
   * @param column - The column identifier.
   */
  cellClick(grade: Grade, column: GradebookColumn): void {
    this.onCellClick?.(grade, column)
  }

  /**
   * Whether a node-valued field arrived as a projected template.
   * @param value - The field value.
   * @returns True for a template.
   */
  isNode(value: unknown): value is TemplateRef<unknown> {
    return value instanceof TemplateRef
  }

  /**
   * A node-valued field as a template (the `@if` above already checked it).
   * @param value - The field value.
   * @returns The template, or null when it is not one.
   */
  asTemplate(value: unknown): TemplateRef<unknown> | null {
    return value instanceof TemplateRef ? value : null
  }

  /**
   * A node-valued field as display text.
   * @param value - The field value.
   * @returns Its text, or an empty string when absent.
   */
  text(value: unknown): string {
    return value === null || value === undefined ? '' : String(value)
  }
}
```

### Functions

#### `computePercentage(grade)`

Compute a percentage `[0, 100]` from a {@link Grade} row. When `maxPoints`
is missing or ≤ 0 the score is treated as already being a percentage.

```typescript
function computePercentage(grade: Grade): number
```

- `grade` — The grade row.

**Returns:** The percentage value clamped to `[0, 100]`.

#### `formatGpa(value, scale)`

Format a numeric GPA for display. Percentages render with no decimals;
4.0 / 5.0 scales render with two decimals.

```typescript
function formatGpa(value: number, scale: GpaScale): string
```

- `value` — The GPA / percentage value to format.
- `scale` — The scale being displayed.

**Returns:** A locale-independent string representation.

#### `defaultGpaMax(scale)`

Default ceiling for a given GPA scale.

```typescript
function defaultGpaMax(scale: GpaScale): number
```

- `scale` — The GPA scale.

**Returns:** The default maximum value for that scale.
