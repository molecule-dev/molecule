# @molecule/app-feature-chapter-list-solid

Solid chapter list — scrollable list of chapters with seek-to-on-click and a
progress highlight for the chapter the playhead is currently inside.

Used by podcast and video-streaming surfaces for in-episode chapter
navigation. It is the Solid counterpart of
`@molecule/app-feature-chapter-list-react`: the same exports, the same props
(React names) and the same DOM for the same input, so an app switches
framework by changing only the package name in its imports.

## Quick Start

```tsx
import { createSignal } from 'solid-js'

import { ChapterList } from '@molecule/app-feature-chapter-list-solid'

export function Player() {
  const [currentTime, setCurrentTime] = createSignal(150)
  return (
    <ChapterList
      chapters={[
        { id: 'c1', title: 'Intro', startTime: 0 },
        { id: 'c2', title: 'Topic A', startTime: 120, thumbnail: '/a.jpg' },
        { id: 'c3', title: 'Outro', startTime: 1800 },
      ]}
      currentTime={currentTime()}
      onSeek={(s) => setCurrentTime(s)}
    />
  )
}
```

#### `Chapter`

A single chapter entry inside an episode / video / podcast track.
`id` is used as the stable row key, `startTime` is in seconds and drives
both the displayed timestamp and the `currentTime`-based highlight.
`thumbnail` is an optional small image (square) shown to the left of the
title.

```typescript
interface ChapterListProps {
```

### Functions

#### `ChapterList(props)`

Scrollable list of chapters with seek-to-on-click and a progress
highlight for the chapter the playhead is currently inside. Used by
podcast and video-streaming surfaces for in-episode chapter
navigation. Each row shows an optional small thumbnail, the chapter
title, and the timestamp.

All styling routes through `getClassMap()` (no raw class names). All
user-visible text routes through `t()` so the list translates via the
companion `@molecule/app-locales-feature-chapter-list` locale bond.

React keys each row by the chapter's `id` value, so a re-passed or
re-ordered array keeps the rendered rows per id. Solid's `For` keys by
reference, so the rows are keyed through stable per-id records: the record
for an id is created once and reused, while each row's content reads the
CURRENT chapter for that id reactively.

```typescript
function ChapterList(props: ChapterListProps): JSX.Element
```

- `props` — Component props (see {@link ChapterListProps}).

**Returns:** The rendered chapter list.

#### `findActiveChapterIndex(chapters, currentTime)`

Find the index of the active chapter for a given `currentTime`.
Returns the index of the last chapter whose `startTime` is `<=
currentTime`. Returns `-1` when `chapters` is empty or `currentTime`
is before the first chapter.

```typescript
function findActiveChapterIndex(chapters: Chapter[], currentTime: number): number
```

- `chapters` — Chapters in start-time order.
- `currentTime` — Current playback time in seconds.

**Returns:** The active chapter index, or `-1`.
