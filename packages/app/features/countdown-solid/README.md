```tsx
import { Countdown } from '@molecule/app-countdown-solid'

export function Sale() {
  return (
    <Countdown
      // Compact default: "3d 4h 12m 5s"

  )
```

### Functions

#### `Countdown(props)`

Live countdown display with three default formats:

- `'compact'` — `3d 4h 12m 5s` (skips zero leading units)
- `'long'` — `3 days 4 hours 12 minutes 5 seconds`
- `'colon'` — `03:04:12:05`

Pass `render` for full control over markup. Once the target has passed and
an `expired` node was given, that node renders instead of the display.

```typescript
function Countdown(props: CountdownProps): JSX.Element
```

- `props` — Component props (see {@link CountdownProps}).

**Returns:** The rendered countdown.

#### `useCountdown(target, tickMs)`

Live-updating countdown to a target date, React's `useCountdown` in Solid's
idiom: the target and interval may each be a plain value or an accessor, and
the primitive follows a changed source on the same mount — a component
re-rendering with a new `target` prop behaves as React's hook does.

```typescript
function useCountdown(
  target: Date | string | number | Accessor<Date | string | number>,
  tickMs?: number | undefined | Accessor<number | undefined>,
): {
  /** Days remaining. */
  days: Accessor<number>
  /** Hours (0-23) within current day. */
  hours: Accessor<number>
  /** Minutes (0-59) within current hour. */
  minutes: Accessor<number>
  /** Seconds (0-59) within current minute. */
  seconds: Accessor<number>
  /** Total milliseconds remaining (negative if past). */
  msRemaining: Accessor<number>
  /** True once the target is in the past. */
  expired: Accessor<boolean>
}
```

- `target` — Date / ISO string / epoch ms.
- `tickMs` — Refresh interval. Defaults to `1000`; `0` or less disables it.

**Returns:** An accessor per live countdown field.

The built-in `'compact'` and `'long'` formats hardcode English unit labels
and pluralization ("3d 4h", "3 days 4 hours") — there is no locale bond.
For localized apps use the `render` prop with the `useCountdown` state and
compose translated units via `t()` (or `Intl.RelativeTimeFormat`). `expired`
only swaps the rendering once the target passes — schedule side effects
(redirects, refetches) from `useCountdown().expired` in an effect, not from
the component.
