# @molecule/app-canvas-engine-angular

`@molecule/app-canvas-engine-angular` — vector design-tool canvas
engine. Thin domain wrapper on top of
`@molecule/app-feature-canvas-angular` (peer dep) that adds:

- Vector primitives — `rect`, `ellipse`, `line`, `path`, `text`, `group`
- Style fields — fill, stroke, opacity, blend mode
- Multi-select — marquee selector + shift/meta/ctrl additive click
- Alignment — `align('left' | 'center' | 'right' | 'top' | 'middle' | 'bottom')`
- Distribution — `distribute('horizontal' | 'vertical')`
- Grouping — `group()` / `ungroup()`
- Snap-to-grid — pointer-coords are snapped to `gridSize` (default 8)
- Undo/redo — bounded stack (default 100 entries)

The engine never re-implements pan/zoom — that lives in the
`<CanvasSurface>` base.

Exports:

- `<CanvasEngine>` (`div[mol-canvas-engine]`) — main component + its inputs.
- `<VectorElementSvg>` (`g[mol-vector-element-svg]`) — pure-presentational

  component it is the instance `@ViewChild` hands back.

- `alignLayers`, `distributeLayers` — pure layer-list transforms.

#### `HistoryStack`

Bounded undo/redo pair backing undo/redo. State is intentionally
mutable so a component instance can hold one — every public method
either pushes/pops a snapshot or queries stack depth.

```typescript
class HistoryStack {
  private undoStack: HistoryEntry[] = []
  private redoStack: HistoryEntry[] = []
  private readonly limit: number

  /**
   * Create a new history stack with the given undo/redo entry cap.
   *
   * @param limit - Max number of undo entries kept. Defaults to 100.
   */
  constructor(limit: number = DEFAULT_HISTORY_LIMIT) {
    this.limit = Math.max(1, Math.floor(limit))
  }

  /**
   * Push a snapshot of the document _before_ a mutation. Clears the
   * redo stack — once you make a new edit, the redo path is gone.
   *
   * @param entry - Snapshot to record.
   */
  push(entry: HistoryEntry): void {
    this.undoStack.push(entry)
    if (this.undoStack.length > this.limit) {
      this.undoStack.splice(0, this.undoStack.length - this.limit)
    }
    this.redoStack = []
  }

  /**
   * Pop the latest undo entry; the caller passes the _current_ state
   * so it can be moved onto the redo stack.
   *
   * @param current - Current document, captured into redo.
   * @returns The previous document, or `null` when the stack is empty.
   */
  undo(current: HistoryEntry): HistoryEntry | null {
    const prev = this.undoStack.pop()
    if (!prev) return null
    this.redoStack.push(current)
    if (this.redoStack.length > this.limit) {
      this.redoStack.splice(0, this.redoStack.length - this.limit)
    }
    return prev
  }

  /**
   * Pop the latest redo entry; the caller passes the _current_ state
   * so it can be moved back onto the undo stack.
   *
   * @param current - Current document, captured into undo.
   * @returns The next document, or `null` when redo is empty.
   */
  redo(current: HistoryEntry): HistoryEntry | null {
    const next = this.redoStack.pop()
    if (!next) return null
    this.undoStack.push(current)
    if (this.undoStack.length > this.limit) {
      this.undoStack.splice(0, this.undoStack.length - this.limit)
    }
    return next
  }

  /** `true` when there is at least one undo entry. */
  canUndo(): boolean {
    return this.undoStack.length > 0
  }

  /** `true` when there is at least one redo entry. */
  canRedo(): boolean {
    return this.redoStack.length > 0
  }

  /** Drop every entry on both stacks. */
  clear(): void {
    this.undoStack = []
    this.redoStack = []
  }
}
```

export class VectorElementSvg {
  /** Element to draw. */
  element!: VectorElement
  /** Whether the element is currently selected (drives `data-selected`). */
  selected?: boolean

  /**
   * The element narrowed to a rect, for the template's branch.
   *
   * @returns The rect, or `undefined` for another kind.
   */
  asRect(): VectorRect | undefined {
    const element = this.element
    return element.kind === 'rect' ? element : undefined
  }

  /**
   * The element narrowed to an ellipse, for the template's branch.
   *
   * @returns The ellipse, or `undefined` for another kind.
   */
  asEllipse(): VectorEllipse | undefined {
    const element = this.element
    return element.kind === 'ellipse' ? element : undefined
  }

  /**
   * The element narrowed to a line, for the template's branch.
   *
   * @returns The line, or `undefined` for another kind.
   */
  asLine(): VectorLine | undefined {
    const element = this.element
    return element.kind === 'line' ? element : undefined
  }

  /**
   * The element narrowed to a path, for the template's branch.
   *
   * @returns The path, or `undefined` for another kind.
   */
  asPath(): VectorPath | undefined {
    const element = this.element
    return element.kind === 'path' ? element : undefined
  }

  /**
   * The element narrowed to text, for the template's branch.
   *
   * @returns The text element, or `undefined` for another kind.
   */
  asText(): VectorText | undefined {
    const element = this.element
    return element.kind === 'text' ? element : undefined
  }

  /**
   * The element narrowed to a group, for the template's branch.
   *
   * @returns The group, or `undefined` for another kind.
   */
  asGroup(): VectorGroup | undefined {
    const element = this.element
    return element.kind === 'group' ? element : undefined
  }

  /**
   * Fill paint (`none` when the element has no fill).
   *
   * @returns The fill value.
   */
  fill(): string {
    return this.element.fill ?? 'none'
  }

  /**
   * Stroke paint, or `null` when the element has none.
   *
   * @returns The stroke value or null.
   */
  stroke(): string | null {
    return this.element.stroke ?? null
  }

  /**
   * Stroke width, or `null` when the element has none.
   *
   * @returns The stroke width or null.
   */
  strokeWidth(): number | null {
    const stroke = this.element.stroke
    return stroke != null ? (this.element.strokeWidth ?? 1) : (this.element.strokeWidth ?? null)
  }

  /**
   * The element's `transform` attribute.
   *
   * @returns The transform string, or null.
   */
  transform(): string | null {
    return transformAttr(this.element)
  }

  /**
   * Inline style for opacity and blend mode, as React writes it.
   *
   * @returns The style text (possibly empty).
   */
  styleText(): string {
    const parts: string[] = []
    if (this.element.opacity != null) parts.push(`opacity: ${this.element.opacity}`)
    if (this.element.blendMode != null) parts.push(`mix-blend-mode: ${this.element.blendMode}`)
    return parts.join('; ')
  }
}

### Functions

#### `alignLayers(layers, selection, mode)`

Apply an alignment op to every selected layer, returning the new
layers array. Layers not in the selection are passed through.

```typescript
function alignLayers(
  layers: readonly VectorElement[],
  selection: CanvasSelection,
  mode: CanvasAlignment,
): VectorElement[]
```

- `layers` — Top-level layer list.
- `selection` — Ids of layers to operate on.
- `mode` — Alignment mode.

**Returns:** New layer list with aligned elements.

#### `distributeLayers(layers, selection, axis)`

Distribute three or more selected layers evenly across the given
axis between the outermost layers (which stay put). Returns a new
layer list. For fewer than three selected items the input is
returned unchanged.

```typescript
function distributeLayers(
  layers: readonly VectorElement[],
  selection: CanvasSelection,
  axis: CanvasDistribution,
): VectorElement[]
```

- `layers` — Top-level layer list.
- `selection` — Ids of layers to operate on.
- `axis` — Distribution axis.

**Returns:** New layer list with distributed elements.

#### `snapToGrid(value, gridSize)`

Snap a value to the nearest multiple of `gridSize`. When `gridSize`
is `<= 0` the input is returned unchanged so callers don't have to
branch on "snap disabled".

```typescript
function snapToGrid(value: number, gridSize: number): number
```

- `value` — Value to snap (canvas units).
- `gridSize` — Grid spacing in canvas units. `<= 0` disables snap.

**Returns:** The snapped value.

#### `elementBounds(element)`

Compute the axis-aligned bounding box of a single element. Lines
use their two endpoints; every other kind uses its `x/y/width/height`.

```typescript
function elementBounds(element: VectorElement): Bounds
```

- `element` — Element to measure.

**Returns:** Bounding box in canvas-space coordinates.

#### `unionBounds(a, b)`

Combine two bounding boxes into the smallest axis-aligned rect that
contains both. Useful for selection envelopes and group snapshots.

```typescript
function unionBounds(a: Bounds, b: Bounds): Bounds
```

- `a` — First bounding box.
- `b` — Second bounding box.

**Returns:** The union rectangle.

#### `combinedBounds(elements)`

Compute the bounding box that contains every element in the list.
Returns a zero-sized rect at the origin when `elements` is empty so
downstream code can blindly read the result.

```typescript
function combinedBounds(elements: readonly VectorElement[]): Bounds
```

- `elements` — Non-empty list of elements.

**Returns:** Combined bounding box.

#### `rectsIntersect(bounds, box)`

`true` when `bounds` and `box` overlap on both axes (touching edges
count as overlap). Used by the marquee selector.

```typescript
function rectsIntersect(bounds: Bounds, box: Bounds): boolean
```

- `bounds` — First rectangle.
- `box` — Second rectangle.

**Returns:** Whether the rects intersect.

#### `translateElement(element, dx, dy)`

Translate an element by `(dx, dy)` in canvas-space, returning a new
element. Group children are translated recursively so the group
stays internally consistent.

```typescript
function translateElement(element: VectorElement, dx: number, dy: number): VectorElement
```

- `element` — Source element.
- `dx` — X-axis displacement in canvas units.
- `dy` — Y-axis displacement in canvas units.

**Returns:** Translated element (new object).

#### `findElement(elements, id)`

Look up an element by id within a flat list. Returns `undefined`
when not found — callers decide whether that's an error.

```typescript
function findElement(
  elements: readonly VectorElement[],
  id: VectorElementId,
): VectorElement | undefined
```

- `elements` — Source list.
- `id` — Element id.

**Returns:** The matching element or `undefined`.
