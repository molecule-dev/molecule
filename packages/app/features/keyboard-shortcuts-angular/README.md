# @molecule/app-keyboard-shortcuts-angular

Angular functions for `@molecule/app-keyboard-shortcuts`.

{@link useKeyboardShortcut} registers a shortcut with the bonded provider
for the life of a component and always calls the latest handler, so a
component can bind `/` to focus its search box or `mod+k` to open a
palette in one line. It is the Angular counterpart of
`@molecule/app-keyboard-shortcuts-react`: same names, same options, same
provider calls.

## Quick Start

```typescript
import { Component, signal, viewChild } from '@angular/core'
import { useKeyboardShortcut } from '@molecule/app-keyboard-shortcuts-angular'
import { t } from '@molecule/app-i18n'

@Component({
  selector: 'app-search',
  template: '<input #input />',
})
export class Search {
  readonly input = viewChild.required<ElementRef<HTMLInputElement>>('input')

  // A field initializer runs in the injection context.
  readonly shortcuts = useKeyboardShortcut('/', () => this.input().nativeElement.focus(), {
    description: t('catalogSearch.focus', undefined, { defaultValue: 'Focus search' }),
  })
  readonly palette = useKeyboardShortcut('mod+k', () => openPalette())
}
```

#### `useKeyboardShortcut(keys, handler, options)`

Registers `keys` with the bonded keyboard-shortcuts provider for the life
of the component (`DestroyRef`), and unregisters on destroy or when
`enabled` turns false. The latest handler is always the one called: pass a
changing action as a signal, which the registration reads at call time.
With no provider bonded the function does nothing.

Call it in an injection context (a component field initializer or
constructor), the way an app calls Angular's injection-based APIs. Pass
`keys` or `options` as a signal when any part of them can change: a changed
combination, enable flag, description, scope or `preventDefault` flag
unregisters the previous registration and registers the new one on the SAME
instance, the way React re-renders the hook with new arguments.

```typescript
function useKeyboardShortcut(
  keys: string | string[] | Signal<string | string[]>,
  handler: ShortcutHandler | Signal<ShortcutHandler>,
  options?: UseKeyboardShortcutOptions | Signal<UseKeyboardShortcutOptions>,

```

- `keys` — One combination or several (`'mod+k'` is expanded to `ctrl+k` and `command+k`), or a signal of either.
- `handler` — Called with the keyboard event; or a signal of one, read at call time.
- `options` — Enable flag, description, scope, preventDefault; or a signal of them.

- **`mod+` means Ctrl on Windows and Linux, Command on macOS** — the
  function registers both, so never write `ctrl+k` for a shortcut people
  expect as `⌘K` on a Mac.
- Whether a shortcut fires while an input has focus is the bond's decision
  (the hotkeys bond suppresses it, which is what `/` needs). Keys the input
  itself should handle — Escape to clear, arrows to move — belong on the
  input's own keydown handling, not here.
