### Functions

#### `ProgressBar(props)`

Labeled progress bar with optional value display.

Renders a `[label ... valueLabel]` header row above a track. The track
itself uses the wired ClassMap progress tokens — swap the ClassMap bond
to restyle without touching this component.

The track always carries an accessible name (`aria-progressbar-name`):
`labelledBy` when given, else the rendered `label`, else
`t('progressBar.label', undefined, { defaultValue: 'Progress' })`.

```typescript

  value,
  max = 100,

  describedBy,
  size = 'md',
  color = 'primary',
  className,
}: ProgressBarProps): JSX.Element
```

- `props` — Component props (see {@link ProgressBarProps}).

#### `ProgressCard(props)`

`<Card>`-wrapped progress display with title, optional icon and description,
the progress bar itself, and an optional extras slot below. Useful for
budget/goal cards, storage-used panels, onboarding progress, etc.

The bar is named by the title (`aria-labelledby`) and, when a description
renders, described by it (`aria-describedby`).

All visible text (`label`, `valueLabel`, `title`, `description`) is
pass-through — supply already-translated strings. The track's fallback
accessible name resolves through `t('progressBar.label', undefined,
{ defaultValue: 'Progress' })`, so a locale bond can translate it; a
rendered `label` or a `labelledBy` id names it instead. Requires a wired
ClassMap bond: the track/fill styles come from the `progress*` ClassMap
tokens, so colors follow the active theme.
