# @molecule/app-progress-rings-vue

Vue Apple-Health-style concentric SVG progress rings — single + triad.

Exports `<ProgressRings>` for one or more rings rendered as a single SVG —
the Vue counterpart of `@molecule/app-progress-rings-react`, with the same
props (React names) and the same DOM for the same input, so an app switches
framework by changing only the package name in its imports.

## Quick Start

```ts
import { createApp, defineComponent, h } from 'vue'

import { ProgressRings } from '@molecule/app-progress-rings-vue'

const App = defineComponent({
  setup() {
    return () =>
      h(ProgressRings, {
        rings: [
          { value: 8200, max: 10000, color: 'var(--color-success)', label: 'Steps' },
          { value: 7, max: 8, color: 'var(--color-info)', label: 'Sleep (hrs)' },
          { value: 35, max: 60, color: 'var(--color-warning)', label: 'Active (min)' },
        ],
        size: 160,
        strokeWidth: 12,
      })
  },
})

createApp(App).mount('#app')
```
