# @molecule/app-feature-track-lane-svelte

Svelte horizontal track-lane primitive for multi-track timelines (music DAW,
video editor, animation tool). Renders one lane row of draggable + resizable
clip blocks on a `pixelsPerSecond` time axis.

Svelte counterpart of `@molecule/app-feature-track-lane-react`: the same props
(React names), the same DOM for the same input, and the same callback calls,
so an app switches framework by changing only the package name it imports.

Exports `<TrackLane>` and the `Clip` type, plus the pure-function helpers
`clipToPixels`, `pixelsToTime` and `clampClipMove` that back the
pointer-event drag/resize math.

## API

### Interfaces

#### `Clip`

A single clip block on a track lane. `startTime` and `duration` are both in
seconds; `pixelsPerSecond` on the lane converts them to the on-screen
geometry. `id` is a stable identifier used as the row key and as the argument
passed back to all event handlers. `color` accents the body fill (defaults to
a neutral surface) and `label` is rendered inside the clip when given.

```typescript
interface Clip {
  /** Stable identifier for the clip (used as the row key + handler arg). */
  id: string
  /** Clip start time on the lane in seconds. */
  startTime: number
  /** Clip duration in seconds. Always positive — minimum is enforced. */
  duration: number
  /** Optional accent color for the clip body (any valid CSS color). */
  color?: string
  /** Optional inline label rendered on top of the clip body (a snippet or text). */
  label?: string | number | Snippet
}
```

#### `TrackLaneProps`

Props accepted by the {@link TrackLane} component — the same props React's
`TrackLane` accepts. A node-valued prop is a snippet (or plain text).

```typescript
interface TrackLaneProps {
  /** Optional lane name shown in the leading lane header. */
  name?: string | number | Snippet
  /** Clips on this lane. Order is preserved as-is. */
  clips: Clip[]
  /** Horizontal time scale, defaults to 20. */
  pixelsPerSecond?: number
  /**
   * Optional opaque lane identifier. Forwarded to handlers and emitted as
   * `data-lane` so multi-lane parents can tell lanes apart.
   */
  lane?: string
  /** Lane row height in pixels. Defaults to 44. */
  height?: number
  /** Called when a clip is dragged horizontally. */
  onClipMove?: (clipId: string, startTime: number, lane?: string) => void
  /** Called when a clip's right edge handle is dragged. */

  /** Called when a clip body is clicked (no drag). */
  onClipClick?: (clipId: string, lane?: string) => void
  /** Currently-selected clip id (renders the selection ring on that clip). */
  selectedClipId?: string
  /** Extra classes merged onto the root element. */
  className?: string
}
```

### Functions

#### `clipToPixels(clip, pixelsPerSecond)`

Convert a clip to its on-lane pixel geometry.

```typescript
function clipToPixels(
  clip: { startTime: number; duration: number },
  pixelsPerSecond: number,
): { left: number; width: number }
```

- `clip` — The clip to project (`startTime` + `duration` in seconds).
- `pixelsPerSecond` — Horizontal scale; zero or negative falls back to 1.

**Returns:** `{ left, width }` in pixels.

#### `pixelsToTime(pixels, pixelsPerSecond)`

Convert a pixel offset back to a time value, clamped to `>= 0`.

```typescript
function pixelsToTime(pixels: number, pixelsPerSecond: number): number
```

- `pixels` — Offset in pixels.
- `pixelsPerSecond` — Horizontal scale; zero or negative falls back to 1.

**Returns:** Time in seconds (never negative).

#### `clampClipMove(proposedStartTime)`

Clamp the proposed new `startTime` for a clip move so the clip stays
non-negative. (No upper bound — the parent decides whether to clip to a song
length.)

```typescript
function clampClipMove(proposedStartTime: number): number
```

- `proposedStartTime` — The candidate start time in seconds.

**Returns:** The clamped start time.
