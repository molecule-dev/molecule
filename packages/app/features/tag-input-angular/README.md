# @molecule/app-tag-input-angular

Angular tag-token input and tag-chip display.

Exports:

- `<TagList>` — read-only saved tags on detail/preview screens. Renders
  every value in order; optional `itemClassName` and `renderTag` (a
  template reference) keep app-owned markup.
- `<TagChip>` — standalone labeled chip with optional remove button.
- `<TagInput>` — controlled tokenizer: Enter, comma, or Tab adds the
  draft; blur commits a non-empty draft; Backspace on an empty field
  removes the last token. Enter never submits an enclosing form.
- `useTagInput()` — the same tag-entry behavior without markup, for an
  app whose markup is already decided (a design system, a spec's selectors):
  bind `fieldProps()` to a renderer-neutral `TextField` or `inputProps()` to
  your own `<input>`, render the tags yourself, and call `remove(i)` from
  your own remove control.

This is the Angular counterpart of `@molecule/app-tag-input-react`: the same
exports, the same props (React names) and the same DOM for the same input.

```ts
import { Component, signal } from '@angular/core'
import { TagChip, TagInput, TagList } from '@molecule/app-tag-input-angular'

@Component({
  selector: 'app-tag-editor',
  standalone: true,
  imports: [TagInput, TagChip, TagList],
  template: `
    <div mol-tag-input [value]="tags()" [onChange]="setTags" [maxTags]="10"></div>
    <span mol-tag-chip (onRemove)="drop('angular')">angular</span>
  `,
})
export class TagEditor {
  readonly tags = signal<string[]>(['angular'])

  // Adopts the tag list the input proposes.
  readonly setTags = (next: string[]): void => this.tags.set(next)

  drop(tag: string): void {
    this.tags.update((tags) => tags.filter((t) => t !== tag))
  }
}
```

#### `TagChip`

TagChip component — the Angular counterpart of
`@molecule/app-tag-input-react`'s `TagChip`.

Small labeled chip with an optional close button. The host IS the chip's
outer `<span>` (`span[mol-tag-chip]`), matching React's root exactly; the
label is projected content.

The chip body action is keyboard-operable. With no remove button the chip
itself is the control: `role="button"`, tabbable, and Enter / Space fire
`onClick`. With a remove button the action lives on a native button around
the label text instead, since a button may not contain another control.

Angular projection needs an always-mounted `<ng-content>` capture point, so
the label span (holding the projected text) is moved into the label button
when the chip has a body control, and back beside the remove button when it
does not — reconciling the DOM to what React renders.

```typescript
@Component({
  selector: 'span[mol-tag-chip]',
  standalone: true,
  hostDirectives: [MolPlacement],
  inputs: ['onClick', 'onRemove', 'className'],
  host: {
    '[class]': 'classes()',
    '[attr.role]': 'bodyControl() ? "button" : null',
    '[attr.tabindex]': 'bodyControl() ? 0 : null',
    '(click)': 'handleHostClick($event)',
    '(keydown)': 'handleHostKeyDown($event)',
  },
  template: `<span #label
      ><span #capture><ng-content></ng-content></span></span
    ><button
      #labelButton
      type="button"
      [class]="cursorClass()"
      [style.background]="'transparent'"
      [style.border]="'none'"
      [style.padding]="'0'"
      [style.font]="'inherit'"
      [style.color]="'inherit'"
      (click)="emitClick($event)"
    ></button
    ><button
      #removeButton
      type="button"
      (click)="emitRemove($event)"
      [attr.aria-label]="removeLabel()"
      [class]="removeClasses()"
    >
      {{ removeGlyph() }}
    </button>`,
})
export class TagChip {
  /** Optional click callback for the chip body. */
  onClick?: (event?: Event) => void
  /** Optional remove callback — renders the `×` button when provided. */
  onRemove?: (event?: Event) => void
  /** Extra classes. */
  className?: string

  /** The translation service (i18n provider). */
  readonly i18n = useTranslation()

  @ViewChild('label', { static: true })
  private label?: ElementRef<HTMLElement>

  @ViewChild('capture', { static: true })
  private capture?: ElementRef<HTMLElement>

  @ViewChild('labelButton', { static: true })
  private labelButton?: ElementRef<HTMLButtonElement>

  @ViewChild('removeButton', { static: true })
  private removeButton?: ElementRef<HTMLButtonElement>

  constructor() {
    usePlacement(() => this.reconcile())
  }

  /**
   * The current class map.
   * @returns The UIClassMap.
   */
  cm(): UIClassMap {
    return getClassMap()
  }

  /**
   * Whether the chip itself is the body control (no remove button to share it).
   * @returns True when the chip carries the button role and keyboard path.
   */
  bodyControl(): boolean {
    return !!this.onClick && !this.onRemove
  }

  /**
   * The chip's class list (the caller's `className` included).
   * @returns The class string.
   */
  classes(): string {
    const cm = this.cm()
    return cm.cn(
      cm.flex({ align: 'center', gap: 'xs' }),
      cm.sp('px', 2),
      cm.sp('py', 1),
      cm.textSize('xs'),
      cm.fontWeight('medium'),
      cm.roundedFull,
      this.className,
      this.bodyControl() ? cm.cursorPointer : '',
    )
  }

  /**
   * The label button's pointer class.
   * @returns The class string.
   */
  cursorClass(): string {
    const cm = this.cm()
    return cm.cn(cm.cursorPointer)
  }

  /**
   * The remove button's class list.
   * @returns The class string.
   */
  removeClasses(): string {
    const cm = this.cm()
    return cm.cn(cm.w(4), cm.h(4), cm.flex({ align: 'center', justify: 'center' }))
  }

  /**
   * The remove button's accessible name.
   * @returns The translated label.
   */
  removeLabel(): string {
    return this.i18n.t('tagChip.remove', {}, { defaultValue: 'Remove' })
  }

  /**
   * The remove button's glyph.
   * @returns The translated glyph.
   */
  removeGlyph(): string {
    return this.i18n.t('tagChip.removeGlyph', undefined, { defaultValue: '×' })
  }

  /**
   * Mouse activation of the chip body — only when the chip itself is the
   * control (otherwise a button inside it carries the action).
   * @param event - The DOM click event.
   */
  handleHostClick(event: Event): void {
    if (!this.bodyControl()) return
    this.onClick?.(event)
  }

  /**
   * Keyboard activation for the chip body — the same handler the mouse click
   * runs. `preventDefault()` suppresses Space's page scroll and Enter's form
   * submission when a chip sits inside a form.
   * @param event - The DOM keyboard event.
   */
  handleHostKeyDown(event: KeyboardEvent): void {
    if (!this.bodyControl()) return
    if (event.key !== 'Enter' && event.key !== ' ') return
    event.preventDefault()
    this.onClick?.()
  }

  /**
   * Runs the body action from the label button.
   * @param event - The DOM click event.
   */
  emitClick(event: Event): void {
    this.onClick?.(event)
  }

  /**
   * Runs the remove action.
   * @param event - The DOM click event.
   */
  emitRemove(event: Event): void {
    this.onRemove?.(event)
  }

  /**
   * Applies React's DOM after each render: the label button exists only while
   * the chip holds both actions, and the label then moves inside it; the
   * remove button exists while `onRemove` is set.
   */
  private reconcile(): void {
    const label = this.label?.nativeElement
    const labelButton = this.labelButton?.nativeElement
    const removeButton = this.removeButton?.nativeElement
    if (!label || !labelButton || !removeButton) return
    const removable = !!this.onRemove
    // React renders the label button only when the chip holds BOTH actions:
    // a chip with one action is that control itself.
    const labelButtonControl = !!this.onClick && removable

    // React renders the projected label bare: its content stands in the capture point's
    // place and the point itself leaves the page.
    const capture = this.capture?.nativeElement
    if (capture) {
      placeContentBefore(capture, capture)
      setElementPresent(capture, false)
    }

    // The label button is present only in that both-actions branch, and the
    // label itself moves inside it there (React renders it around the label
    // text); otherwise the label sits in the chip and any remove button beside
    // it. The helpers keep Angular's own place for each node.
    setElementPresent(labelButton, labelButtonControl)
    placeElement(label, labelButtonControl ? labelButton : null)
    setElementPresent(removeButton, removable)
  }
}
```

#### `TagInput`

TagInput component — the Angular counterpart of
`@molecule/app-tag-input-react`'s `TagInput`.

Tokenized tag-input with chip display: commits the draft on Enter, comma, or
Tab AND on blur (clicking away with a non-empty draft adds a tag); Backspace

form. The host IS React's outer `<div>` (`div[mol-tag-input]`).

Controlled component — callers own the `value` array. For markup the app has

directly: this component is that hook plus default markup.

```typescript
@Component({
  selector: 'div[mol-tag-input]',
  standalone: true,
  imports: [TagChip],
  inputs: ['value', 'onChange', 'placeholder', 'normalize', 'maxTags', 'className'],
  host: { '[class]': 'classes()' },
  template: `@for (tag of value; track tag + '-' + $index) {
      <span mol-tag-chip [onRemove]="remover($index)">{{ tag }}</span>
    }
    <input
      type="text"
      [value]="input.draft()"
      [attr.value]="input.draft()"
      (input)="handleInput($event)"
      (keydown)="handleKeyDown($event)"
      (focusout)="handleBlur()"
      [attr.placeholder]="placeholderText()"
      [class]="inputClasses()"
    />`,
})
export class TagInput {
  /** Controlled list of tag values. */
  value: string[] = []
  /** Called whenever the tag list changes. */
  onChange?: (next: string[]) => void
  /** Placeholder shown in the text input when no tokens exist yet. */
  placeholder?: string
  /** Validate/transform an input before adding; `null` rejects it. */
  normalize?: (raw: string, current: string[]) => string | null
  /** Max tags allowed. When reached, further input is ignored. */
  maxTags?: number
  /** Extra classes on the outer wrapper. */
  className?: string

  /** The translation service (i18n provider). */
  readonly i18n = useTranslation()

  /** The tag-entry behavior: the same composable an app-owned markup uses. */
  readonly input = useTagInput(() => ({
    value: this.value,
    onChange: (next: string[]) => this.onChange?.(next),
    normalize: this.normalize,
    maxTags: this.maxTags,
  }))

  /**
   * The current class map.
   * @returns The UIClassMap.
   */
  cm(): UIClassMap {
    return getClassMap()
  }

  /**
   * The outer wrapper's class list.
   * @returns The class string.
   */
  classes(): string {
    const cm = this.cm()
    return cm.cn(
      cm.flex({ align: 'center', gap: 'xs', wrap: 'wrap' }),
      cm.sp('p', 2),
      this.className,
    )
  }

  /**
   * The text field's class list.
   * @returns The class string.
   */
  inputClasses(): string {
    const cm = this.cm()
    return cm.cn(cm.flex1, cm.input())
  }

  /**
   * The placeholder shown in the text field.
   * @returns The caller's placeholder, else the translated default.
   */
  placeholderText(): string {
    return (
      this.placeholder ?? this.i18n.t('tagInput.placeholder', {}, { defaultValue: 'Add a tag…' })
    )
  }

  /**
   * The remove control of the tag at an index.
   * @param index - The tag's position.
   * @returns The callback the chip runs.
   */
  remover(index: number): () => void {
    return () => this.input.remove(index)
  }

  /**
   * Forwards a text-field change to the draft.
   * @param event - The DOM input event.
   */
  handleInput(event: Event): void {
    this.input.inputProps().onChange(event)
  }

  /**
   * Commits (or removes) on a key press.
   * @param event - The DOM keyboard event.
   */
  handleKeyDown(event: KeyboardEvent): void {
    this.input.inputProps().onKeyDown(event)
  }

  /** Commits a non-empty draft when the field loses focus. */
  handleBlur(): void {
    this.input.inputProps().onBlur()
  }
}
```

#### `useTagInput(options)`

Tag-entry behavior without markup, for an app whose markup is already
decided (a design system, a spec's selectors). Bind `inputProps()` onto your
own `<input>` — or `fieldProps()` onto a renderer-neutral `TextField` — and
render the tags however you need, calling `remove(i)` from your own remove
control. `<TagInput>` is this hook plus default markup.

Enter commits the draft and never submits an enclosing form: its default is
canceled even when the draft is blank, rejected, or past `maxTags`. Comma and
Tab commit a non-empty draft (an empty Tab keeps normal focus traversal);
blur commits a non-empty draft; Backspace on an empty draft removes the last
tag. A keystroke the input method owns is left to it, including the Enter
that confirms a composition and arrives with the legacy key code 229.

```typescript
function useTagInput(
  options: UseTagInputOptions | Signal<UseTagInputOptions> | (() => UseTagInputOptions),
): UseTagInputResult
```

- `options` — The controlled tag list and its rules, a signal of them, or a getter, so a component changed inputs reach the same hook instance.

**Returns:** The draft, input props and add/remove actions (see {@link UseTagInputResult}).

  duplicates; pass your own to lowercase, validate, or map values
  (return `null` to reject).
- When `maxTags` is reached further input is silently discarded (the
  draft clears, no error UI).
- `<TagChip>` ships no background surface of its own — add one via
  `className` if bare text chips are too subtle in your theme.
