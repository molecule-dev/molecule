# @molecule/app-notifications-page-angular

Drop-in `/notifications` page for molecule-built Angular apps.

Exports `<NotificationsPage>` — a full-page Notifications view that
composes `@molecule/app-notification-feed-angular` and wires it to the
routes exposed by `@molecule/api-resource-notification` over the
HTTP bond. Header, filter chips (all / unread / mentions), pagination,
mark-all-read action, and empty state are all handled internally.

### Types

#### `NotificationsPageFilter`

Filter chips shown above the notification list.

- `'all'` shows every notification (read + unread, every type).
- `'unread'` keeps only `read === false`.
- `'mentions'` keeps only `type === 'mention'`.

```typescript
type NotificationsPageFilter = 'all' | 'unread' | 'mentions'
```

#### `NotificationsPageTypeIconMap`

Maps `Notification.type` values to material-symbol icon names so the
underlying `<NotificationFeed>` can render the right glyph.

Defaults are provided for the most common types; consumers can extend
or replace the map by passing the `typeIcons` prop.

```typescript
type NotificationsPageTypeIconMap = Readonly<Record<string, string>>
```

#### `NotificationsPage`

NotificationsPage component.

Drop-in `/notifications` page used by every flagship app. The host IS the
outer `<section>` (`section[mol-notifications-page]`), matching React's root
exactly, with the same ClassMap tokens, `data-mol-id` and `aria-busy`.

Composes `<NotificationFeed>` with a header (title + mark-all-read action),
a row of filter chips (all / unread / mentions), a paginated body, and an
empty state. All data is loaded over the HTTP bond, and all UI text flows
through `t()` so apps can localise via the companion locale bond
`@molecule/app-locales-notifications-page`.

The list reloads exactly where React's effect does: on mount, when
`pageSize` or `endpoint` changes, and whenever the filter chip or the page
changes. An icon override re-renders the rows and refetches nothing.

All UI text resolves through `t()` and ships in the companion locale
bond `@molecule/app-locales-notifications-page`. All styling
resolves through `getClassMap()` — no Tailwind class names live in
this package.

Prereqs: `provideMolecule({ http })` in the component's injector (from
`@molecule/app-angular` — `useHttpClient()` throws without it), a wired
ClassMap bond, and the `i18n` provider. Icons come from the composed
`@molecule/app-notification-feed-angular`, which renders Material
Symbols LIGATURES — load the "Material Symbols Outlined" font (and its
CSS class) or icon names render as plain text. Notifications whose
`data.href` is set render the binding's `Link` rows, which require the
router the app provides. Defaults assume the API is proxied at `/api` —
override `endpoint` / `markAllReadEndpoint` otherwise.
