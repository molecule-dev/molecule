# @molecule/app-gradebook-solid

Solid gradebook UI — unified table of grades + optional GPA hero card.

Pairs with the `@molecule/api-resource-grade` resource. Rows can be courses
or assignments — the caller picks the granularity. The letter column renders
`Grade.letter` as plain text (string); pass pre-styled content via `title`
if you need richer cells.

This is the Solid counterpart of `@molecule/app-gradebook-react`: the same
exports, the same props (React names), and the same DOM for the same input,
so an app switches framework by changing only the package name in its
imports.

## Quick Start

```tsx
import type { Grade } from '@molecule/app-gradebook-solid'
import { GpaCard, Gradebook } from '@molecule/app-gradebook-solid'

const rows: Grade[] = [
  { id: 'g1', title: 'Algebra II', letter: 'A-', score: 92, weight: 0.25, contribution: 0.92 },
]

export function GradesPage() {
  return (
    <>
      <GpaCard gpa={3.72} scale="4.0" trend="up" />
      <Gradebook gpaScale="4.0" grades={rows} />
    </>
  )
}
```

### Types

#### `GpaScale`

GPA scale supported by the gradebook.

- `'4.0'` — US-style 4.0 unweighted scale.
- `'5.0'` — US-style 5.0 weighted scale (honours / AP).
- `'percentage'` — 0–100 percentage rendering (no GPA conversion applied).

```typescript
type GpaScale = '4.0' | '5.0' | 'percentage'
```

#### `GpaTrend`

#### `GradebookColumn`
