# @molecule/app-drawing-toolbar-svelte

Svelte whiteboard / canvas / annotation tool selector.

Exports `<DrawingToolbar>` (a `role="toolbar"` row/column of toggle
buttons) — the Svelte counterpart of `@molecule/app-drawing-toolbar-react`:
same props and the same DOM for the same input. Selection is controlled:
pass `selectedId` + `onSelect`.

## Quick Start

```svelte
<script lang="ts">
  import { DrawingToolbar } from '@molecule/app-drawing-toolbar-svelte'

  let tool = $state('select')
</script>

<DrawingToolbar
  tools={[
    { id: 'select', label: 'Select', icon: '↖' },
    { id: 'pen', label: 'Pen', icon: '✎' },
    { id: 'rectangle', label: 'Rectangle', icon: '▭' },
  ]}
  selectedId={tool}
  onSelect={(id) => (tool = id)}
  orientation="horizontal"
/>
```
