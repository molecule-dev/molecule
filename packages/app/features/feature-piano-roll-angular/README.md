# @molecule/app-feature-piano-roll-angular

Angular piano roll — MIDI note-grid editor for music-daw and other
DAW-style surfaces. Renders a vertical piano keyboard on the left, a
horizontal time grid on the right, and draggable / resizable note rectangles
on top.

Angular counterpart of `@molecule/app-feature-piano-roll-react`: the same
props (React names), the same DOM for the same input, and the same callback
calls, so an app switches framework by changing only the package name it
imports.

## Quick Start

```ts
import { Component } from '@angular/core'
import { PianoRoll, type MidiNote } from '@molecule/app-feature-piano-roll-angular'

@Component({
  selector: 'app-roll',
  standalone: true,
  imports: [PianoRoll],
  template: `
    <div
      mol-piano-roll
      [notes]="notes"
      snap="1/16"
      [onNoteAdd]="addNote"
      [onNoteMove]="moveNote"
      [onNoteResize]="resizeNote"
      [onNoteDelete]="deleteNote"
    ></div>
  `,
})
export class Roll {
  notes: MidiNote[] = []
  addNote = (note: MidiNote): void => {
    this.notes = [...this.notes, note]
  }
  moveNote = (noteId: string, startBeat: number, pitch: number): void => {
    this.notes = this.notes.map((n) => (n.id === noteId ? { ...n, startBeat, pitch } : n))
  }
  resizeNote = (noteId: string, durationBeats: number): void => {
    this.notes = this.notes.map((n) => (n.id === noteId ? { ...n, durationBeats } : n))
  }
  deleteNote = (noteId: string): void => {
    this.notes = this.notes.filter((n) => n.id !== noteId)
  }
}
```

## API

### Interfaces

#### `MidiNote`

A single MIDI note rendered on the piano roll. `pitch` is a standard MIDI
pitch number in the closed interval `[0, 127]` where `60` represents middle C
(`C4`). `startBeat` is the note's start position on the time grid, and
`durationBeats` is its length in beats. `id` is a stable identifier used as
the row key and as the argument passed back to all event handlers.
`velocity` is an optional MIDI velocity in the closed interval `[0, 127]`
(defaults to a neutral mid-range).


### Types

#### `PianoRollSnap`

Snap resolution for note placement / movement / resize. Each value is a
fraction of a beat: `'1/16'` is sixteenth-notes (a quarter of a beat), `'1/4'`
is quarter-notes (one beat), `'1'` snaps to whole beats with no
sub-divisions, etc.

```typescript
type PianoRollSnap = '1/16' | '1/8' | '1/4' | '1/2' | '1'
```

### Classes

#### `PianoRoll`

PianoRoll component.

The host IS React's root `<div>` (`div[mol-piano-roll]`), matching React's
root exactly. Renders a vertical piano keyboard on the left, a horizontal
time grid on the right, and draggable / resizable note rectangles on top.
Click an empty cell to paint a new note, drag a note body to move it
(snapped), drag the right-edge handle to resize, right-click a note to
delete it.

Keyboard users get the same paint action: focus the grid (Tab), move the
cell cursor with the arrow keys, and press Enter or Space to paint a new note
at the cursor cell.
