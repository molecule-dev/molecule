### Functions

#### `EditorToolbar(props)`

Editor-page top toolbar — title + optional version/status badge + primary
actions (Save, Publish, Test) + secondary icon actions.

Renders React's exact DOM: the title row (leading, `<h1>`, badge) and the
actions row, with the same ClassMap tokens, the 1px divider between
non-empty primary and secondary groups, and the sticky inline style by
default (`sticky` defaults to true). Action `label`s render verbatim — the
component has no `t()` calls of its own.

React keys each action button by `p-<id>` / `s-<id>`, so a re-ordered or
re-passed array moves/keeps the rendered buttons per key. Solid's `For`
keys by reference, so the primary buttons are keyed through stable per-id
records — the record for an id is created once and reused, while the button
reads the CURRENT action for its id reactively (a changed label updates in
place).

### Runtime Dependencies

- `@molecule/app-ui-solid`
- `solid-js`

- `sticky` defaults to TRUE and applies `position: sticky; top: 0` with a
  TRANSPARENT background — pass a surface class via `className` or page
  content will scroll visibly through the toolbar.
- Action `label`s render verbatim (into the button and nothing else) — pass
  already-translated strings; the component has no `t()` calls or locale
  bond of its own.
- Prefer `onClick` over `href`: an `href` action wraps the button in a plain
  anchor (full page navigation, and invalid button-in-anchor nesting for
  assistive tech).
- A 1px divider renders between the primary and secondary groups only when
  both are non-empty.
- Buttons come from `@molecule/app-ui-solid`; requires a wired ClassMap bond
  (standard molecule app setup). Node-valued props are Solid JSX values.
