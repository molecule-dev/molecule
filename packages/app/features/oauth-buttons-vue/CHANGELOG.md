# @molecule/app-oauth-buttons-vue

## 1.2.0

### Minor Changes

- A provider without a built-in label now renders through one fallback translation key that passes the provider name as a placeholder, instead of a translation key built at runtime. The locale bond adds that key in every language.

## 1.1.0

### Minor Changes

- Add `@molecule/app-oauth-buttons-vue`, `@molecule/app-oauth-buttons-solid`, `@molecule/app-oauth-buttons-svelte` and `@molecule/app-oauth-buttons-angular`: the config-driven OAuth provider button row for Vue, Solid, Svelte and Angular, matching `@molecule/app-oauth-buttons-react`.
