# @molecule/app-sidebar-layout-angular

Angular vertical sidebar app shell layout — the counterpart of
`@molecule/app-sidebar-layout-react`: the same props and the same DOM for the
same input.

Exports `<SidebarLayout>` plus the `SidebarLayoutProps` and `SidebarNavItem`
types — fixed-width left sidebar with brand link, vertical nav links, and
bottom user-menu / theme-toggle slots; the main area on the right scrolls and
renders the routed page.

## Quick Start

```ts
import { Component } from '@angular/core'
import { SidebarLayout } from '@molecule/app-sidebar-layout-angular'

const NAV = [
  { key: 'dashboard', to: '/dashboard', icon: 'dashboard', label: 'Dashboard' },
  { key: 'projects', to: '/projects', icon: 'folder', label: 'Projects' },
  { key: 'settings', to: '/settings', icon: 'settings', label: 'Settings' },
]

@Component({
  selector: 'app-shell',
  standalone: true,
  imports: [SidebarLayout],
  template: `
    <div mol-sidebar-layout [appName]="'Acme App'" [navItems]="NAV">
      <app-user-menu slot="userMenu" />
      <router-outlet />
    </div>
  `,
})
```

### Types

#### `SidebarWidth`

Semantic sidebar width. Mapped to a fixed pixel width internally and applied
via inline style (a width is one of the "specific values" a styling-agnostic
ClassMap cannot express as a swappable token) so the sidebar renders the same
regardless of which ClassMap bond is active — no Tailwind width utility leaks
into consumer code.

- `sm` → 208px, `md` → 240px (default), `lg` → 256px.
- Pass a raw `number` for an exact pixel width.

```typescript
type SidebarWidth = 'sm' | 'md' | 'lg' | number
```

### Classes

#### `SidebarLayout`

SidebarLayout component.

Fixed-width left sidebar with brand link + vertical router links + bottom
user-menu / theme-toggle slots, and the `<main>` holding the routed page
body. The host IS the outer `<div>` (`div[mol-sidebar-layout]`), matching
React's root exactly. The page body is projected as the element's default
content (React renders its router's `<Outlet />` in the `<main>`); the bottom
slots are projected as `[slot=userMenu]` / `[slot=themeToggle]` content.

The sidebar WIDTH is the one value a styling-agnostic ClassMap can't express,
so it is applied via inline style from `sidebarWidth`; active-nav
highlighting picks the longest prefix-match of the current path, and
same-path links get a `#top` fragment appended. `label` is rendered as-is:
pass an already-translated string.

```typescript
@Component({
  selector: 'div[mol-sidebar-layout]',
  standalone: true,
  imports: [Link, RoutedView],
  inputs: [
    'appName',
    'logoTo',
    'navItems',
    'navAriaLabel',
    'sidebarWidth',
    'sidebarWidthClass',
    'className',
    'dataMolId',
  ],
  host: {
    '[class]': 'classes()',
    '[attr.data-mol-id]': 'dataMolId ?? null',
  },
  // prettier-ignore
  template: `<aside [class]="asideClasses()" [style.width.px]="widthPx()"><a [molLink]="logoPath()" [class]="brandClasses()">{{ appName }}</a><nav [class]="navClasses()" [attr.aria-label]="navLabel()">@for (item of navItems; track item.key) {<a [molLink]="itemPath(item)" [attr.data-mol-id]="'nav-' + item.key" [attr.aria-current]="isActive(item) ? 'page' : null" [class]="itemClasses(item)">@if (item.icon) {<span [class]="iconClasses()" aria-hidden="true">{{ item.icon }}</span>}<span>{{ item.label }}</span></a>}</nav><div #bottom [class]="bottomClasses()"><span #placeholder aria-hidden="true"></span><span #userSlot data-parity-unwrap style="display: contents"><ng-content select="[slot=userMenu]"></ng-content></span><span #themeSlot data-parity-unwrap style="display: contents"><ng-content select="[slot=themeToggle]"></ng-content></span></div></aside><main [class]="mainClasses()" [style.min-width.px]="0"><span #pageSlot data-parity-unwrap style="display: contents"><ng-content></ng-content></span>@if (routed()) {<mol-routed-view />}</main>`,
})
export class SidebarLayout implements AfterViewInit, AfterViewChecked, DoCheck, OnDestroy {
  /** Brand text shown at the top of the sidebar (typically the app name). */
  appName = ''
  /** Path the brand link navigates to (defaults to `'/'` at read time). */
  logoTo?: string
  /** Vertical nav items rendered in the sidebar. */
  navItems: ReadonlyArray<SidebarNavItem> = []
  /** Aria-label for the primary `<nav>`. */
  navAriaLabel?: string
  /** Sidebar width preset or explicit pixel number (defaults to `'md'` at read time). */
  sidebarWidth?: string | number
  /** Deprecated Tailwind width utility, parsed to pixels (never emitted as a class). */
  sidebarWidthClass?: string
  /** Extra classes on the outer wrapper. */
  className?: string
  /** `data-mol-id` for AI-agent selectors. */
  dataMolId?: string

  /** The projected bottom-slot container (detached when both slots are absent). */
  @ViewChild('bottom') private bottom?: ElementRef<HTMLElement>
  /** The placeholder `<span>` React renders while the user menu is absent. */
  @ViewChild('placeholder') private placeholder?: ElementRef<HTMLElement>
  /** The `[slot=userMenu]` projection capture point. */
  @ViewChild('userSlot') private userSlot?: ElementRef<HTMLElement>
  /** The `[slot=themeToggle]` projection capture point. */
  @ViewChild('themeSlot') private themeSlot?: ElementRef<HTMLElement>
  /** The page body's projection capture point. */
  @ViewChild('pageSlot') private pageSlot?: ElementRef<HTMLElement>

  /** Whether the `<main>` renders the routed view: no page body was projected. */
  readonly routed = signal(false)

  private readonly router = useRouterInstance()

  private readonly i18n = useTranslation()

  /** The current location, kept current so active items follow navigation. */
  private readonly location = signal(this.router.getLocation())

  private readonly stop = this.router.subscribe(() => this.location.set(this.router.getLocation()))

  private readonly guard = new SlotGuard(inject(Renderer2))

  /** Stops listening to the router when the component goes away. */
  ngOnDestroy(): void {
    this.stop()
  }

  /** The current class map. */
  cm(): UIClassMap {
    return getClassMap()
  }

  /** Computes the wrapper class list. */
  classes(): string {
    return this.cm().cn(this.cm().pageShell, this.cm().page, this.className)
  }

  /** Computes the sidebar's class list. */
  asideClasses(): string {
    const cm = this.cm()
    return cm.cn(cm.sp('p', 4), cm.shrink0, cm.flex({ direction: 'col' }), cm.surface, cm.borderR)
  }

  /** The inline sidebar width, in pixels. */
  widthPx(): number {
    return resolveSidebarWidthPx(this.sidebarWidth, this.sidebarWidthClass)
  }

  /** Computes the brand link class list. */
  brandClasses(): string {
    const cm = this.cm()
    return cm.cn(cm.textSize('xl'), cm.fontWeight('bold'), cm.sp('mb', 6), cm.displayBlock)
  }

  /** Computes the nav class list. */
  navClasses(): string {
    return this.cm().cn(this.cm().flex1, this.cm().stack(1))
  }

  navLabel(): string {
    return (
      this.navAriaLabel ??
      this.i18n.t('sidebarLayout.aria.primaryNavigation', undefined, {
        defaultValue: 'Primary navigation',
      })
    )
  }

  /** The brand link destination (React's default parameter). */
  logoPath(): string {
    return this.samePathTarget(this.logoTo ?? '/')
  }

  /** One nav item's link destination. */
  itemPath(item: SidebarNavItem): string {
    return this.samePathTarget(item.to)
  }

  /** Computes the icon span class list. */
  iconClasses(): string {
    return this.cm().cn(this.cm().iconGlyphFont)
  }

  /** Computes the bottom-slot container class list. */
  bottomClasses(): string {
    const cm = this.cm()
    return cm.cn(
      cm.sp('pt', 4),
      cm.flex({ align: 'center', justify: 'between', gap: 'sm' }),
      cm.borderT,
    )
  }

  /** Computes the main content area class list. */
  mainClasses(): string {
    return this.cm().cn(this.cm().pageShellContent)
  }

  /** The key of the nav item whose `to` is the longest prefix-match of the current pathname. */
  activeKey(): string | null {
    const pathname = this.location().pathname
    return this.navItems.reduce<string | null>((bestKey, item) => {
      const isMatch = pathname === item.to || pathname.startsWith(`${item.to}/`)
      if (!isMatch) return bestKey
      if (bestKey === null) return item.key
      const best = this.navItems.find((i) => i.key === bestKey)
      return best && item.to.length > best.to.length ? item.key : bestKey
    }, null)
  }

  /** Whether one nav item is the active one at the current location. */
  isActive(item: SidebarNavItem): boolean {
    return item.key === this.activeKey()
  }

  /** Computes the class list of one nav link: the shared nav-item treatment plus the active or idle variant. */
  itemClasses(item: SidebarNavItem): string {
    const cm = this.cm()
    return cm.cn(
      cm.flex({ align: 'center', gap: 'sm' }),
      cm.sp('px', 3),
      cm.sp('py', 2),
      cm.textSize('sm'),
      cm.fontWeight('medium'),
      cm.roundedFull,
      this.isActive(item)
        ? cm.cn(cm.bgPrimaryContainer, cm.textOnPrimaryContainer)
        : cm.cn(cm.textMuted, cm.link),
    )
  }

  /** Appends `#top` when `to` is the current path, so a same-route click still produces an observable URL change. */
  private samePathTarget(to: string): string {
    const pathname = this.location().pathname
    const samePath = pathname === to || pathname + '/' === to
    if (!samePath) return to
    return `${to.replace(/\/$/, '') || '/'}#top`
  }

  /** Reconciles the projected bottom slots against React's branch once the view queries resolve. */
  ngAfterViewInit(): void {
    this.reconcile()
  }

  /** Re-reconciles on later passes, so a change to the projected content swaps the branch the way React does. */
  ngDoCheck(): void {
    this.reconcile()
  }

  /** Re-reconciles after each view update. */
  ngAfterViewChecked(): void {
    this.reconcile()
  }

  private reconcile(): void {
    const user = this.userSlot?.nativeElement
    const theme = this.themeSlot?.nativeElement
    const hasUser = hasNodes(user)
    const hasTheme = hasNodes(theme)
    this.guard.toggle(this.bottom?.nativeElement, hasUser || hasTheme)
    this.guard.toggle(this.placeholder?.nativeElement, !hasUser && hasTheme)
    // React renders `children ?? <RoutedView />`; the capture point resolves at view init.
    const page = this.pageSlot?.nativeElement
    if (page) this.routed.set(!hasNodes(page))
  }
}
```

### Runtime Dependencies

- `@angular/common`
- `@angular/core`
- `@angular/platform-browser`
- `@molecule/app-angular`
- `@molecule/app-ui`
- `@molecule/app-ui-angular`

- Router required: reads the current location and renders router links, so
  it must be mounted inside the molecule router provider (the app shell
  does that at startup).
- Node props are projected content: the bottom slots are selected by
  `[slot=userMenu]` / `[slot=themeToggle]`, everything else lands in the main
  container as the default projection (React's `<Outlet />`).
- Fully ClassMap-driven: every layout/surface/border/text/state class is
  resolved through `getClassMap()` (`cm.pageShell`, `cm.page`, `cm.surface`,
  `cm.borderR`, …), so swapping the ClassMap bond restyles the whole shell.
  The sidebar WIDTH is applied via inline style from `sidebarWidth`
  (`'sm'`|`'md'`|`'lg'`|pixel `number`); the old `sidebarWidthClass` prop is
  `@deprecated` — parsed to pixels, never re-emitted as a class.
- `icon` values are Material Symbols ligature names rendered with the
  `material-symbols-outlined` font class — the one documented icon-font
  exception. Without the font loaded, the raw icon name shows as text.
- Active-nav highlighting picks the longest prefix-match of the current
  path; same-path links get a `#top` fragment appended.
- `navAriaLabel` overrides the translated nav region name; without it the
  label comes from `t('sidebarLayout.aria.primaryNavigation')` (English
  default `'Primary navigation'`), so it follows a locale switch through its
  companion locale bond (`@molecule/app-locales-sidebar-layout`). Nav item
  `label`s stay plain caller strings — translate them upstream.
- Requires a bonded ClassMap. Sibling: `@molecule/app-shell-layout-angular`
  is the top header/footer shell (router-free).
