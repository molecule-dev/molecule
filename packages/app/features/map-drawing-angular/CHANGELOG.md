# @molecule/app-map-drawing-angular

## 1.2.0

### Minor Changes

- Keeps drawing when the pointer leaves the surface, finishes a circle or selection at the release position and discards a drag the browser interrupts. Requires `@molecule/app-ui-angular` 1.6 or later.

## 1.1.1

### Patch Changes

- Projected content that the consumer stops passing and passes again renders again, and a default shows only while nothing is projected.

## 1.1.0

### Minor Changes

- Add the Vue, Solid, Svelte and Angular counterparts of `@molecule/app-map-drawing-react`: the same exports and props, rendering the same DOM.
