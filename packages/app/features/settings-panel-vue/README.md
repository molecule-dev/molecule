# @molecule/app-settings-panel-vue

`@molecule/app-settings-panel-vue` — the Vue counterpart of
`@molecule/app-settings-panel-react`: a composable, batteries-included
settings panel with the same props (React names), the same DOM for the
same input, and the same callbacks and service calls.

`<SettingsContainer onClose={…}>` owns the layout and publishes `onClose`
via Vue injection; each section component is independent and loads its own
data through `@molecule/app-vue` composables:

- `<AccountSection>` — name/email edit (`PATCH /api/users/:id`).
- `<AppearanceSection>` — dark-mode toggle (`useTheme()`).
- `<AuthSection>` — password change + TOTP two-factor
  (`POST /api/users/:id/verify-two-factor`).
- `<NotificationsSection>` — web-push toggle (see the exported
  `enablePushOnCurrentDevice` / `disablePushOnCurrentDevice` helpers and
  their documented device-row contract).
- `<BillingSection>` — read-only plan display (`GET /api/billing/status`),
  or `<TiersUpgradeSection>` — full Stripe upgrade/cancel flow
  (`/api/billing/tiers|checkout|cancel`). Use one or the other, not both.
- `<DevicesSection>` / `<ThisDeviceSection>` — device list + current
  device (`GET/DELETE /api/devices`).
- `<LogOutDeleteSection>` — sign out + delete account
  (`DELETE /api/users/:id`).

## Quick Start

```ts
import { createApp, defineComponent, h } from 'vue'
import {
  AccountSection,
  AppearanceSection,
  AuthSection,
  BillingSection,
  DevicesSection,
  LogOutDeleteSection,
  NotificationsSection,
  SettingsContainer,
  ThisDeviceSection,
  TiersUpgradeSection,
} from '@molecule/app-settings-panel-vue'

const SettingsPanel = defineComponent({
  props: { onClose: { type: Function, required: true } },
  setup(props) {
    return () =>
      h(
        SettingsContainer,
        { onClose: props.onClose },
        {
          default: () => [
            h(AccountSection),
            h(AppearanceSection),
            h(AuthSection),
            h(NotificationsSection),
            h(BillingSection),
            h(DevicesSection),
            h(ThisDeviceSection),
            h(LogOutDeleteSection),
          ],
        },
      )
  },
})

createApp(SettingsPanel).mount('#app')
```

#### `AuthSection`

Authentication section — change password (modal) + two-factor (TOTP) setup.

Two-factor uses the real enrollment flow against the user resource's
`POST /users/:id/verify-two-factor` endpoint (`@molecule/api-two-factor`):

- Enable → `{action:'setup'}` returns a QR code + secret to scan into an
  authenticator app → user enters the 6-digit code → `{action:'enable', token}`.
- Disable → user enters a current code → `{action:'disable', token}`.
  The current status is read from `/users/me`. (This replaces the previous
  boolean toggle, which PATCHed `twoFactorEnabled` — a field the update
  handler deliberately ignores — so it never actually enrolled 2FA.)

password / 2FA wouldn't apply. Pass `:two-factor="false"` when the app's API
has no two-factor provider: it then serves no `verify-two-factor` route, so
the section shows only the password change and reads no 2FA status.

#### `DevicesSection`

Devices section — lists the user's registered devices and lets them
revoke (sign out) any device other than the one they're currently using.

Revoking deletes the device row (`DELETE /api/devices/:id`). The API's
authorization layer enforces server-side revocation: it rejects that
device's session the next time it makes a request (within the
device-exists cache TTL), so the removed device is actually signed out —
not just hidden from the list. The current device is labelled
"This device" and is not revocable here (use Sign out for the current
session). Recreates molecule v1's device-revocation behaviour.

  (they read its injection for `onClose`).
- Server contract: the molecule API surface from
  `@molecule/api-resource-user`, `@molecule/api-resource-device`,
  `@molecule/api-two-factor`, and the billing endpoints
  (`/api/billing/*`) wired by the payments stack. Missing read endpoints
  degrade gracefully (sections render empty); the mutating actions do not.
- Translations: `@molecule/app-locales-settings-panel` companion bond.
