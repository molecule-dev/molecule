# @molecule/app-legal-pages-angular

Angular page scaffolds for Terms, Privacy, and PlanUpdated.

Exports:

- Drop-in pages: `<TermsPage>`, `<PrivacyPage>` (boilerplate bodies with
  configurable i18n keys), `<PlanUpdatedPage>` (post-checkout confirmation).
- Bonded-content pages: `<LegalContentPage kind="privacy" | "terms">` — renders
  the SAME legal HTML as the footer modals (`content.privacyPolicy` /
  `content.termsOfService` from `@molecule/app-locales-legal-default`), inside
  the branded `ContentPageShell` shell.
- In-place modals: `<LegalModalLinks>` + `useLegalModals()` — Privacy/Terms
  triggers that open modals instead of navigating.
- Primitives: `<ContentPageShell>` (hero band + surface card),
  `<LegalPageLayout>`, `<LegalPageSection>`.

This is the Angular counterpart of `@molecule/app-legal-pages-react`: the same
export names, the same props (React names), the same ClassMap tokens and the
same DOM for the same input. Switching framework is a change of package name
in the imports only.

#### `ContentPageShell`

ContentPageShell component.

Branded shell for public content pages (Privacy, Terms, Pricing,
PlanUpdated, …). The host IS the outer `<div>` (`div[mol-content-page-shell]`),
matching React's root exactly. The app's own chrome is projected content
(`[slot=header]`, `[slot=footer]`); the hero's eyebrow, title and subtitle are
`[slot=eyebrow]`, `[slot=title]` and `[slot=subtitle]`; the body is the
default projection.

React renders the hero only when a title is supplied, the eyebrow and
subtitle paragraphs only when their nodes are, and the body's surface card
only when `bare` is false — Angular's projection points must exist, so
{@link ContentPageShell.reconcile} reconciles all four against React's DOM.

```typescript
    setElementPresent(this.heroEl?.nativeElement, hasContent(this.titleEl?.nativeElement))
    setElementPresent(this.eyebrowEl?.nativeElement, hasContent(this.eyebrowEl?.nativeElement))
    setElementPresent(this.subtitleEl?.nativeElement, hasContent(this.subtitleEl?.nativeElement))
    this.syncBare()
  }

  /**
   * Applies React's `bare ? children : <div class="…surface…">{children}</div>`:
   * the card exists for its `<ng-content>` capture point, so `bare` renders its
   * projected nodes without the wrapper, and a later non-bare pass puts them
   * back inside it.
   */
  private syncBare(): void {
    const card = this.cardEl?.nativeElement
    const body = this.bodyEl?.nativeElement
    if (!card || !body) return
    if (this.bare) {
      if (this.cardBare) return
      setElementPresent(card, true)
      placeContent(card, body, card)
      setElementPresent(card, false)
      this.cardBare = true
      return
    }
    if (!this.cardBare) return
    setElementPresent(card, true)
    placeContent(card, null)
    this.cardBare = false
  }
```

#### `LegalContentPage`

LegalContentPage component.

Standalone Privacy / Terms page that renders the SAME bonded legal HTML the
footer modal shows (`content.privacyPolicy` / `content.termsOfService`),
wrapped in the same shell `ContentPageShell` renders — the host IS React's
outer `<div>` (`div[mol-legal-content-page]`), and its template mirrors the
shell's markup so the header/footer chrome is projected straight into it.

The legal HTML renders through a sanitizer-bypassed `[innerHTML]`: React uses
`dangerouslySetInnerHTML` on app-supplied catalog content, and sanitizing
here would strip markup and render a different DOM. The `appName`
interpolated into that HTML is HTML-escaped first, exactly as React does.

```typescript
    )
  }

  /**
   * Marks the legal HTML as safe for the `[innerHTML]` binding. This bypasses
   * Angular's sanitizer DELIBERATELY: the legal HTML is app-supplied catalog
   * content and React renders it with `dangerouslySetInnerHTML`; sanitizing
   * would strip markup and render a different DOM. Memoized by string so a
   * re-render carrying the same HTML does not re-parse it (React skips such an
   * update too).
   *
   * @returns The trusted value for `[innerHTML]`.
   */
  trustedHtml(): SafeHtml {
    const html = this.html()
    const hit = this.trusted.get(html)
    if (hit !== undefined) return hit
    if (this.trusted.size >= TRUSTED_CACHE_LIMIT) this.trusted.clear()
    const value = this.sanitizer.bypassSecurityTrustHtml(html)
    this.trusted.set(html, value)
    return value
  }

  /**
   * Runs the app's lazy loader (React's `useEffect` over `[loadContent, kind]`):
   * once when the inputs first exist and again whenever either changes.
   *
   * @param changes - The changed inputs.
   */
  ngOnChanges(changes: SimpleChanges): void {
    // React's dependency list is `[loadContent, kind]`: any other input change
    // must not re-run the loader.
    if (!changes['kind'] && !changes['loadContent']) return
    const load = this.loadContent
    Promise.resolve(load?.(MODULE[this.kind ?? 'privacy'])).then(
      () => undefined,
      // A loader failure is not this page's to report: React's effect ignores
      // it the same way, and the bonded content that did register renders.
      (_error) => undefined,
    )
  }
}
```

```typescript
   * React renders either the plain text or the projected nodes, unwrapped
   * inside the trigger — never one of the two capture spans. The projected
   * nodes win when the label received any; the text is the fallback otherwise.
   * The trigger stays the same element while it renders, so the parent is kept
   * once seen (a detached capture point has no parent).
   *
   * @param fallback - The span holding the plain text.
   * @param slot - The span holding the projected nodes.
   * @param label - The form rendered last time and the element it rendered in.
   * @param hasContent - Reads whether a slot has content.
   */
  private syncLabel(
    fallback: HTMLElement | undefined,
    slot: HTMLElement | undefined,
    label: { mode: 'text' | 'nodes' | null; parent: HTMLElement | null; slot: HTMLElement | null },
    hasContent: SlotReader,
  ): void {
    if (!fallback || !slot) return
    // A re-created trigger (a `show` change) is planned again from scratch.
    if (label.slot !== slot) {
      label.slot = slot
      label.mode = null
    }
    const live = (fallback.parentNode ?? slot.parentNode) as HTMLElement | null
    if (live !== null) label.parent = live
    const parent = label.parent
    if (!parent) return
    const next: 'text' | 'nodes' = hasContent(slot) ? 'nodes' : 'text'
    if (next === label.mode) return
    if (next === 'nodes') {
      placeContent(fallback, null)
      setElementPresent(fallback, false)
      setElementPresent(slot, true)
      placeContent(slot, parent, slot)
      setElementPresent(slot, false)
    } else {
      placeContent(slot, null)
      setElementPresent(slot, false)
      setElementPresent(fallback, true)
      placeContent(fallback, parent, fallback)
      setElementPresent(fallback, false)
    }
    label.mode = next
  }
}
```

```typescript
    const slot = this.contentSlot?.nativeElement

    if (live !== null) this.bodyParent = live

    if (next === this.bodyMode) return
    if (next === 'content') {
      setElementPresent(intro, false)
      setElementPresent(slot, true)
      placeContent(slot, parent, slot)
      setElementPresent(slot, false)
    } else {
      placeContent(slot, null)
      setElementPresent(slot, false)
      setElementPresent(intro, true)
    }
    this.bodyMode = next
  }
}
```

#### `TermsPage`

TermsPage component.

Default Terms-of-service page scaffold: the canonical boilerplate Terms page,
or the projected body when the app supplies one. React's root is the layout's
`<main>`, so that `<main>` renders immediately before the host's place and
the host itself never appears in the page; the heading is projected into
`LegalPageLayout`'s `[slot=title]`.

React renders the boilerplate intro paragraph only when no children were
passed and the projected body otherwise, so both capture points exist and
{@link TermsPage.syncBody} keeps whichever React would have rendered.

```typescript
@Component({
  selector: 'mol-terms-page',
  standalone: true,
  hostDirectives: [MolPlacement],
  imports: [LegalPageLayout],
  inputs: ['titleKey', 'titleDefault', 'introKey', 'introDefault', 'stackGap'],
  template: `<main #pageMain mol-legal-page-layout [dataMolId]="'page-terms'" [stackGap]="stackGap">
    <ng-container ngProjectAs="[slot=title]">{{ titleText() }}</ng-container>
    <p #introEl>{{ introText() }}</p>
    <span #contentSlot><ng-content></ng-content></span>
  </main>`,
})
export class TermsPage {
  /** i18n key for the page heading (defaults to `terms.title` at read time). */
  titleKey?: string
  /** Default for the heading when the i18n key is missing (defaults to `Terms`). */
  titleDefault?: string
  /** i18n key for the single-paragraph intro (ignored when content is projected). */
  introKey?: string
  /** Default intro body when the key is missing. */
  introDefault?: string
  /** Stack gap between body children. */
  stackGap?: SpacingScale

  /** The boilerplate intro paragraph (React renders none when children are passed). */
  @ViewChild('introEl') private introEl?: ElementRef<HTMLElement>
  /** The projected body's capture point. */
  @ViewChild('contentSlot') private contentSlot?: ElementRef<HTMLElement>
  /** The layout `<main>` (React's root, rendered beside the host). */
  @ViewChild('pageMain', { read: ElementRef }) private pageMain?: ElementRef<HTMLElement>

  /** Which body form renders last (null until the first pass). */
  private bodyMode: 'intro' | 'content' | null = null
  /** Where the body renders (kept once seen: a detached capture point has no parent). */
  private bodyParent: HTMLElement | null = null

  /** The reactive i18n binding, read in the injection context. */
  private readonly i18n = useTranslation()

  private readonly host: ElementRef<HTMLElement> = inject(ElementRef)

  constructor() {
    usePlacement((hasContent) => {
      const main = this.pageMain?.nativeElement
      if (!main) return
      // React's root is the layout's <main>; the host itself leaves the page.
      placeElementBefore(main, this.host.nativeElement)
      setElementPresent(this.host.nativeElement, false)
      this.syncBody(hasContent)
    })
  }

  /**
   * The current class map.
   * @returns The UIClassMap.
   */
  cm(): UIClassMap {
    return getClassMap()
  }

  /**
   * The page heading.
   * @returns The translated heading.
   */
  titleText(): string {
    return this.i18n.t(
      this.titleKey ?? 'terms.title',
      {},
      {
        defaultValue: this.titleDefault ?? 'Terms',
      },
    )
  }

  /**
   * The boilerplate intro.
   * @returns The translated intro.
   */
  introText(): string {
    return this.i18n.t(
      this.introKey ?? 'terms.intro',
      {},
      {
        defaultValue:
          this.introDefault ??
          'This is the Terms page. Replace this placeholder with real content.',
      },
    )
  }

  /**
   * React's `{children ?? <p>{intro}</p>}`: keeps the intro paragraph when
   * nothing was projected, and renders the projected body unwrapped in its
   * place when something was.
   *
   * @param hasContent - Reads whether a slot has content.
   */
  private syncBody(hasContent: SlotReader): void {
    const intro = this.introEl?.nativeElement
    const slot = this.contentSlot?.nativeElement
    if (!intro || !slot) return
    const live = (slot.parentNode ?? intro.parentNode) as HTMLElement | null
    if (live !== null) this.bodyParent = live
    const parent = this.bodyParent
    if (!parent) return
    const next: 'intro' | 'content' = hasContent(slot) ? 'content' : 'intro'
    if (next === this.bodyMode) return
    if (next === 'content') {
      setElementPresent(intro, false)
      setElementPresent(slot, true)
      placeContent(slot, parent, slot)
      setElementPresent(slot, false)
    } else {
      placeContent(slot, null)
      setElementPresent(slot, false)
      setElementPresent(intro, true)
    }
    this.bodyMode = next
  }
}
```

#### `useLegalModals(options)`

Headless hook powering in-place Privacy/Terms modals. Use it when the

- **`appName` is HTML-escaped before interpolation.** The legal bodies are

  `dangerouslySetInnerHTML` trust model); an `appName` carrying markup is
  escaped to inert entities first, so it can never execute inside the legal

  `[slot=termsLabel]`; the body is each element's default content.
- `LegalContentPage` / `useLegalModals` render bonded HTML that defaults to an
  EMPTY string until the locale module is registered — pass your app's
  `loadContent` (from `src/config.ts`, re-exporting
  `@molecule/app-locales-legal-default`) or the page/modal body will be blank.
- `PlanUpdatedPage` requires BOTH the app's router (it renders the router
  link) and wired auth state from `@molecule/app-angular` — without an auth
  provider it shows a spinner forever (`state.initialized` never flips). The
  rest of the package is router-free.

  `@molecule/app-pricing-page-react` (the pricing-page-flavored success page),
  and a standalone `<PlanUpdated>` lives in
  `@molecule/app-plan-updated-page-react`. THIS package's `<PlanUpdatedPage>`
