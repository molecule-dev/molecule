# @molecule/app-legal-pages-angular

Angular page scaffolds for Terms, Privacy, and PlanUpdated.

Exports:

- Drop-in pages: `<TermsPage>`, `<PrivacyPage>` (boilerplate bodies with
  configurable i18n keys), `<PlanUpdatedPage>` (post-checkout confirmation).
- Bonded-content pages: `<LegalContentPage kind="privacy" | "terms">` — renders
  the SAME legal HTML as the footer modals (`content.privacyPolicy` /
  `content.termsOfService` from `@molecule/app-locales-legal-default`), inside
  the branded `ContentPageShell` shell.
- In-place modals: `<LegalModalLinks>` + `useLegalModals()` — Privacy/Terms
  triggers that open modals instead of navigating.
- Primitives: `<ContentPageShell>` (hero band + surface card),
  `<LegalPageLayout>`, `<LegalPageSection>`.

This is the Angular counterpart of `@molecule/app-legal-pages-react`: the same
export names, the same props (React names), the same ClassMap tokens and the
same DOM for the same input. Switching framework is a change of package name
in the imports only.

#### `ContentPageShell`

ContentPageShell component.

Branded shell for public content pages (Privacy, Terms, Pricing,
PlanUpdated, …). The host IS the outer `<div>` (`div[mol-content-page-shell]`),
matching React's root exactly. The app's own chrome is projected content
(`[slot=header]`, `[slot=footer]`); the hero's eyebrow, title and subtitle are
`[slot=eyebrow]`, `[slot=title]` and `[slot=subtitle]`; the body is the
default projection.

React renders the hero only when a title is supplied, the eyebrow and
subtitle paragraphs only when their nodes are, and the body's surface card
only when `bare` is false — Angular's projection points must exist, so
{@link ContentPageShell.ngDoCheck} reconciles all four against React's DOM.

```typescript
  ngDoCheck(): void {
    this.sync()

  /**
   * Detaches the wrappers React would not render, at their own position so a
   * later pass can restore them.
   */
  private sync(): void {
    this.guard.toggle(this.heroEl?.nativeElement, hasNodes(this.titleEl?.nativeElement))
    this.guard.toggle(this.eyebrowEl?.nativeElement, hasNodes(this.eyebrowEl?.nativeElement))
    this.guard.toggle(this.subtitleEl?.nativeElement, hasNodes(this.subtitleEl?.nativeElement))
    this.syncBare()
  }

  /**
   * Applies React's `bare ? children : <div class="…surface…">{children}</div>`:
   * the card exists for its `<ng-content>` capture point, so `bare` unwraps it
   * by moving the projected nodes into the body container, and a later
   * non-bare pass puts them back.
   */
  private syncBare(): void {
    const card = this.cardEl?.nativeElement
    const body = this.bodyEl?.nativeElement
    if (!card || !body) return
    if (this.bare) {
      if (!card.isConnected) return
      const nodes = Array.from(card.childNodes).filter(
        (node) =>
          node.nodeType === 1 || (node.nodeType === 3 && (node.textContent ?? '').trim() !== ''),
      )
      for (const node of nodes) body.insertBefore(node, card)
      this.bareMoved = nodes
      card.remove()
      return
    }
    if (card.isConnected) return
    body.appendChild(card)
    for (const node of this.bareMoved) card.appendChild(node)
    this.bareMoved = []
  }
}
```

#### `LegalContentPage`

LegalContentPage component.

Standalone Privacy / Terms page that renders the SAME bonded legal HTML the
footer modal shows (`content.privacyPolicy` / `content.termsOfService`),
wrapped in the same shell `ContentPageShell` renders — the host IS React's
outer `<div>` (`div[mol-legal-content-page]`), and its template mirrors the
shell's markup so the header/footer chrome is projected straight into it.

The legal HTML renders through a sanitizer-bypassed `[innerHTML]`: React uses
`dangerouslySetInnerHTML` on app-supplied catalog content, and sanitizing
here would strip markup and render a different DOM. The `appName`
interpolated into that HTML is HTML-escaped first, exactly as React does.

```typescript
   * @returns The translated title.
   */
  titleText(): string {
    const title = TITLE[this.kind ?? 'privacy']
    return this.i18n.t(title.key, {}, { defaultValue: title.def })
  }

  /**
   * The legal body: the catalog HTML for `kind`, the app name escaped.
   * @returns The HTML string.
   */
  html(): string {
    const appName = this.appName
    return this.i18n.t(
      CONTENT_KEY[this.kind ?? 'privacy'],
      appName ? { appName: escapeHtml(appName) } : {},
      { defaultValue: '' },
    )
  }

  /**
   * Marks the legal HTML as safe for the `[innerHTML]` binding. This bypasses
   * Angular's sanitizer DELIBERATELY: the legal HTML is app-supplied catalog
   * content and React renders it with `dangerouslySetInnerHTML`; sanitizing
   * would strip markup and render a different DOM. Memoized by string so a
   * re-render carrying the same HTML does not re-parse it (React skips such an
   * update too).
   *
   * @returns The trusted value for `[innerHTML]`.
   */
  trustedHtml(): SafeHtml {
    const html = this.html()
    const hit = this.trusted.get(html)
    if (hit !== undefined) return hit
    if (this.trusted.size >= TRUSTED_CACHE_LIMIT) this.trusted.clear()
    const value = this.sanitizer.bypassSecurityTrustHtml(html)
    this.trusted.set(html, value)
    return value
  }

  /**
   * Runs the app's lazy loader (React's `useEffect` over `[loadContent, kind]`):
   * once when the inputs first exist and again whenever either changes.
   *
   * @param changes - The changed inputs.
   */
  ngOnChanges(changes: SimpleChanges): void {
    // React's dependency list is `[loadContent, kind]`: any other input change
    // must not re-run the loader.
    if (!changes['kind'] && !changes['loadContent']) return
    const load = this.loadContent
    Promise.resolve(load?.(MODULE[this.kind ?? 'privacy'])).then(
      () => undefined,
      // A loader failure is not this page's to report: React's effect ignores
      // it the same way, and the bonded content that did register renders.
      (_error) => undefined,
    )
  }
}
```

```typescript
          'This is the Terms page. Replace this placeholder with real content.',
      },
    )
  }

  /** Reads whether the body received projected content and applies the layout. */
  ngAfterViewInit(): void {
    this.hasContent = hasNodes(this.contentSlot?.nativeElement)
    this.syncBody()
  }

  /** Re-applies the body layout after projected-content changes. */
  ngDoCheck(): void {
    this.syncBody()
  }

  /**
   * React's `{children ?? <p>{intro}</p>}`: keeps the intro paragraph when
   * nothing was projected, and unwraps the projected body into its place when
   * something was.
   */
  private syncBody(): void {
    const intro = this.introEl?.nativeElement
    const slot = this.contentSlot?.nativeElement
    const parent = slot?.parentNode
    if (!intro || !slot || !parent) return
    if (!this.hasContent) {
      if (slot.isConnected) parent.removeChild(slot)
      return
    }
    if (intro.isConnected) parent.removeChild(intro)
    if (!slot.isConnected) return
    while (slot.firstChild) parent.insertBefore(slot.firstChild, slot)
    parent.removeChild(slot)
  }
}
```

### Functions

#### `useLegalModals(options)`

Headless hook powering in-place Privacy/Terms modals. Use it when the
triggers live in different parts of a bespoke footer (or a signup page);
render the modals component once and wire `openPrivacy`/`openTerms` to your
