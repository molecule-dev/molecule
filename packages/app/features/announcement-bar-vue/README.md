# @molecule/app-announcement-bar-vue

Vue announcement / promo bar.

Exports `<AnnouncementBar>` — persistent top-of-page banner with icon,
message, optional action (link or button), and optional dismiss (×).
Long-lived and prominent, unlike a Toast; carries an action slot +
dismiss, unlike an Alert. It is the Vue counterpart of
`@molecule/app-announcement-bar-react`: same props (React names), same DOM
for the same input, same ClassMap tokens and i18n keys.

### Constants

#### `AnnouncementBar`

Persistent announcement banner — product updates, promos, outage
notices, feature callouts. Different from `<Toast>` in being
long-lived and prominent (top-of-page), and from `<Alert>` in
including an action slot + dismiss.

Dismissal is uncontrolled by default (internal state) — pass `visible` to
control it. `kind` is exposed as `data-kind` only; it does not change the
bar's colors by itself.
