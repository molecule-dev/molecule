# @molecule/app-shell-layout-angular

Angular top-level app shell layout — the counterpart of
`@molecule/app-shell-layout-react`: the same props and the same DOM for the
same input.

Exports `<AppShellLayout>` — header slot + main content + footer slot, with
the page frame styled via the ClassMap bond. Apps fill the slots with their
own header, footer, and route content (typically the routed page).

## API

### Interfaces

#### `AppShellLayoutProps`

Props accepted by {@link AppShellLayout} — the same props
`@molecule/app-shell-layout-react` accepts. Node props (`header`, `footer`,
`children`) are projected content in Angular (an input cannot carry a node),
so they are typed `unknown`: pass them in the host template, not as values.

```typescript
interface AppShellLayoutProps {
  /** Slot for the header (typically the app's `<app-header>`), projected as `[slot=header]` content. */
  header?: unknown
  /** Slot for the footer (typically the app's `<app-footer>`), projected as `[slot=footer]` content. */
  footer?: unknown
  /** Main content, projected as the element's default content. */
  children?: unknown
  /** Container max-width for the main content. Defaults to `'xl'`. */
  maxWidth?: 'sm' | 'md' | 'lg' | 'xl' | '2xl' | 'full' | string
  /** Extra classes on the outer wrapper. */
  className?: string
  /**
   * Extra classes on the inner `<main>` element. Apps that need vertical
   * rhythm around the routed content pass it here instead of forking the
   * shell. Omitted by default so the `<main>` carries no padding.
   */
  mainClassName?: string
  /** `data-mol-id` for AI-agent selectors. */
  dataMolId?: string
}
```

### Classes

#### `AppShellLayout`

AppShellLayout component.

Top-level page scaffold: header → main (constrained by {@link Container}) →
footer. The host IS the outer `<div>` (`div[mol-shell-layout]`), matching
React's root exactly. The page frame uses ClassMap tokens (`cm.page`,
`cm.appLayout`) so the styling library can be swapped without touching
consumers. The header and footer are projected slots (`[slot=header]`,
`[slot=footer]`) so consumers retain full control over branding, navigation,
and footer copy.

```typescript
@Component({
  selector: 'div[mol-shell-layout]',
  standalone: true,
  imports: [Container],
  inputs: ['maxWidth', 'className', 'mainClassName', 'dataMolId'],
  host: {
    '[class]': 'classes()',
    '[attr.data-mol-id]': 'dataMolId ?? null',
  },
  template: `<ng-content select="[slot=header]"></ng-content>
    <main [class]="mainClassName">
      <div mol-container [maxWidth]="containerWidth()"><ng-content></ng-content></div>
    </main>
    <ng-content select="[slot=footer]"></ng-content>`,
})
export class AppShellLayout {
  /** Container max-width for the main content (defaults to `'xl'` at read time). */
  maxWidth?: 'sm' | 'md' | 'lg' | 'xl' | '2xl' | 'full' | string
  /** Extra classes on the outer wrapper. */
  className?: string
  /** Extra classes on the inner `<main>` element (no padding by default). */
  mainClassName?: string
  /** `data-mol-id` for AI-agent selectors. */
  dataMolId?: string

  /**
   * The current class map.
   * @returns The UIClassMap.
   */
  cm(): UIClassMap {
    return getClassMap()
  }

  /**
   * Computes the wrapper class list.
   * @returns The class string.
   */
  classes(): string {
    return this.cm().cn(this.cm().page, this.cm().appLayout, this.className)
  }

  /**
   * The container max width (React's default parameter: a later-bound write
   * of `undefined` must not erase the `'xl'` default).
   * @returns The max width.
   */
  containerWidth(): string {
    return this.maxWidth ?? 'xl'
  }
}
```

- `@molecule/app-ui`
- `@molecule/app-ui-angular`

- Requires a bonded ClassMap (frame uses `cm.page` + `cm.appLayout`) —
  rendering throws otherwise. No i18n or router dependency; the default
  content is just the typical routed child — any content works.
- Node props are projected content: `header` and `footer` are selected by
  `[slot=header]` / `[slot=footer]`, everything else lands in the main
  container as the default projection.
- The `<main>` carries no padding by default — pass `mainClassName`
  for vertical rhythm around routed content.
- Header/footer slots render as-is with no positioning — make your header
  sticky yourself if desired.
- Sibling: `@molecule/app-sidebar-layout-react` is the left-sidebar shell in
  React; this package is the top header/footer shell for Angular.
