# @molecule/app-settings-actions-bar-svelte

Svelte sticky Save/Cancel bar with "Saved" timestamp + loading state for
settings and form pages.

Exports `SettingsActionsBar`. Props: `onSave` (required; sync or async),
`onCancel?` (Cancel hidden when omitted), `loading?` (disables Save and
shows "Saving…"), `disabled?`, `savedAt?` (epoch ms → "Saved 3m ago"),
`error?` (inline snippet or string), `sticky?` (default true), `leading?`
(snippet/string before the status), `className?`.

This is the Svelte counterpart of `@molecule/app-settings-actions-bar-react`:
the same props (React names) and the same DOM for the same input.

  import { SettingsActionsBar } from '@molecule/app-settings-actions-bar-svelte'

  let saving = $state(false)
  let savedAt = $state<number | null>(null)

  async function save() {
    saving = true
    try {
      await api.saveProfile()
      savedAt = Date.now()
    } finally {
      saving = false
    }
  }
