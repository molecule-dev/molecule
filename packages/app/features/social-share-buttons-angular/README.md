# @molecule/app-social-share-buttons-angular

Angular social share buttons row.

Exports `<SocialShareButtons>` — the Angular counterpart of
`@molecule/app-social-share-buttons-react`, with the same props (React names)
and the same DOM, plus the `SocialPlatform` union. Twitter(X)/LinkedIn/
Facebook/Reddit/email/copy button group: each network button opens that
platform's share URL in a new tab and `'copy'` writes the URL to the
clipboard with "Copied!" feedback. `'x'` is an alias of `'twitter'` (same
intent URL). Default platforms: twitter, linkedin, facebook, copy.

### Classes

#### `SocialShareButtons`

SocialShareButtons component.

Row of share buttons — opens each platform's share sheet in a new tab.
`'copy'` copies the URL to the clipboard with "Copied!" feedback. The host IS
the outer `<div>` (`div[mol-social-share-buttons]`), matching React's root
exactly. Styling routes through the ClassMap token
`cm.flex({ align: 'center', gap: 'xs' })`.

Copying uses `navigator.clipboard`, which exists only in secure contexts —
elsewhere the button silently does nothing, as in React. Platform labels use
`share.<platform>` i18n keys and the copy feedback uses `share.copied`, read
through the binding's reactive `useTranslation()`, so a locale switch
refreshes the text (React's components re-render through `useTranslation()`).

```typescript
@Component({
  selector: 'div[mol-social-share-buttons]',
  standalone: true,
  imports: [Button],
  inputs: ['url', 'title', 'platforms', 'size', 'className'],
  host: {
    '[class]': 'classes()',
  },
  template: `@for (platform of platformsList(); track platform) {
    @if (platform === 'copy') {
      <button
        mol-button
        [variant]="'outline'"
        [size]="size ?? 'sm'"
        [attr.aria-label]="label(platform)"
        (click)="copy()"
      >
        {{ buttonLabel() }}
      </button>
    } @else {
      <a
        [href]="shareUrlFor(platform)"
        target="_blank"
        rel="noreferrer noopener"
        [attr.aria-label]="label(platform)"
      >
        <button mol-button [variant]="'outline'" [size]="size ?? 'sm'">
          {{ icon(platform) }}
        </button>
      </a>
    }
  }`,

export class SocialShareButtons implements OnDestroy {
  /** URL to share. */
  url?: string
  /** Optional share text / title. */
  title?: string
  /** Platforms to include (order = display order; defaults to twitter, linkedin, facebook, copy). */
  platforms?: SocialPlatform[]
  /** Visual size (defaults to `'sm'` at read time). */
  size?: 'sm' | 'md'
  /** Extra classes on the outer wrapper. */
  className?: string

  /**
   * Reactive translation, read in the injection context. Its `t` reads the
   * locale, so the view re-renders the text on a locale switch (the static `t`
   * does not).
   */
  private readonly i18n = useTranslation()

  /** Whether the last copy succeeded ("Copied!" is showing). */
  private readonly copied = signal(false)

  /** The pending feedback reset timer, cleared when the component dies. */
  private timer?: ReturnType<typeof setTimeout>

  /**
   * The current class map.
   * @returns The UIClassMap.
   */
  cm(): UIClassMap {
    return getClassMap()
  }

  /**
   * The wrapper class list (React's
   * `cm.cn(cm.flex({ align: 'center', gap: 'xs' }), className)`).
   * @returns The class string.
   */
  classes(): string {
    return this.cm().cn(this.cm().flex({ align: 'center', gap: 'xs' }), this.className)
  }

  /**
   * The platforms to render (React's `platforms` default parameter).
   * @returns The platform list.
   */
  platformsList(): SocialPlatform[] {
    return this.platforms ?? DEFAULT_PLATFORMS
  }

  /**
   * The platform's button glyph (React's `ICON[platform]`).
   * @param platform - The platform.
   * @returns The text glyph.
   */
  icon(platform: SocialPlatform): string {
    return ICON[platform]
  }

  /**
   * The platform's accessible label (React's `t(`share.${p}`, {}, { defaultValue: p })`).
   * @param platform - The platform.
   * @returns The label text.
   */
  label(platform: SocialPlatform): string {
    return this.i18n.t(`share.${platform}`, undefined, { defaultValue: platform })
  }

  /**
   * The platform's share URL (React's `shareUrl(p, url, title)`).
   * @param platform - The platform.
   * @returns The share URL (the raw url for the copy platform).
   */
  shareUrlFor(platform: SocialPlatform): string {
    return shareUrl(platform, this.url ?? '', this.title)
  }

  /**
   * The copy button's text: "Copied!" while the feedback shows, the copy glyph
   * otherwise (React's `copied ? t('share.copied', …) : ICON.copy`).
   * @returns The button text.
   */
  buttonLabel(): string {
    return this.copied()
      ? this.i18n.t('share.copied', undefined, { defaultValue: 'Copied!' })
      : ICON.copy
  }

  /**
   * Copies the URL, then shows the "Copied!" feedback for 1.5 s.
   */
  copy(): void {
    if (typeof navigator !== 'undefined' && navigator.clipboard) {
      void navigator.clipboard.writeText(this.url ?? '').then(() => {
        this.copied.set(true)
        this.timer = setTimeout(() => this.copied.set(false), 1500)
      })
    }
  }

  /** Detaches the feedback timer with the component. */
  ngOnDestroy(): void {
    clearTimeout(this.timer)
  }
}
```

### Runtime Dependencies

- `@angular/common`
- `@angular/core`
- `@angular/platform-browser`
- `@molecule/app-angular`
- `@molecule/app-ui`
- `@molecule/app-ui-angular`

- Must render inside the app's i18n provider and with a ClassMap bond wired
  (`useTranslation()` / `getClassMap()` throw otherwise).
- `'copy'` uses `navigator.clipboard`, which exists only in secure contexts
  (HTTPS or localhost). On plain HTTP the button silently does nothing —
  hide it or serve over HTTPS.
- Sharing uses fixed platform intent URLs opened in a new tab; there is no
  Web Share API integration and no per-platform SDKs.
- Button icons are plain text glyphs (𝕏, "in", "f", ✉, ⧉), not brand SVG
  logos — restyle via `className` if brand marks are required.
- Only `share.copied` ships in the companion locale bond today; the
  per-platform `share.<platform>` aria-label keys fall back to the raw
  platform id in every language.
