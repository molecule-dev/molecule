# @molecule/app-contact-form-angular

Angular generic contact form — the counterpart of
`@molecule/app-contact-form-react`: the same props and the same DOM for the
same input.

Exports `<ContactForm>` and the `ContactFormValues` type: name + email +
message fields with submit handling and success state, plus an `extraFields`

### Classes

#### `ContactForm`

ContactForm component.

Generic name + email + message contact form with submit handling and success
state; the app owns the side-effect via the `onSubmit` input. React's root
element is a `<form>` while idle and a `<div>` once `successContent` renders,
so the rendered root stands in front of the host's place and the host itself
leaves the page (`placeContentBefore` + `setElementPresent`, React's fragment
root).

The optional title and description are text inputs or projected content
(`[slot=title]`, `[slot=description]`); `extraFields` is projected content
(`[slot=extraFields]`) rendered above the message textarea, as React renders
it. The submit label and success content are inputs (`TemplateRef` or
string), because their regions only exist inside conditional branches.

  showDescription(): boolean {
    return (

      isTemplate(this.description) ||
      this.descriptionProjected() === true

    return this.cm().stack(1)

    this.email.set((event.target as HTMLInputElement).value)

  onMessageChange(event: Event): void {
    this.message.set((event.target as HTMLTextAreaElement).value)
  }

  async handle(event: Event): Promise<void> {
    event.preventDefault()
    if (this.submitting()) return
    this.submitting.set(true)
    this.error.set(null)
    try {
      await this.onSubmit?.({
        name: this.name(),
        email: this.email(),
        message: this.message(),

      this.submitted.set(true)
      this.name.set('')
      this.email.set('')
      this.message.set('')

      this.error.set(
        err instanceof Error
          ? err.message
          : this.i18n.t(
              'contactForm.error.submissionFailed',
              {},
              { defaultValue: 'Submission failed' },
            ),
      )
    } finally {
      this.submitting.set(false)
    }
  }
}

Requires a wired ClassMap bond and `@molecule/app-angular`'s i18n provider
above it — `getClassMap()` and `useTranslation()` both throw before wiring.
Pair with `@molecule/app-locales-contact-form` for the placeholder / button
strings in 79 languages.

`onSubmit` receives ONLY `{ name, email, message }` — inputs rendered via the
`[slot=extraFields]` projection are displayed but NOT collected; own their
state in the parent and merge them inside your `onSubmit`. Always pass
`successContent`: without it the form clears silently after a successful
submit. If `onSubmit` throws, the thrown `Error.message` is shown verbatim
below the form — throw translated, user-safe messages.

Node props are `TemplateRef`s or strings; `title`, `description` and
`extraFields` may also be projected as `[slot=title]`, `[slot=description]`
and `[slot=extraFields]` content.
