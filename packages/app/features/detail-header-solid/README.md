# @molecule/app-detail-header-solid

Solid detail-page header.

Exports `DetailHeader` — the Solid counterpart of
`@molecule/app-detail-header-react` with the same props and the same DOM:
leading slot + title/subtitle + status + right-aligned actions, with an
optional meta row and an optional search slot. Different from
`<PageHeader>` (top of list/index pages) in prioritising status + search +
stickiness for long-scrolling detail screens. All slots are JSX props —
compose any components.
