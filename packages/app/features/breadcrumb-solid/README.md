# @molecule/app-breadcrumb-solid

Solid breadcrumb navigation component.

Exports `Breadcrumb` — the Solid counterpart of
`@molecule/app-breadcrumb-react` with the same props and the same DOM:
a list of crumbs where each but the last is a link. The final crumb
renders as plain text with `aria-current="page"`. Pass `onNavigate` to
intercept clicks and hand off to a router.

### Functions

#### `Breadcrumb(props)`

Breadcrumb navigation.

Each item before the last is rendered as a link; the last item is
rendered as plain text (the "current page"). Pass `onNavigate` to
intercept clicks (e.g. hand off to a router's navigate). Without it,
crumbs render as plain `<a href>` anchors.

This is the Solid counterpart of `@molecule/app-breadcrumb-react`: the
same props (React names), the same ClassMap tokens, and the same DOM for
the same input. The separator renders once per gap; a caller's separator
node is cloned per gap, because a DOM node can only live in one place —
React renders the same element in every gap.

```typescript
function Breadcrumb(props: BreadcrumbProps): JSX.Element
```

- `props` — Component props (see {@link BreadcrumbProps}).

**Returns:** The rendered breadcrumb.

Without `onNavigate`, crumbs render as plain `<a href>` (full page
load in SPAs) — pass `onNavigate={(to) => navigate(to)}` to stay
client-side; with it, crumbs render as `<button>`s. The last item (or
any item without `to`) renders as plain text with `aria-current="page"`.
No router dependency is required by the component itself. The separator
renders per gap (the default `/`, or the `separator` node cloned per
gap — a DOM node can only live in one place).
