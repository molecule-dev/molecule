# @molecule/app-node-editor-panel-angular

`@molecule/app-node-editor-panel-angular` — right-side properties panel for
node-based editors (chatbot-builder bot nodes, workflow canvases,
design-tool inspector panes). The Angular counterpart of
`@molecule/app-node-editor-panel-react`: the same exports, the same props
(React names) and the same DOM for the same input.

Composable sub-primitives:

- `<NodeEditorPanel>` — aside chrome with title row, scroll body, footer.
- `<NodeEditorSection>` — labeled section with optional trailing slot.
- `<NodeEditorSlider>` — range slider with mono-font value chip.
- `<NodeEditorToggle>` — switch row with optional icon tile.
- `<NodeEditorRadioGroup>` — radio list with custom radio dots.

Consumer brings the form state; the package handles structure and styling.

```typescript
export class NodeEditorRadioGroup {
  /** The selectable options. */
  options: NodeEditorRadioOption[] = []
  /** The selected value. */
  value!: string
  /** Called with the option selected by a click, keyboard or assistive technology. */
  onChange?: (next: string) => void

  /**
   * The group's generated name, one per instance (see {@link generatedName}).
   */

  /**
   * The current class map.
   * @returns The UIClassMap.
   */
  cm(): UIClassMap {
    return getClassMap()
  }

  /**
   * Reports the selected option, then restores the radio group's live
   * `checked` state to the controlled value — React restores controlled inputs
   * after an event even when the render output is unchanged.
   * @param next - The option that was selected.
   * @param event - The native change event.
   */
  select(next: string, event: Event): void {
    this.onChange?.(next)
    const group = (event.target as HTMLElement).closest('[role="radiogroup"]')
    if (!group) return
    for (const input of Array.from(
      group.querySelectorAll<HTMLInputElement>('input[type="radio"]'),
    )) {
      input.checked = input.value === this.value
    }
  }

  /**
   * The hidden radio's class list (React's `cm.srOnly`).
   * @returns The class string.
   */
  srOnlyClass(): string {
    return this.cm().cn(this.cm().srOnly)
  }

  /**
   * The host's class list (React's `cm.grid({ cols: 1, gap: 2 })`).
   * @returns The class string.
   */
  classes(): string {
    return this.cm().grid({ cols: 1, gap: 2 })
  }

  /**
   * One option tile's class list.
   * @param option - The option.
   * @returns The class string.
   */
  optionClasses(option: NodeEditorRadioOption): string {
    const cm = this.cm()
    return cm.cn(
      cm.flex({ align: 'center', justify: 'between' }),
      cm.sp('p', 3),
      cm.cursorPointer,
      option.value === this.value ? cm.nodeEditorPanelOptionSelected : cm.nodeEditorPanelOption,
    )
  }

  /**
   * One option label's class list.
   * @param option - The option.
   * @returns The class string.
   */
  optionLabelClasses(option: NodeEditorRadioOption): string {
    const cm = this.cm()
    return cm.cn(
      cm.textSize('xs'),
      option.value === this.value
        ? cm.nodeEditorPanelOptionLabelSelected
        : cm.nodeEditorPanelOptionLabel,
    )
  }

  /**
   * One option radio ring's class list.
   * @param option - The option.
   * @returns The class string.
   */
  ringClasses(option: NodeEditorRadioOption): string {
    const cm = this.cm()
    return cm.cn(
      cm.nodeEditorPanelRadioRing,
      option.value === this.value
        ? cm.nodeEditorPanelRadioRingSelected
        : cm.nodeEditorPanelRadioRingIdle,
    )
  }

  /**
   * The selected option's inner dot class list.
   * @returns The class string.
   */
  dotClasses(): string {
    const cm = this.cm()
    return cm.cn(cm.w(2), cm.h(2), cm.roundedFull, cm.bgPrimary)
  }

  /**
   * Whether a label is a projected template.

    return value as TemplateRef<unknown>
```

```typescript
  /**
   * Parses the range input's value, reports it, then restores the controlled
   * value in the DOM as React does after a change.
   * @param event - The native change event.
   */
  handleChange(event: Event): void {
    const element = event.target as HTMLInputElement
    this.onChange?.(parseFloat(element.value))
    element.value = String(this.value)
  }

  /**
   * The host's class list (React's `cm.stack(3)`).
   * @returns The class string.
   */
  classes(): string {
    return this.cm().stack(3)
  }

  /**
   * The label row's class list.
   * @returns The class string.
   */
  rowClasses(): string {
    return this.cm().flex({ justify: 'between', align: 'center' })
  }

  /**
   * The label's class list.
   * @returns The class string.
   */
  labelClasses(): string {
    const cm = this.cm()
    return cm.cn(cm.fontWeight('bold'), cm.nodeEditorPanelSectionLabel)
  }

  /**
   * The value chip's class list.
   * @returns The class string.
   */
  valueClasses(): string {
    const cm = this.cm()
    return cm.cn(cm.textSize('xs'), cm.sp('px', 2), cm.nodeEditorPanelSliderValue)
  }

  /**
   * The range input's class list.
   * @returns The class string.
   */
  inputClasses(): string {
    const cm = this.cm()
    return cm.cn(cm.w('full'), cm.h(1.5), cm.cursorPointer, cm.nodeEditorPanelSliderTrack)
  }
```

#### `NodeEditorToggle`

NodeEditorToggle component.

iOS-style switch row with an optional leading icon tile. The host IS the
outer `<div>` (`div[mol-node-editor-toggle]`), matching React's root exactly;
the switch is the `<mol-switch>` from `@molecule/app-ui-angular`.

Node props are projected content: `title` is `[slot=title]` and `subtitle`
is `[slot=subtitle]`. Plain strings may also be passed as inputs.

```typescript
@Component({
  selector: 'div[mol-node-editor-toggle]',
  standalone: true,
  hostDirectives: [MolPlacement],
  imports: [Switch],
  inputs: ['title', 'subtitle', 'icon', 'checked', 'onChange', 'ariaLabel'],
  host: {
    '[class]': 'classes()',
  },
  template: `<div [class]="groupClasses()">
      @if (icon) {
        <div [class]="iconTileClasses()">
          <span [class]="iconClasses()">{{ icon }}</span>
        </div>
      }
      <div>
        <p [attr.id]="titleId" [class]="titleClasses()">
          @if (hasTitle) {
            {{ title }}
          }
          <ng-content select="[slot=title]" />
        </p>
        <p #subtitleEl [attr.id]="subtitleId" [class]="subtitleClasses()">
          @if (rendersSubtitle()) {
            {{ subtitle }}
          }
          <ng-content select="[slot=subtitle]" />
        </p>
      </div>
    </div>
    <mol-switch
      [size]="'sm'"
      [checked]="checked"
      data-mol-id="node-editor-toggle"
      (change)="handleChange($event)"
    ></mol-switch>`,
})
export class NodeEditorToggle implements AfterViewChecked {
  /** Row title — a string input, or `[slot=title]` projected content. */
  title?: unknown
  /** Optional second line — a string input, or `[slot=subtitle]` projected content. */
  subtitle?: unknown
  /** Material-symbols icon for the leading tile (omit for no tile). */
  icon?: string
  /** Whether the switch is on. */
  checked!: boolean
  /** Called with the switch's next checked state. */
  onChange?: (next: boolean) => void
  /** Accessible label for the switch (overrides the title paragraph as its name). */
  ariaLabel?: string

  /** The instance's id base for the title and subtitle paragraphs (where React's binding calls `useId()`). */
  private readonly instanceId = nextToggleId++
  /** The title paragraph's id, which names the switch unless `ariaLabel` overrides it. */
  readonly titleId = `node-editor-toggle-title-${this.instanceId}`
  /** The subtitle paragraph's id, which describes the switch when one renders. */
  readonly subtitleId = `node-editor-toggle-subtitle-${this.instanceId}`

  /** The host element (the root `<div>`). */
  private readonly host = inject(ElementRef)

  /** The optional subtitle paragraph (its projected nodes decide whether it shows). */
  @ViewChild('subtitleEl', { static: true }) private subtitleEl?: ElementRef<HTMLElement>

  /** Whether the subtitle paragraph renders (placement decides, so a refilled slot returns). */
  private readonly subtitleShown = signal(false)

  /**
   * Keeps the subtitle paragraph on the page only while it renders a text input
   * or projected `[slot=subtitle]` content, re-decided whenever either changes.
   */
  constructor() {
    usePlacement((hasContent) => {
      const subtitleEl = this.subtitleEl?.nativeElement
      const showSubtitle =
        rendersNode(this.subtitle) || (subtitleEl ? hasContent(subtitleEl) : false)
      this.subtitleShown.set(showSubtitle)
      setElementPresent(subtitleEl, showSubtitle)
    })
  }

  /**
   * The current class map.
   * @returns The UIClassMap.
   */
  cm(): UIClassMap {
    return getClassMap()
  }

  /**
   * Whether a string title input renders (a projected title is not).
   * @returns True when the title input renders as text.
   */
  get hasTitle(): boolean {
    return rendersNode(this.title)
  }

  /**
   * Whether the subtitle paragraph interpolates a string input.
   * @returns True when the subtitle input renders as text.
   */
  rendersSubtitle(): boolean {
    return rendersNode(this.subtitle)
  }

  /**
   * Whether the subtitle paragraph renders: a truthy string input or a
   * projected `[slot=subtitle]` element.
   * @returns True when the subtitle shows.
   */
  showSubtitle(): boolean {
    return rendersNode(this.subtitle) || this.subtitleShown()
  }

  /**
   * Applies the switch's accessible name and description to the element that
   * carries `role="switch"`.
   *
   * `<mol-switch>` moves host `aria-*` attributes onto its trigger button once,
   * at its own view check, so a binding that CLEARS later (the subtitle goes
   * away) would leave the moved copy behind on the button. Writing the three
   * attributes on the button on every pass keeps them in step with React's
   * render, removals included. Children check before their parent, so this runs
   * after the switch's own move.
   */
  ngAfterViewChecked(): void {
    const button = (this.host.nativeElement as HTMLElement).querySelector('button[role="switch"]')
    if (!button) return
    const attrs: [string, string | undefined][] = [
      ['aria-label', this.ariaLabel],
      // React names the switch by the title paragraph unless `ariaLabel` is given.
      ['aria-labelledby', this.ariaLabel === undefined ? this.titleId : undefined],
      ['aria-describedby', this.showSubtitle() ? this.subtitleId : undefined],
    ]
    for (const [name, value] of attrs) {
      if (value === undefined) button.removeAttribute(name)
      else button.setAttribute(name, value)
    }
  }

  /**
   * Forwards the switch's genuine native change event, reading the hidden
   * checkbox's `checked` at emit time (React reads `e.target.checked`).
   * @param event - The native change event.
   */
  handleChange(event: Event): void {
    this.onChange?.((event.target as HTMLInputElement | null)?.checked ?? false)
  }

  /**
   * The host's class list.
   * @returns The class string.
   */
  classes(): string {
    const cm = this.cm()
    return cm.cn(
      cm.sp('p', 4),
      cm.flex({ align: 'center', justify: 'between' }),
      cm.nodeEditorPanelToggleRow,
    )
  }

  /**
   * The left group's class list.
   * @returns The class string.
   */
  groupClasses(): string {
    const cm = this.cm()
    return cm.cn(cm.flex({ align: 'center' }), cm.nodeEditorPanelToggleGroup)
  }

  /**
   * The icon tile's class list.
   * @returns The class string.
   */
  iconTileClasses(): string {
    const cm = this.cm()
    return cm.cn(cm.sp('p', 2), cm.nodeEditorPanelToggleIconTile)
  }

  /**
   * The icon glyph's class list.
   * @returns The class string.
   */
  iconClasses(): string {
    const cm = this.cm()
    return cm.cn(cm.textSize('sm'), cm.iconGlyphFont)
  }

  /**
   * The title's class list.
   * @returns The class string.
   */
  titleClasses(): string {
    const cm = this.cm()
    return cm.cn(cm.textSize('xs'), cm.fontWeight('semibold'), cm.nodeEditorPanelToggleTitle)
  }

  /**
   * The subtitle's class list.
   * @returns The class string.
   */
  subtitleClasses(): string {
    return this.cm().cn(this.cm().nodeEditorPanelToggleSubtitle)
  }
}
```

Node-valued props are projected content: each component's `[slot=<name>]`
selector (`title`, `footer`, `label`, `trailing`, `valueDisplay`, `subtitle`)
carries the nodes, and the host's default content is the body. Plain strings
may also be passed as inputs.

KNOWN LIMITATION — this package styles itself with the same Tailwind classes
and Material-3 color tokens as the React package (`bg-surface-container-low`,
`text-on-surface-variant`, `border-outline-variant`, `accent-primary`,
`w-80`, …) resolved through the ClassMap bond. Out of the box in a standard
molecule app the panel renders UNSTYLED because (a) the app's Tailwind build
does not scan this package's dist for class literals, and (b) the M3 color
tokens are not defined by standard themes. To adopt it today you must add an
`@source "<path-to>/app-node-editor-panel-angular/dist"` line to the app's
Tailwind CSS AND define the referenced `surface-container-*` / `on-surface*` /
`outline-variant` theme colors.

The close button and `NodeEditorToggle.icon` render Material Symbols
LIGATURES — without the "Material Symbols Outlined" font loaded and a
`material-symbols-outlined` CSS class defined, icon names render as plain
text (e.g. the word "close").

A wired ClassMap bond is still required for the layout helpers —
`getClassMap()` throws before wiring. The close button's default aria-label is
the `nodeEditorPanel.close` key, translated by `@molecule/app-locales-node-editor-panel`
through the app's i18n provider (English when none is bonded).
