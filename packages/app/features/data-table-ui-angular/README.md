# @molecule/app-data-table-ui-angular

Angular data-table UI primitives (standalone — they render plain table
elements and do not require a table component from a UI package).

Exports:

- `<DataTableCard>` — full polished-pattern data table (card wrapper +
  title + uppercase headers + divided rows + loading skeleton + empty
  state). Drop-in for the most common dashboard CRUD use case.
- `<TableToolbar>` — top chrome with left/right slots + optional filter row.
- `<TableEmpty>` — single full-width "no rows" cell for hand-rolled tables.
- `<TableFooter>` — bottom bar (left summary + right pagination).
- `<RowWithActions>` — `<tr>` wrapper with trailing actions cell and click handler.

Use `DataTableCard` for new screens; use the row-level primitives to compose
richer custom tables (group-by, expandable rows, etc.).

This package is the Angular counterpart of `@molecule/app-data-table-ui-react`:
the same export names, the same props (React's prop names), and the same DOM
for the same input, so an app swaps framework by changing only the package
name in its imports. Each component's host element IS React's root element
(`section[mol-data-table-card]`, `tr[mol-row-with-actions]`, …). Node props
are projected content (`[slot=<name>]`), a `TemplateRef`, or text.

DataTableCard component.

Drop-in card-shaped data table matching the polished flagship pattern — the
Angular counterpart of `@molecule/app-data-table-ui-react`'s
`DataTableCard`: the same props (React names), the same ClassMap tokens, and
the same DOM for the same input. The host IS the outer `<section>`

Renders an optional title row (title + action), then a card-wrapped table

spanning empty cell. Rows are keyed by `rowKey(row)` (React's

    this.onRowClick?.(row)

    this.syncVisibility()
  }

  ngDoCheck(): void {
    this.syncVisibility()
  }

  private syncVisibility(): void {
    const heading = this.titleHeading?.nativeElement
    const titleShown = this.title !== undefined || hasContent(heading)
    this.conditional.sync(this.headerRow?.nativeElement, titleShown || this.hasTitleAction())
    this.conditional.sync(heading, titleShown)
  }

  private hasTitleAction(): boolean {
    if (this.titleAction !== undefined) return true
    const row = this.headerRow?.nativeElement
    if (!row) return false
    const heading = this.titleHeading?.nativeElement
    return Array.from(row.childNodes).some(
      (node) =>
        node !== heading &&
        (node.nodeType === Node.ELEMENT_NODE ||
          (node.nodeType === Node.TEXT_NODE && (node.textContent ?? '').trim() !== '')),
    )
  }
}

      : ''
  }

   * The actions' template, when the caller passed a node.
   * @returns The template, or null.
   */
  actionsTemplate(): TemplateRef<unknown> | null {
    return templateOf(this.actions)
  }

  /**
   * Runs the row's click handler the way React's `onClick` does.
   * @param event - The native click event.
   */

    this.onClick?.(event)
  }

   * Stops a click inside the actions cell from reaching the row (React's

   * @param event - The native click event.
   */

    event.stopPropagation()
  }

  ngAfterViewInit(): void {
    this.syncActions()
  }

  /** Re-reconciles the actions cell after input writes. */
  ngDoCheck(): void {
    this.syncActions()

  /** Keeps the actions cell in the DOM exactly while React renders it. */

    const cell = this.actionsCell?.nativeElement
    this.conditional.sync(cell, this.actions !== undefined || hasContent(cell))

names), the same ClassMap tokens, and the same DOM for the same input. The
host IS the outer stack `<div>` (`div[mol-table-toolbar]`), matching React's
root exactly. `left`, `right` and `below` are `[slot=…]` content,
`TemplateRef`s, or text.

```typescript
@Component({
  selector: 'div[mol-table-toolbar]',
  standalone: true,
  imports: [NgTemplateOutlet],
  inputs: ['left', 'right', 'below', 'className'],
  host: { '[class]': 'classes()' },
  template: `<div [class]="rowClasses()">
      <div [class]="sectionClasses()">
        <ng-content select="[slot=left]"></ng-content>
        @if (leftTemplate(); as tpl) {
          <ng-container [ngTemplateOutlet]="tpl" />
        }
        {{ leftText() }}
      </div>
      <div [class]="sectionClasses()">
        <ng-content select="[slot=right]"></ng-content>
        @if (rightTemplate(); as tpl) {
          <ng-container [ngTemplateOutlet]="tpl" />
        }
        {{ rightText() }}
      </div>
    </div>
    <ng-content select="[slot=below]"></ng-content>
    @if (belowTemplate(); as tpl) {
      <ng-container [ngTemplateOutlet]="tpl" />
    }
    {{ belowText() }}`,
})
export class TableToolbar {
  /** Left-aligned content (a `TemplateRef` or `[slot=left]` content). */
  left?: unknown
  /** Right-aligned actions (a `TemplateRef` or `[slot=right]` content). */
  right?: unknown
  /** Optional filter sub-row (a `TemplateRef` or `[slot=below]` content). */
  below?: unknown
  /** Extra classes. */
  className?: string

  /**
   * The current class map.
   * @returns The UIClassMap.
   */
  cm(): UIClassMap {
    return getClassMap()
  }

  /**
   * The toolbar's class list (`stack(2)` + the caller's classes).
   * @returns The class string.
   */
  classes(): string {
    return this.cm().cn(this.cm().stack(2), this.className)
  }

  /**
   * The left/right row's class list (`flex between/center, gap sm, wrap`).
   * @returns The class string.
   */
  rowClasses(): string {
    return this.cm().flex({ justify: 'between', align: 'center', gap: 'sm', wrap: 'wrap' })
  }

  /**
   * One left/right section's class list (`flex center, gap sm`).
   * @returns The class string.
   */
  sectionClasses(): string {
    return this.cm().flex({ align: 'center', gap: 'sm' })
  }

  /**
   * The left slot's text (React's `{left}` for text).
   * @returns The text, or `''` for a node slot.
   */
  leftText(): string {
    return typeof this.left === 'string' || typeof this.left === 'number' ? textOf(this.left) : ''
  }

  /**
   * The left slot's template, when the caller passed a node.
   * @returns The template, or null.
   */
  leftTemplate(): TemplateRef<unknown> | null {
    return templateOf(this.left)
  }

  /**
   * The right slot's text (React's `{right}` for text).
   * @returns The text, or `''` for a node slot.
   */
  rightText(): string {
    return typeof this.right === 'string' || typeof this.right === 'number'
      ? textOf(this.right)
      : ''
  }

  /**
   * The right slot's template, when the caller passed a node.
   * @returns The template, or null.
   */
  rightTemplate(): TemplateRef<unknown> | null {
    return templateOf(this.right)
  }

  /**
   * The filter row's text (React's `{below}` for text).
   * @returns The text, or `''` for a node row.
   */
  belowText(): string {
    return typeof this.below === 'string' || typeof this.below === 'number'
      ? textOf(this.below)
      : ''
  }

  /**
   * The filter row's template, when the caller passed a node.
   * @returns The template, or null.
   */
  belowTemplate(): TemplateRef<unknown> | null {
    return templateOf(this.below)
  }
}
```

### Runtime Dependencies

- `@angular/common`
- `@angular/core`
- `@angular/platform-browser`
- `@molecule/app-angular`
- `@molecule/app-ui`
- `@molecule/app-ui-angular`

All text (`title`, column `header`s, `emptyMessage`) is consumer-provided —
pass translated strings; there is no built-in copy and no locale bond.
`DataTableCard`'s chrome uses Tailwind classes with Material-3 theme tokens
(`bg-surface-container-lowest`, `divide-surface-container`,
`text-on-surface-variant`, …) — the app's Tailwind theme must define those
tokens (molecule's default Tailwind ClassMap bond does); with a non-Tailwind
ClassMap the card surface, dividers, and skeleton styling drop out.
`onRowClick` makes rows pointer-clickable only — add your own keyboard path
(e.g. a link/button in a cell) where accessibility matters.

Rows are keyed by `rowKey(row)` (React's `key={rowKey(row)}`), so a row keeps
its DOM node while its key is unchanged.
