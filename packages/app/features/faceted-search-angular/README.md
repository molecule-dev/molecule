# @molecule/app-faceted-search-angular

`@molecule/app-faceted-search-angular` — composable building blocks for
pinned faceted filter bars across property / catalog / report pages.

Angular counterpart of `@molecule/app-faceted-search-react`: the same
exports, the same props (React names), the same ClassMap tokens and the same
DOM for the same input. Each component's host element IS React's root
element, so an app switches framework by changing only the import.

- `<div mol-faceted-search-segmented-control>` — pill toggle group
  (Buy / Rent / All).
- `<div mol-faceted-search-filter-pill>` — outlined pill trigger + dropdown
  panel; the default projection becomes the panel content.
- `<div mol-faceted-search-bar>` — fixed-position horizontal container that
  wraps the row of primitives.

Each filter pill owns its dropdown content so consumers can drop in range
sliders, checkbox lists, selects, etc.

#### `FilterPill`

FilterPill component.

Outlined filter pill with an optional `expand_more` chevron and a dropdown
panel that opens beneath it. The host IS the React root `<div>`
(`div[mol-faceted-search-filter-pill]`), carrying React's `position:
relative` class. The pill is the trigger; the panel content arrives as the
element's default projection and the label as text, a `TemplateRef`, or
`[slot=label]` content. React renders the panel `<div>` only while it is
open, so the always-mounted projection wrapper is detached and restored to
match.

```typescript
@Component({
  selector: 'div[mol-faceted-search-filter-pill]',
  standalone: true,
  hostDirectives: [MolPlacement],
  imports: [NgTemplateOutlet],
  inputs: ['label', 'active', 'hideChevron', 'leadingIcon', 'panelAlign', 'dataMolId'],
  host: {
    '[class]': 'classes()',
  },
  // Icon-font ligature names are decoration (aria-hidden): the pill's own label
  // names the filter, so screen readers must not read the glyphs out.
  // prettier-ignore
  template: `<button type="button" aria-haspopup="true" [attr.aria-expanded]="isOpen() ? })
export class FilterPill implements OnDestroy {
  /** Pill label: text, a template ref, or projected `[slot=label]` content. */
  label?: string | TemplateRef<unknown>
  /** Highlight pill when a filter value is applied. */
  active?: boolean
  /** Hide chevron (e.g. "More filters" pill uses a tune icon instead). */
  hideChevron?: boolean
  /** Leading icon (material-symbols name). */
  leadingIcon?: string
  /** Panel position relative to the trigger (defaults to `'left'` at read time). */
  panelAlign?: 'left' | 'right'
  /** `data-mol-id` for AI-agent selectors, on the trigger button. */
  dataMolId?: string

  /** The panel `<div>` (detached while closed, as React renders it conditionally). */
  @ViewChild('panelWrap') private panelWrap?: ElementRef<HTMLElement>

  /** Whether the panel is open (React's `useState(false)`). */
  private readonly open = signal(false)
  /** Whether the document mousedown listener is currently attached. */
  private listening = false

  /** The host element (the React root `<div>`). */
  private readonly host = inject(ElementRef<HTMLElement>)
  /**
   * The component's change detector. React re-renders from the outside-click
   * listener; a zoneless Angular view only refreshes when it is marked, and a
   * manually added document listener marks nothing on its own.
   */
  private readonly cdr = inject(ChangeDetectorRef)

  constructor() {
    usePlacement((hasContent) => this.reconcile(hasContent))
  }

  /**
   * Removes the outside-mousedown listener.
   */
  ngOnDestroy(): void {
    this.detachListener()
  }

  /**
   * The current class map.
   * @returns The UIClassMap.
   */
  cm(): UIClassMap {
    return getClassMap()
  }

  /**
   * Computes the wrapper's class list (React's `cn(position('relative'))`).
   * @returns The class string.
   */
  classes(): string {
    return this.cm().cn(this.cm().position('relative'))
  }

  /**
   * Computes the trigger's class list, exactly as React composes it.
   * @returns The class string.
   */
  triggerClasses(): string {
    return this.cm().cn(
      this.cm().tabsTrigger({ variant: 'soft-rounded', size: 'sm' }),
      this.cm().fontWeight('medium'),
      this.cm().touchTargetCompact,
    )
  }

  /**
   * Computes the trigger's inner row class (React's `flex({ align: 'center', gap: 'sm' })`).
   * @returns The class string.
   */
  innerClasses(): string {
    return this.cm().flex({ align: 'center', gap: 'sm' })
  }

  /**
   * Computes a glyph span's class list (the leading icon and the chevron).
   * @returns The class string.
   */
  iconClasses(): string {
    return this.cm().cn(this.cm().textSize('sm'), this.cm().iconGlyphFont)
  }

  /**
   * Computes the panel's class list (React's left/right branch).
   * @returns The class string.
   */
  panelClasses(): string {
    return this.cm().cn(
      this.cm().sp('mt', 2),
      this.cm().sp('p', 4),
      this.cm().facetedSearchPillPanel,
      (this.panelAlign ?? 'left') === 'right'
        ? this.cm().facetedSearchPillPanelRight
        : this.cm().facetedSearchPillPanelLeft,
    )
  }

  /**
   * Whether the panel is open.
   * @returns The open state.
   */
  isOpen(): boolean {
    return this.open()
  }

  /**
   * Toggles the panel, attaching or removing React's outside-mousedown listener
   * with it.
   */
  toggle(): void {
    this.open.update((value) => !value)
    if (this.open()) this.attachListener()
    else this.detachListener()
    this.cdr.markForCheck()
  }

  /**
   * The label as a template, when the caller passed one.
   * @returns The label template, or null.
   */
  labelTemplate(): TemplateRef<unknown> | null {
    return isTemplate(this.label) ? this.label : null
  }

  /**
   * The label input's text (React renders strings and numbers; a projected
   * label is not repeated as text).
   * @returns The text, or `''`.
   */
  labelText(): string {
    if (this.label === undefined || this.label === null || isTemplate(this.label)) return ''
    return textOf(this.label)
  }

  /**
   * Applies React's condition for the panel: it renders only while open and
   * only when there is content.
   *
   * @param hasContent - Reads whether a slot has content.
   */
  private reconcile(hasContent: SlotReader): void {
    const panel = this.panelWrap?.nativeElement
    if (!panel) return
    setElementPresent(panel, this.open() && hasContent(panel))
  }

  /**
   * Closes the panel when a mousedown occurs outside the host element (React's
   * outside-click effect, which only exists while the panel is open).
   * @param event - The document mousedown.
   */
  private readonly onDoc = (event: MouseEvent): void => {
    if (!this.open()) return
    if (this.host.nativeElement.contains(event.target as Node)) return
    this.open.set(false)
    this.detachListener()
    this.cdr.markForCheck()
  }

  /** Attaches the document mousedown listener once. */
  private attachListener(): void {
    if (this.listening) return
    document.addEventListener('mousedown', this.onDoc)
    this.listening = true
  }

  /** Removes the document mousedown listener. */
  private detachListener(): void {
    if (!this.listening) return
    document.removeEventListener('mousedown', this.onDoc)
    this.listening = false
  }
}
```

#### `SegmentedControl`

SegmentedControl component.

Pill-shaped segmented control: two or more options, the active one taking the
primary fill. The host IS the React root `<div>`
(`div[mol-faceted-search-segmented-control]`), carrying React's
`role="tablist"` and its class list. React keys each segment by the option's
`value`, and `@for` tracks the same key, so a re-passed or re-ordered array
keeps the rendered rows per value.

```typescript
@Component({
  selector: 'div[mol-faceted-search-segmented-control]',
  standalone: true,
  imports: [NgTemplateOutlet],
  inputs: ['options', 'value', 'onChange', 'className'],
  host: {
    role: 'tablist',
    '[class]': 'classes()',
  },
  // prettier-ignore
  template: `@for (opt of options; track opt.value) {<button type="button" role="tab" [attr.aria-selected]="opt.value === value ? 'true' : 'false'" [attr.data-state]="opt.value === value ? 'active' : 'inactive'" [attr.data-mol-id]="opt.dataMolId ?? null" (click)="select(opt)" [class]="triggerClasses()">@if (isTemplate(opt.label)) {<ng-container [ngTemplateOutlet]="asTemplate(opt.label)"></ng-container>} @else {{{ optionText(opt) }}}</button>}`,
})
export class SegmentedControl {
  /** The segments to render. */
  options: SegmentedControlProps['options'] = []
  /** The currently selected segment's value. */
  value = ''
  /** Called with a segment's value when it is clicked (React's `onChange`). */
  onChange?: (next: string) => void
  /** Extra classes on the row. */
  className?: string

  /**
   * The current class map.
   * @returns The UIClassMap.
   */
  cm(): UIClassMap {
    return getClassMap()
  }

  /**
   * Computes the row's class list, exactly as React composes it.
   * @returns The class string.
   */
  classes(): string {
    return this.cm().cn(
      this.cm().tabsList({ variant: 'solid-rounded', size: 'sm' }),
      this.className,
    )
  }

  /**
   * Computes a segment's class list, exactly as React composes it.
   * @returns The class string.
   */
  triggerClasses(): string {
    return this.cm().cn(
      this.cm().tabsTrigger({ variant: 'solid-rounded', size: 'sm' }),
      this.cm().fontWeight('semibold'),
      this.cm().touchTargetCompact,
    )
  }

  /**
   * Whether a label is an embedded template rather than text.
   * @param label - The option's label.
   * @returns True when it renders through `ngTemplateOutlet`.
   */
  isTemplate(label: unknown): label is TemplateRef<unknown> {
    return (
      typeof label === 'object' &&
      label !== null &&
      typeof (label as TemplateRef<unknown>).createEmbeddedView === 'function'
    )
  }

  /**
   * Narrows a label to an embedded template.
   * @param label - The option's label.
   * @returns The template.
   */
  asTemplate(label: unknown): TemplateRef<unknown> {
    return label as TemplateRef<unknown>
  }

  /**
   * An option's label as text (React renders strings and numbers).
   * @param opt - The option.
   * @returns The text, or `''` when the label is an embedded template.
   */
  optionText(opt: SegmentedControlProps['options'][number]): string {
    return textOf(opt.label)
  }

  /**
   * Reports a segment's value, React's `onChange(opt.value)`.
   * @param opt - The clicked option.
   */
  select(opt: SegmentedControlProps['options'][number]): void {
    this.onChange?.(opt.value)
  }
}
```

- **The bar is `position: fixed`, not sticky.** It overlays the page at
  `top: topOffsetPx` and reserves NO layout space — add matching top
  padding to the content below it.
- **Styling prereqs:** these components emit Tailwind + Material-3 token
  class literals (`bg-surface-container-high`, `ring-primary`,
  `text-on-primary`, `border-outline-variant/20`, …). They only style
  correctly with a Tailwind-based ClassMap bond whose theme defines the M3
  color tokens (the molecule scaffold default). On other ClassMap bonds the
  pills lose surfaces/rings but remain functional.
- **Icon font prereq:** `leadingIcon` and the chevron render
  `material-symbols-outlined` glyph names — without the Material Symbols
  font loaded they appear as raw text like "expand_more".
- The horizontal overflow uses a `hide-scrollbar` class that no package
  defines — define it in your app CSS (webkit-scrollbar none +
  scrollbar-width none) or scrollbars show; purely cosmetic.
- `FilterPill` closes on outside mousedown; it does not trap focus. Node
  props are projected content: the pill's label as `[slot=label]` content
  (or text / a template ref) and its panel as the default projection. Pass
  already-translated strings.
