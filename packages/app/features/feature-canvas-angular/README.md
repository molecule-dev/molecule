# @molecule/app-feature-canvas-angular

Angular canvas primitives — the SHARED BASE for canvas-family wrappers
(whiteboard, mind-map, design-canvas, presentation slide-canvas).

This package provides only the generic mechanics every canvas variant
uses: pan/zoom/select/transform infrastructure, node/edge primitives,
pointer-event utilities, and pure coordinate-transform helpers.

Domain-specific behavior (whiteboard drawing tools, mind-map auto-
layout, design-canvas vector ops) lives in the wrapper packages,
which consume this base as a peer dependency.

Exports:

- `<CanvasSurface>` (`div[mol-canvas-surface]`) — pan/zoom container;
  projected content renders in canvas-coordinate-space. Wheel zooms
  around the cursor; primary drag on the empty surface pans.
- `<CanvasNode>` (`div[mol-canvas-node]`) — generic positioned +
  draggable + resizable wrapper that lives inside the surface's
  canvas-space layer.
- `<CanvasEdge>` (`svg[mol-canvas-edge]`) — generic edge between two
  canvas-space points, with `'line'`, `'bezier'`, or `'orthogonal'`
  geometry.
- `useCanvasViewport()` — viewport state hook with `panBy` / `zoomBy`
  helpers and optional clamping.
- `useCanvasSelection()` — selection-set hook with idiomatic toggles.
- `screenToCanvas`, `canvasToScreen`, `clampViewport`, `fitToBounds`
  — pure coordinate-transform helpers.
- `buildEdgePath` — pure SVG path builder used by `<CanvasEdge>`.
- `CanvasViewport`, `Point`, `Size`, `Bounds`, `ViewportLimits`,
  `CanvasEdgeKind`, `CanvasItemId`, `CanvasDragInfo`,
  `CanvasResizeInfo` types.

#### `CanvasEdge`

CanvasEdge component.

Generic edge between two canvas-space points. The host IS the `<svg>`
(`svg[mol-canvas-edge]`), matching React's root exactly: an
absolutely-positioned SVG spanning the bounding box of the two endpoints
(with a small overflow margin so curves are not clipped). Domain semantics
(which nodes are connected, labels, arrowheads) live in wrapper packages —
this base just draws the geometry.

```typescript
  standalone: true,

    '[attr.height]': 'height()',

    '[style.left]': 'leftPx()',
    '[style.top]': 'topPx()',
    '[style.width]': 'widthPx()',
    '[style.height]': 'heightPx()',
    '[style.pointer-events]': "'none'",
    '[style.overflow]': "'visible'",
  },
  template: `<svg:path
    [attr.d]="pathData()"
    fill="none"
    [attr.stroke]="stroke ?? 'currentColor'"
    [attr.stroke-width]="strokeWidth ?? 2"
    stroke-linecap="round"
    stroke-linejoin="round"
    data-mol-id="canvas-edge-path"
  ></svg:path>`,

export class CanvasEdge {
  /** Edge starting point in canvas-space. */
  from?: Point
  /** Edge ending point in canvas-space. */
  to?: Point
  /** Edge geometry (defaults to `'line'` at read time). */
  kind?: CanvasEdgeKind
  /** Stroke width in canvas units (defaults to `2` at read time). */
  strokeWidth?: number
  /** SVG `stroke` attribute (defaults to `'currentColor'` at read time). */
  stroke?: string
  /** Optional aria-label override (defaults to a translated label). */
  ariaLabel?: string
  /** Extra classes merged onto the wrapper. */
  className?: string

  /** Reactive translation. */
  private readonly i18n = useTranslation()

  /**
   * The current class map.
   *
   * @returns The UIClassMap.
   */
  cm(): UIClassMap {
    return getClassMap()
  }

  /**
   * Computes the wrapper class list.
   *
   * @returns The class string.
   */
  classes(): string {
    return this.cm().cn(this.cm().position('absolute'), this.className)
  }

  /**
   * The overflow margin around the endpoint bounding box.
   *
   * @returns The margin in canvas units.
   */
  margin(): number {
    return Math.max(20, (this.strokeWidth ?? 2) * 4)
  }

  /**
   * The SVG's left edge.
   *
   * @returns The canvas-space x.
   */
  minX(): number {
    return Math.min(this.from?.x ?? 0, this.to?.x ?? 0) - this.margin()
  }

  /**
   * The SVG's top edge.
   *
   * @returns The canvas-space y.
   */
  minY(): number {
    return Math.min(this.from?.y ?? 0, this.to?.y ?? 0) - this.margin()
  }

  /**
   * The SVG's width (the endpoints' span plus the margin on both sides).
   *
   * @returns The width in canvas units.
   */
  width(): number {
    return Math.abs((this.to?.x ?? 0) - (this.from?.x ?? 0)) + this.margin() * 2
  }

  /**
   * The SVG's height (the endpoints' span plus the margin on both sides).
   *
   * @returns The height in canvas units.
   */
  height(): number {
    return Math.abs((this.to?.y ?? 0) - (this.from?.y ?? 0)) + this.margin() * 2
  }

  /**
   * The SVG's left offset as a CSS length.
   *
   * @returns The CSS length.
   */
  leftPx(): string {
    return `${this.minX()}px`
  }

  /**
   * The SVG's top offset as a CSS length.
   *
   * @returns The CSS length.
   */
  topPx(): string {
    return `${this.minY()}px`
  }

  /**
   * The SVG's width as a CSS length.
   *
   * @returns The CSS length.
   */
  widthPx(): string {
    return `${this.width()}px`
  }

  /**
   * The SVG's height as a CSS length.
   *
   * @returns The CSS length.
   */
  heightPx(): string {
    return `${this.height()}px`
  }

  /**
   * The SVG's viewBox.
   *
   * @returns The `0 0 width height` pair.
   */
  viewBox(): string {
    return `0 0 ${this.width()} ${this.height()}`
  }

  /**
   * The `path` `d` attribute, in viewBox-local coordinates.
   *
   * @returns SVG path data.
   */
  pathData(): string {
    const from = this.from ?? { x: 0, y: 0 }
    const to = this.to ?? { x: 0, y: 0 }
    const minX = this.minX()
    const minY = this.minY()
    return buildEdgePath(
      { x: from.x - minX, y: from.y - minY },
      { x: to.x - minX, y: to.y - minY },
      this.kind ?? 'line',
    )
  }

  /**
   * The accessible name of the edge.
   *
   * @returns The label.
   */
  resolvedAriaLabel(): string {
    return this.ariaLabel ?? this.i18n.t('canvas.aria.edge', {}, { defaultValue: 'Canvas edge' })
  }
}
```

#### `CanvasNode`

CanvasNode component.

Generic positioned + draggable + resizable wrapper. The host IS the node
(`div[mol-canvas-node]`), matching React's root exactly. It owns absolute
positioning at `position` (canvas units), an optional explicit `size`,
`onSelect` on a press that never moved, `onDrag` from any press on the node
body, and `onResize` from a SE-corner handle (rendered only when `onResize`
is supplied). It does NOT own visual chrome — wrappers compose chrome on top
with projected content.

Accessibility: the host renders as `role="group"` named by `aria-label`.
`aria-selected` is not valid on a group, and the selectable roles need a
listbox, grid or tree parent the `role="application"` surface is not; a
selected node is therefore described by a hidden "Selected" text through
`aria-describedby`.

```typescript
export class CanvasNode {
  id?: CanvasItemId
  /** Canvas-space top-left position of the node. */
  position?: Point
  /** Optional canvas-space size. */
  size?: Size
  /** Whether the node is currently selected. */
  selected?: boolean
  /** Called when a press that never moved activates the node. */
  onSelect?: (id: CanvasItemId | undefined, e: PointerEvent) => void
  /** Called continuously during a drag gesture. */
  onDrag?: (info: CanvasDragInfo) => void
  onResize?: (info: CanvasResizeInfo) => void
  ariaLabel?: string
  /** Extra classes merged onto the wrapper. */
  className?: string

  /** Reactive translation. */
  private readonly i18n = useTranslation()
  readonly descriptionId = `mol-canvas-node-${nextDescriptionId++}`

  // Drag gesture state.
  private dragPointerId: number | null = null
  private dragLastScreen: { x: number; y: number } | null = null
  private dragPosition: Point = { x: 0, y: 0 }
  private movedDuringGesture = false

  // Resize gesture state.
  private resizePointerId: number | null = null
  private resizeStartScreen: { x: number; y: number } | null = null
  private resizeStartSize: Size | null = null

  /** The current class map. */
  cm(): UIClassMap {
    return getClassMap()
  }

  /** Computes the wrapper class list. */
  classes(): string {
    return this.cm().cn(this.cm().position('absolute'), this.className)
  }

  /** The node's left edge in canvas units. */
  leftPx(): string {
    return `${this.position?.x ?? 0}px`
  }

  /** The node's top edge in canvas units. */
  topPx(): string {
    return `${this.position?.y ?? 0}px`
  }

  /** The node's width, or `null` (no style) without a size. */
  widthPx(): string | null {
    return this.size ? `${this.size.width}px` : null
  }

  /** The node's height, or `null` (no style) without a size. */
  heightPx(): string | null {
    return this.size ? `${this.size.height}px` : null
  }

  /** The accessible name of the node. */
  resolvedAriaLabel(): string {
    return this.ariaLabel ?? this.i18n.t('canvas.aria.node', {}, { defaultValue: 'Canvas node' })
  }

  /** The accessible name of the resize handle. */
  handleLabel(): string {
    return this.i18n.t('canvas.aria.resizeHandle', {}, { defaultValue: 'Resize node' })
  }

  /** The hidden description a selected node is named by. */
  selectedLabel(): string {
    return this.i18n.t('canvas.aria.nodeSelected', {}, { defaultValue: 'Selected' })
  }

  /** The resize handle's agent selector. */
  handleMolId(): string {
    return this.id ? `canvas-node-resize-handle-${this.id}` : 'canvas-node-resize-handle'
  }

  onPointerDown(event: PointerEvent): void {
    // Block surface pan.
    event.stopPropagation()
    if (event.button !== 0 && event.pointerType === 'mouse') return
    this.dragPointerId = event.pointerId
    this.dragLastScreen = { x: event.clientX, y: event.clientY }
    this.dragPosition = this.position ?? { x: 0, y: 0 }
    this.movedDuringGesture = false
    try {
      ;(event.currentTarget as HTMLDivElement).setPointerCapture(event.pointerId)
    } catch (_error) {}
  }

  /** Reports each drag tick in canvas-space. */
  onPointerMove(event: PointerEvent): void {
    if (this.dragPointerId !== event.pointerId) return
    const last = this.dragLastScreen
    if (!last) return
    const zoom = readSurfaceZoom(event.currentTarget as Element) || 1
    const dx = (event.clientX - last.x) / zoom
    const dy = (event.clientY - last.y) / zoom
    if (dx === 0 && dy === 0) return
    this.dragLastScreen = { x: event.clientX, y: event.clientY }
    const next: Point = { x: this.dragPosition.x + dx, y: this.dragPosition.y + dy }
    const start = !this.movedDuringGesture
    this.movedDuringGesture = true
    this.dragPosition = next
    this.onDrag?.({ position: next, delta: { x: dx, y: dy }, start, end: false })
  }

  onPointerUp(event: PointerEvent): void {
    if (this.dragPointerId !== event.pointerId) return
    this.dragPointerId = null
    this.dragLastScreen = null
    try {
      ;(event.currentTarget as HTMLDivElement).releasePointerCapture(event.pointerId)
    } catch (_error) {}
    if (this.movedDuringGesture) {
      this.onDrag?.({ position: this.dragPosition, delta: { x: 0, y: 0 }, start: false, end: true })
    } else {
      this.onSelect?.(this.id, event)
    }
    this.movedDuringGesture = false
  }

  /** Starts a resize gesture from the SE handle. */
  onResizePointerDown(event: PointerEvent): void {
    event.stopPropagation()
    const size = this.size
    if (!this.onResize || !size) return
    if (event.button !== 0 && event.pointerType === 'mouse') return
    this.resizePointerId = event.pointerId
    this.resizeStartScreen = { x: event.clientX, y: event.clientY }
    this.resizeStartSize = { width: size.width, height: size.height }
    try {
      ;(event.currentTarget as HTMLDivElement).setPointerCapture(event.pointerId)
    } catch (_error) {}
  }

  /** Reports each resize tick in canvas-space. */
  onResizePointerMove(event: PointerEvent): void {
    if (this.resizePointerId !== event.pointerId) return
    if (!this.onResize) return
    const start = this.resizeStartScreen
    const startSize = this.resizeStartSize
    if (!start || !startSize) return
    const zoom = readSurfaceZoom(event.currentTarget as Element) || 1
    const dx = (event.clientX - start.x) / zoom
    const dy = (event.clientY - start.y) / zoom
    this.onResize({
      position: this.position ?? { x: 0, y: 0 },
      size: {
        width: Math.max(0, startSize.width + dx),
        height: Math.max(0, startSize.height + dy),
      },
      end: false,
    })
  }

  /** Ends the resize gesture. */
  onResizePointerUp(event: PointerEvent): void {
    if (this.resizePointerId !== event.pointerId) return
    this.resizePointerId = null
    const startSize = this.resizeStartSize
    this.resizeStartScreen = null
    this.resizeStartSize = null
    try {
      ;(event.currentTarget as HTMLDivElement).releasePointerCapture(event.pointerId)
    } catch (_error) {}
    if (this.onResize && startSize)
      this.onResize({
        position: this.position ?? { x: 0, y: 0 },
        size: this.size ?? startSize,
        end: true,
      })
  }
}
```

#### `CanvasSurface`

CanvasSurface component.

Pan/zoom container — the shared base every canvas variant builds on. The host
IS the outer `<div>` (`div[mol-canvas-surface]`), matching React's root
exactly. Wheel scroll zooms around the cursor; primary-button drag on the
empty surface pans; children render inside a CSS-transformed inner layer so
they live in canvas-coordinate-space. Children that handle their own pointer
gestures should stop propagation on pointerdown to suppress surface pan.

Children are projected content: everything inside the host lands in the
inner canvas-space layer.

```typescript
@Component({
  selector: 'div[mol-canvas-surface]',
  standalone: true,
  inputs: [
    'viewport',
    'initialViewport',
    'onViewportChange',
    'limits',
    'zoomFactor',
    'panOnDrag',
    'onBackgroundPointerDown',
    'width',
    'height',
    'ariaLabel',
    'className',
  ],
  host: {
    role: 'application',
    'data-mol-id': 'canvas-surface',
    '[attr.aria-label]': 'resolvedAriaLabel()',
    '[class]': 'classes()',
    '[style.position]': "'relative'",
    '[style.overflow]': "'hidden'",
    '[style.touch-action]': "'none'",
    '[style.width.px]': 'width',
    '[style.height.px]': 'height',
    '(pointerdown)': 'onPointerDown($event)',
    '(pointermove)': 'onPointerMove($event)',
    '(pointerup)': 'endPan($event)',
    '(pointercancel)': 'endPan($event)',
    '(wheel)': 'onWheel($event)',
  },
  template: `<div
    data-mol-id="canvas-surface-inner"
    [attr.data-canvas-zoom]="currentViewport().zoom"
    [attr.data-canvas-x]="currentViewport().x"
    [attr.data-canvas-y]="currentViewport().y"
    [style.position]="'absolute'"
    [style.top]="'0px'"
    [style.left]="'0px'"
    [style.transform-origin]="'0 0'"
    [style.transform]="innerTransform()"
    [style.width]="'0px'"
    [style.height]="'0px'"
  >
    <ng-content></ng-content>
  </div>`,
})
export class CanvasSurface implements OnInit {
  /** Controlled viewport; omit it for an uncontrolled surface. */
  viewport?: CanvasViewport
  /** Initial viewport (uncontrolled mode only, read once). */
  initialViewport?: CanvasViewport
  /** Called whenever the viewport changes. */
  onViewportChange?: (next: CanvasViewport) => void
  /** Optional clamping limits applied on every viewport update. */
  limits?: ViewportLimits
  /** Wheel-zoom factor per scroll tick (defaults to `1.1` at read time). */
  zoomFactor?: number
  /** Whether dragging the empty surface pans (React's default `true`). */
  panOnDrag?: boolean
  /** Called when an empty-area pointerdown fires. */
  onBackgroundPointerDown?: (e: PointerEvent) => void
  /** Width of the surface in CSS pixels. */
  width?: number
  /** Height of the surface in CSS pixels. */
  height?: number
  /** Optional aria-label override (defaults to a translated label). */
  ariaLabel?: string
  /** Extra classes merged onto the outer wrapper. */
  className?: string

  /** The host element (this component's root), for pointer coordinates. */
  private readonly host = inject<ElementRef<HTMLDivElement>>(ElementRef)
  /** Reactive translation. */
  private readonly i18n = useTranslation()

  /** The uncontrolled viewport (React's `useState` seed, read once). */
  private internal: CanvasViewport = DEFAULT_VIEWPORT

  /** Pointer id of the active pan gesture (null = no active pan). */
  private panPointerId: number | null = null
  /** Last screen-space position seen during the active pan. */
  private lastScreen: { x: number; y: number } | null = null

  /**
   * Seeds the uncontrolled viewport from the initial one, once (React's
   * `useRef` seed): inputs are set before this hook runs.
   */
  ngOnInit(): void {
    this.internal = this.initialViewport ?? DEFAULT_VIEWPORT
  }

  /**
   * The current class map.
   *
   * @returns The UIClassMap.
   */
  cm(): UIClassMap {
    return getClassMap()
  }

  /**
   * Computes the wrapper class list.
   *
   * @returns The class string.
   */
  classes(): string {
    return this.cm().cn(this.cm().position('relative'), this.cm().surfaceSecondary, this.className)
  }

  /**
   * The accessible name of the surface.
   *
   * @returns The label.
   */
  resolvedAriaLabel(): string {
    return (
      this.ariaLabel ?? this.i18n.t('canvas.aria.surface', {}, { defaultValue: 'Canvas surface' })
    )
  }

  /**
   * The viewport in effect: the controlled one, or the internal state.
   *
   * @returns The current viewport.
   */
  currentViewport(): CanvasViewport {
    return this.viewport ?? this.internal
  }

  /**
   * The inner layer's transform (canvas-space children).
   *
   * @returns The CSS transform string.
   */
  innerTransform(): string {
    const vp = this.currentViewport()
    return `scale(${vp.zoom}) translate(${-vp.x}px, ${-vp.y}px)`
  }

  /**
   * Replaces the viewport (clamped), reports it, and keeps it when uncontrolled.
   *
   * @param next - The desired viewport.
   */
  setViewport(next: CanvasViewport): void {
    const clamped = clampViewport(next, this.limits)
    this.onViewportChange?.(clamped)
    if (this.viewport === undefined) this.internal = clamped
  }

  /**
   * Pans by a screen-space delta, interpreted through the current zoom.
   *
   * @param deltaX - Screen-space x delta.
   * @param deltaY - Screen-space y delta.
   */
  panBy(deltaX: number, deltaY: number): void {
    const vp = this.currentViewport()
    const safeZoom = vp.zoom === 0 ? 1 : vp.zoom
    this.setViewport({
      x: vp.x - deltaX / safeZoom,
      y: vp.y - deltaY / safeZoom,
      zoom: vp.zoom,
    })
  }

  /**
   * Zooms around a screen-space focal point, holding its canvas-space position.
   *
   * @param factor - Zoom multiplier (> 1 zooms in).
   * @param focalScreenX - Focal x in screen space.
   * @param focalScreenY - Focal y in screen space.
   */
  zoomBy(factor: number, focalScreenX: number, focalScreenY: number): void {
    if (factor <= 0) return
    const vp = this.currentViewport()
    const safeZoom = vp.zoom === 0 ? 1 : vp.zoom
    const focalCanvasX = focalScreenX / safeZoom + vp.x
    const focalCanvasY = focalScreenY / safeZoom + vp.y
    const nextZoom = vp.zoom * factor
    this.setViewport({
      x: focalCanvasX - focalScreenX / nextZoom,
      y: focalCanvasY - focalScreenY / nextZoom,
      zoom: nextZoom,
    })
  }

  /**
   * Handles a surface pointer-down: background callback, then pan.
   *
   * @param event - The pointer event.
   */
  onPointerDown(event: PointerEvent): void {
    // Only react to gestures on the surface itself, not on children.
    if (event.target !== event.currentTarget) return
    this.onBackgroundPointerDown?.(event)
    if (this.panOnDrag === false) return
    if (event.button !== 0 && event.pointerType === 'mouse') return
    this.panPointerId = event.pointerId
    this.lastScreen = { x: event.clientX, y: event.clientY }
    try {
      ;(event.currentTarget as HTMLDivElement).setPointerCapture(event.pointerId)
    } catch (_error) {
      // setPointerCapture throws in jsdom; the pan still works without it.
    }
  }

  /**
   * Pans by the delta since the previous move of the active gesture.
   *
   * @param event - The pointer event.
   */
  onPointerMove(event: PointerEvent): void {
    if (this.panPointerId !== event.pointerId) return
    const last = this.lastScreen
    if (!last) return
    const dx = event.clientX - last.x
    const dy = event.clientY - last.y
    this.lastScreen = { x: event.clientX, y: event.clientY }
    this.panBy(dx, dy)
  }

  /**
   * Ends the active pan gesture (pointer-up or pointer-cancel).
   *
   * @param event - The pointer event.
   */
  endPan(event: PointerEvent): void {
    if (this.panPointerId !== event.pointerId) return
    this.panPointerId = null
    this.lastScreen = null
    try {
      ;(event.currentTarget as HTMLDivElement).releasePointerCapture(event.pointerId)
    } catch (_error) {
      // releasePointerCapture throws in jsdom; capture was never held there.
    }
  }

  /**
   * Zooms around the cursor on a wheel tick.
   *
   * @param event - The wheel event.
   */
  onWheel(event: WheelEvent): void {
    const rect = this.host.nativeElement.getBoundingClientRect()
    if (!rect) return
    const focalX = event.clientX - rect.left
    const focalY = event.clientY - rect.top
    const zoomFactor = this.zoomFactor ?? 1.1
    const factor = event.deltaY < 0 ? zoomFactor : 1 / zoomFactor
    this.zoomBy(factor, focalX, focalY)
  }
}
```

#### `clampViewport(viewport, limits)`

Clamp a viewport to optional limits. `bounds` (if provided) constrains
where the viewport origin may sit; `minZoom` / `maxZoom` clamp zoom.
Returns a new viewport — does not mutate the input.

If `bounds` is provided AND has positive width/height, the origin is
clamped so the surface still overlaps the bounds when fully zoomed
out. (Wrappers can layer richer rules on top via `onViewportChange`.)

```typescript
function clampViewport(viewport: CanvasViewport, limits?: ViewportLimits): CanvasViewport
```

- `viewport` — The desired viewport.
- `limits` — Optional clamping limits.

**Returns:** A clamped viewport.

#### `fitToBounds(bounds, surface, padding)`

Compute the viewport that fits a canvas-space bounds rectangle into a
surface of the given screen-space size, with optional padding (in
screen-space pixels) around the content.

The returned viewport centers the content, but if either dimension
is zero the center is well-defined (the bounds origin) and zoom is
clamped to `1`.

```typescript
function fitToBounds(bounds: Bounds, surface: Size, padding?: number): CanvasViewport
```

- `bounds` — Canvas-space content rectangle to fit.
- `surface` — Screen-space size of the surface.
- `padding` — Screen-space padding around the content (default 0).

**Returns:** A viewport that frames `bounds` inside the surface.
