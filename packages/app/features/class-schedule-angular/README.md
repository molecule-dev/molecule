# @molecule/app-class-schedule-angular

Angular weekly class-schedule grid — the counterpart of
`@molecule/app-class-schedule-react`: the same props and the same DOM for the
same input.

Exports `<div mol-class-schedule>` — a 7-day × N-hour time grid with
absolutely positioned event tiles inside each day column. Overlapping events
on the same weekday are split into side-by-side lanes, and the `eventClick` /
`slotClick` outputs fire separately for event tiles and empty time slots.

#### `assignLanes(events)`

Lay out events that share a weekday into non-overlapping side-by-side
lanes. Each event gets a `lane` index (0…N) and a `lanes` count for the
group it belongs to so the caller can compute width/left as
`width = (1/lanes) * 100%` / `left = (lane/lanes) * 100%`.

```typescript
function assignLanes<E extends { start: number; end: number }>(
  events: E[],
): Array<{ event: E; lane: number; lanes: number }>
```

- `events` — Events occurring on a single weekday.

**Returns:** Array of `{ event, lane, lanes }` records, in input order.
