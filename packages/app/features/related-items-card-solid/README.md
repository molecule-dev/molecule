### Functions

#### `RelatedItemsCard(props)`

Card container for a list of cross-linked / related items.

Common usage: "Company → Deals", "Contact → Notes", "Ticket → Related
Articles", "Post → Related Posts". Apps supply the item data and a renderer;
the card provides consistent header + list + empty-state + view-all chrome.

Clickable rows (`onItemClick`): the `<li>` stays a list item and the card
wraps the row content in an inner `role="button"` div — focusable, with
Enter/Space running the same handler the click does.

Rows keep their DOM node while the item at their index changes, as React's
index-keyed rows do: `<Index>` reconciles by position and the memo rebuilds
the rendered content for the new item.

- Requires a bonded ClassMap — call `setClassMap()` (e.g. with
  `@molecule/app-ui-tailwind`) at startup or rendering throws.
- The "View all" label is hardcoded English in the React reference (not
  routed through i18n) and is the same literal here; pass a translated link
  via `headerActions` in localized apps.
- `onItemClick` rows stay `<li>` list items: the card wraps each row's
  content in an inner `role="button"` control (focusable, Enter/Space
  activate it) so the click works from the keyboard too. A real
  `<button>`/`<a>` inside `renderItem` still takes its own clicks and focus.
- `viewAllHref` renders a plain `<a href>` (full page load in SPA routers);
  use `headerActions` with your router's Link for client-side navigation.
