`contact` fields are display-only data — `email`/`phone` render as
`mailto:`/`tel:` links; there is no formatting/validation. The email/phone/
address markers are text glyphs (✉ ☎ ⌂), not themed SVG icons. `role`,
`address`, and `company` accept Solid JSX values — pass translated strings
via `t()` where needed. When `onClick` is provided the whole row becomes
clickable through a transparent native button covering it, named by the
contact name (the name span); the mail/tel links and the `actions` slot sit
above that button and keep their own clicks.
