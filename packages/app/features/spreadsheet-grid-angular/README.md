```ts
import { Component, signal } from '@angular/core'
import { SpreadsheetGrid } from '@molecule/app-spreadsheet-grid-angular'
import type { CellMap, SpreadsheetSelection } from '@molecule/app-spreadsheet-grid-angular'

@Component({
  selector: 'app-sheet',
  standalone: true,
  imports: [SpreadsheetGrid],
  template: `
    <div
      mol-spreadsheet-grid
      [rows]="1000"
      [columns]="26"
      [cells]="cells()"
      [frozenRows]="1"
      [frozenCols]="1"
      [selection]="selection()"
      [onCellChange]="onCellChange"
      [onSelectionChange]="onSelectionChange"
    ></div>
  `,
})
export class Sheet {
  readonly cells = signal<CellMap>(new Map())
  readonly selection = signal<SpreadsheetSelection>({ r1: 0, c1: 0, r2: 0, c2: 0 })

  readonly onCellChange = (ref: string, value: string | number | boolean | null): void => {
    const next = new Map(this.cells())
    if (value === null) next.delete(ref)
    else next.set(ref, value)
    this.cells.set(next)
  }

  readonly onSelectionChange = (next: SpreadsheetSelection): void => {
    this.selection.set(next)
  }
}
```

drag started) and `r2`/`c2` is the focus (where it ended). Both are

### Types

#### `CellRef`

Cell reference in A1 notation (e.g. `'A1'`, `'AB17'`). Column letters are
uppercase; row numbers are 1-indexed.


#### `CellValue`

Primitive value stored in a cell. Formula strings start with `'='` —

Sparse map from `CellRef` to value. Cells not present in the map render


### Classes

#### `SpreadsheetGrid`

SpreadsheetGrid component.

High-performance virtualized spreadsheet cell grid: the host IS React's root
`<div role="grid">` (`div[mol-spreadsheet-grid]`), so no wrapper element
exists. Renders an `rows × columns` grid backed by a sparse
`Map<cellRef, value>`, with frozen rows/columns, range selection (click +
drag, Shift+click), copy/paste through the system clipboard as TSV, and
in-cell editing (double-click → input; Enter commits, Escape cancels).
Only the cells inside the visible viewport (plus a small overscan margin)
are rendered.

React's callbacks are inputs (they keep their React names and their argument
lists); React's `renderCell` render prop is an `ng-template`.

#### `computeVisibleRange(scroll, viewport, itemSize, total, overscan)`

Compute the inclusive `[start, end]` window of indices to render given
the scroll offset, viewport size, item size, and total count. Adds an
`overscan` margin on each side so newly-visible cells are pre-rendered
during fast scrolls.

```typescript

  scroll: number,
  viewport: number,
  itemSize: number,
  total: number,
  overscan?: number,

```

- `viewport` — Viewport size (px) along the scroll axis.

- `total` — Total number of items.
- `overscan` — Extra items to render on each side (default `2`).

**Returns:** `[startIndex, endIndex]` (both inclusive, clamped to `[0, total)`).

- Must render with a ClassMap bond wired (`getClassMap()` throws
  otherwise), and inside the app's i18n provider (or with the bonded one).
- The viewport is FIXED-PIXEL: `viewportWidth`/`viewportHeight`
  (defaults 720×360) — the grid does not auto-size to its container.
  Measure the container and pass px if you need it to fill.
- Copy (Ctrl/Cmd+C) writes TSV through `copyTextWithFallback()` from
  `@molecule/app-clipboard`, which uses the bonded clipboard provider with
  a selection-and-copy fallback and never throws. Paste is handled through
  the native paste event, so the grid container must have focus (click a
  cell first). Keyboard support is Enter/F2 (edit) + copy/paste only; there
  is NO arrow-key cell navigation.
- Committed edits and pasted cells auto-coerce number-like strings to
  numbers (`'42'` → `42`); empty string clears the cell (`null`).
- Gridlines/selection/header styling uses Material-3 design-token
  utilities (`bg-surface`, `border-outline-variant`, …). Apps whose
  Tailwind theme does not define those tokens (the minimal scaffold
  theme does not) get a functional but unstyled grid.
