# @molecule/app-layer-panel-angular

Angular Photoshop / Figma–style reorderable layer panel.

Exports:

- `<LayerPanel>` (`ul[mol-layer-panel]`) — the panel component
  (drag-to-reorder via pointer events, visibility / lock toggles,
  double-click inline rename, click-to-select, optional thumbnail +
  opacity + blend-mode metadata).
- Types: `LayerPanelProps`, `Layer`, `LayerBlendMode`.
- Helpers: `moveLayer()`, `formatOpacityPercent()`.

It is the Angular counterpart of `@molecule/app-layer-panel-react`: the same
props (React names), the same ClassMap tokens and the same DOM for the same
input. The host element IS React's root `<ul>`, so an app places it on a
`<ul>` in its template.

The panel is fully controlled — the host application owns the `Layer[]`
array and re-renders with the next state in response to the `onReorder` /
`onVisibilityToggle` / `onLockToggle` / `onSelect` / `onRename` inputs.

Layers are rendered top-down per Photoshop convention: index 0 is the first
row in the UI and represents the front-most layer.

Toggle/rename labels route through `t()` — add the companion
`@molecule/app-locales-layer-panel` bond to translate them. Locked layers
cannot be dragged or renamed. The eye / lock toggles render emoji glyphs.

## Quick Start

```ts
import { Component, signal } from '@angular/core'
import { LayerPanel, type Layer } from '@molecule/app-layer-panel-angular'

@Component({
  selector: 'app-editor',
  standalone: true,
  imports: [LayerPanel],
  template: `
    <ul
      mol-layer-panel
      [layers]="layers()"
      [activeId]="activeId()"
      [onReorder]="setLayers"
      [onVisibilityToggle]="toggleVisibility"
      [onLockToggle]="toggleLock"
      [onSelect]="select"
      [onRename]="rename"
    ></ul>
  `,
})
export class Editor {
  readonly layers = signal<Layer[]>([
    { id: 'bg', name: 'Background', visible: true, locked: false },
    { id: 'fg', name: 'Sketch', visible: true, locked: false, opacity: 0.8 },
  ])
  readonly activeId = signal<string | undefined>(undefined)

  readonly setLayers = (next: Layer[]): void => this.layers.set(next)
  readonly select = (id: string): void => this.activeId.set(id)
  readonly rename = (id: string, name: string): void => {
    this.layers.update((ls) => ls.map((l) => (l.id === id ? { ...l, name } : l)))
  }
  private patch(id: string, next: Partial<Layer>): void {
    this.layers.update((ls) => ls.map((l) => (l.id === id ? { ...l, ...next } : l)))
  }
  readonly toggleVisibility = (id: string): void => {
    this.patch(id, { visible: !this.layers().find((l) => l.id === id)?.visible })
  }
  readonly toggleLock = (id: string): void => {
    this.patch(id, { locked: !this.layers().find((l) => l.id === id)?.locked })
  }
}
```

#### `Layer`

A single editable layer in the stack. The host application owns the
data — `<LayerPanel>` is a controlled view that emits intent callbacks

#### `LayerPanel`

LayerPanel component.

Photoshop / Figma–style layer panel: a vertical, drag-to-reorder list of
layers with eye/lock toggles, inline rename (double-click), and
click-to-select. All interactions emit intent callbacks; the host
application owns the data and re-renders with the next `layers` array.

It is the Angular counterpart of `@molecule/app-layer-panel-react`'s
`LayerPanel`: the same props (React names), the same ClassMap tokens and the
same DOM for the same input. The host IS the outer `<ul>`
(`ul[mol-layer-panel]`), matching React's root exactly.

Drag-to-reorder uses pointer events (no `@dnd-kit` or HTML5 DnD
dependency), so it works on touch surfaces and inside transformed canvases
without quirks. The visual convention is top-down — index 0 is the
front-most layer.

### Functions

#### `moveLayer(layers, fromIndex, toIndex)`

Move a layer from one index to another inside the panel array, returning a
fresh array. The display convention is **top-down** (index 0 is the
top-most layer in Photoshop terms — the front-most), so callers don't
have to reverse anything.

Out-of-range indices are clamped to `[0, layers.length - 1]`. If the
source and destination resolve to the same index the original array
is returned unchanged (referential equality preserved).

```typescript
function moveLayer(layers: readonly Layer[], fromIndex: number, toIndex: number): Layer[]
```

- `layers` — Current ordered layers (top-down).
- `fromIndex` — Index of the layer being moved.
- `toIndex` — Destination index after the move.

**Returns:** A new array reflecting the reordered layers, or the original reference if the move is a no-op.

#### `formatOpacityPercent(opacity)`

Format an opacity value (`0`..`1`) as a Photoshop-style integer
percent string (`"100%"`). Returns an empty string when opacity is
`undefined` so callers can render "no metadata" rows naturally.

Values outside `[0, 1]` are clamped, fractional results are rounded
to the nearest integer.

```typescript
function formatOpacityPercent(opacity: number | undefined): string
```

- `opacity` — The 0–1 opacity, or `undefined`.

**Returns:** A locale-agnostic `"NN%"` string, or `""` when opacity is undefined.
