# @molecule/app-auth-shell-angular

`@molecule/app-auth-shell-angular` — centered glassmorphic shell for auth
pages (Login, Signup, ForgotPassword, ResetPassword), the Angular counterpart
of `@molecule/app-auth-shell-react`: the same exports, the same props (React
names), and the same DOM for the same input.

Apps pass per-app `decoration` (orbs, gradient backdrop) and `brand` (logo +
tagline) as projected content. The shell handles layout, the glass card,
heading/subheading, body, footer, and the "Back to home" link.

The shell also publishes its content through a DOM-scoped auth-form context,
so any form rendered inside inherits cross-view email persistence. Forms read
it via `useAuthFormStateContext()`, or use the standalone `useAuthFormState`
hook. Persistence flows through the `@molecule/app-storage` `StorageProvider`
abstraction (never raw `sessionStorage`), defaulting to a process-shared
in-memory store.

Besides the `AuthShell` preset, the package exports the composable
primitives — `AuthShellContainer`, `AuthShellDecoration`, `AuthShellCard`,
`AuthShellHeading`, `AuthShellFooter`, `AuthShellBackLink` — plus a
two-column family for the split layout: `AuthShellSplit` >
`AuthShellSplitRow` > (`AuthShellPanel` + `AuthShellCardColumn`).

#### `AuthFormStateProvider`

Provides a single {@link useAuthFormState} instance to all descendants via a
DOM-scoped context, so sibling/child auth forms share the same email.

The host is `display: contents`, so it adds no box of its own — React's
provider renders its children with no wrapping element.

```typescript
@Component({
  selector: 'div[mol-auth-form-state-provider]',
  standalone: true,
  inputs: ['storage', 'storageKey', 'initialFields'],
  host: { style: 'display: contents' },
  template: `<ng-content></ng-content>`,
})
export class AuthFormStateProvider implements OnInit, OnDestroy {
  /** Storage provider backing persistence (defaults to a shared in-memory provider). */
  storage?: UseAuthFormStateOptions['storage']
  /** Storage key for the persisted fields. */
  storageKey?: string
  /** Seed values used before hydration / when storage is empty. */
  initialFields?: AuthFormFields

  private readonly injector = inject(EnvironmentInjector)
  private readonly host = inject<ElementRef<HTMLElement>>(ElementRef).nativeElement
  private state: AuthFormState | null = null
  private teardown: (() => void) | null = null

  /**
   * Creates the state with this instance's inputs (available only here) and
   * registers it for descendants.
   */
  ngOnInit(): void {
    this.state = runInInjectionContext(this.injector, () =>
      useAuthFormState({
        storage: this.storage,
        storageKey: this.storageKey,
        initialFields: this.initialFields,
      }),
    )
    this.teardown = provideAuthFormState(this.host, this.state)
  }

  /** Removes the DOM-scoped registration. */
  ngOnDestroy(): void {
    this.teardown?.()
  }
}
```

```typescript
    const cm = this.cm()
    return cm.cn(
      cm.flex({ align: 'center', justify: 'center' }),
      cm.minH('screen'),
      cm.sp('p', 6),
      cm.authShellContainer,
    )
  }

  /**
   * The decoration layer's class.
   * @returns The class string.
   */
  decorationClasses(): string {
    return this.cm().cn(this.cm().authShellDecoration)
  }

  /**
   * The outer card `<main>`'s class.
   * @returns The class string.
   */
  cardOuterClasses(): string {
    const cm = this.cm()
    return cm.cn(cm.w('full'), cm.authShellCardOuter)
  }

  /**
   * The card's inner surface class.
   * @returns The class string.
   */
  cardSurfaceClasses(): string {
    const cm = this.cm()
    return cm.cn(cm.flex({ direction: 'col', gap: 'lg' }), cm.sp('p', 8), cm.authShellCardSurface)
  }

  /**
   * The heading wrapper's class.
   * @returns The class string.
   */
  headerClasses(): string {
    return this.cm().flex({ direction: 'col', align: 'center', gap: 'xs' })
  }

  /**
   * The h1's class.
   * @returns The class string.
   */
  titleClasses(): string {
    const cm = this.cm()
    return cm.cn(cm.textSize('2xl'), cm.fontWeight('bold'), cm.authShellHeadingTitle)
  }

  /**
   * The subheading paragraph's class.
   * @returns The class string.
   */
  subheadingClasses(): string {
    const cm = this.cm()
    return cm.cn(cm.textSize('sm'), cm.authShellHeadingSub)
  }

  /**
   * The footer's class.
   * @returns The class string.
   */
  footerClasses(): string {
    const cm = this.cm()
    return cm.cn(cm.textCenter, cm.textSize('sm'), cm.authShellFooter)
  }

  /**
   * The back-link destination (React's `backTo = '/'` default parameter).
   * @returns The path.
   */
  backToValue(): string {
    return this.backTo ?? '/'
  }

  /**
   * Whether the back link renders (React's `showBackLink = true` default).
   * @returns True unless bound to `false`.
   */
  showBackLinkValue(): boolean {
    return this.showBackLink ?? true
  }

  /** Creates and publishes the shared auth-form state (inputs are available here). */
  ngOnInit(): void {
    const state = runInInjectionContext(this.injector, () =>
      useAuthFormState({
        storage: this.formStateStorage,
        storageKey: this.formStateKey,
      }),
    )
    this.teardown = provideAuthFormState(this.host, state)
  }

  /** Removes the decoration and footer wrappers React omits when their slot is empty. */
  ngAfterViewInit(): void {
    for (const slot of [this.decorationSlot, this.footerSlot]) {
      const element = slot?.nativeElement
      if (element && !hasNodes(element)) element.remove()
    }
  }

  /** Removes the DOM-scoped registration. */
  ngOnDestroy(): void {
    this.teardown?.()
  }
}
```

### Functions

#### `useAuthFormStateContext()`

Reads the shared auth form state published by the nearest
`<AuthFormStateProvider>`/`<AuthShell>`.

The lookup is deferred to the first property read, so a form projected into
the provider resolves it reliably after the provider's initialization.

```typescript
function useAuthFormStateContext(): AuthFormState
```

**Returns:** The shared {@link AuthFormState}.

#### `useAuthFormState(options)`

Angular hook holding email + shared auth fields, persisted across auth views
via an injectable `StorageProvider` and cleared on successful auth.

```typescript
function useAuthFormState(options?: UseAuthFormStateOptions): AuthFormState
```

- `options` — Optional storage provider, storage key, and seed fields.

**Returns:** The current fields plus `setField`/`setFields`/`clear` and a `hydrated` flag.

### Constants

#### `DEFAULT_AUTH_FORM_STATE_KEY`

Default storage key for persisted auth form fields.

```typescript
const DEFAULT_AUTH_FORM_STATE_KEY: 'molecule.auth.form-state'
```

`AuthShell` renders the binding's `Link` directive (`<a molLink>`) for
"Back to home" by default, so render it under `provideMolecule({ router })`;
set `[showBackLink]="false"` in router-less setups. The back link's arrow
uses the Material Symbols icon font; the glyph span is `aria-hidden="true"`,
so the link's accessible name is its `t()` label alone. Form-state
persistence defaults to a
process-shared in-memory store (survives route swaps, not reloads) — pass a
`StorageProvider` for reload-safe, tab-scoped persistence. Translations come
from the companion `@molecule/app-locales-auth-shell` locale bond. Node props
(`brand`, `decoration`, `footer`) are projected content selected by
`[slot=brand]` / `[slot=decoration]` / `[slot=footer]`.
