# @molecule/app-pointer-events-dom

Shared DOM drag, hover, and Ctrl-wheel zoom gestures for the Molecule web UI kits.

Use the renderer's drag binding with `ElementDrag` from `@molecule/app-ui`.
All web kits share press ownership, pointer capture, touch intent, and
cancellation on pointer cancel, lost capture, window blur, and host removal.
Use `markPressTarget` for custom controls that must keep their own presses.
Use `bindWebHover` for one mouse or pen transition per boundary and
`bindWebWheelZoom` to handle Ctrl-wheel steps on a surface.

#### `createWebHover()`

Creates one enter/leave transition for a host. Touch and its compatibility
mouse events never hover. A later mouse or pen pointer resumes hover.


**Returns:** A function that reports whether an event changes the host's hover state.

#### `bindWebHover(host, initialHandlers)`

Binds shared hover to a DOM element. The bubbling over/out events and the
direct enter/leave events use the same transition. Moving between a host's
descendants leaves its hover state alone.

```typescript

  host: HTMLElement | SVGElement,
  initialHandlers?: WebHoverHandlers,
): WebHoverBinding
```

- `host` — The HTML or SVG element that receives hover.
- `initialHandlers` — The callbacks to use until the first update.

**Returns:** The binding to update or destroy with the host.

#### `bindWebWheelZoom(host, initialStep)`

Listens non-passively for Ctrl-wheel with a finite, nonzero vertical delta.
The handled event is consumed so the browser leaves page zoom alone.

```typescript

  host: Partial<EventTarget>,

```

- `host` — The surface receiving wheel events. A handle without DOM listeners is inert.
- `initialStep` — The zoom callback to use until the first update.

**Returns:** The binding to update or destroy with the host.
